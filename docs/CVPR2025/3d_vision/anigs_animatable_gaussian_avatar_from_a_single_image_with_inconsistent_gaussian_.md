# AniGS: Animatable Gaussian Avatar from a Single Image with Inconsistent Gaussian Reconstruction

**Conference**: CVPR 2025  
**arXiv**: [2412.02684](https://arxiv.org/abs/2412.02684)  
**Code**: [https://lingtengqiu.github.io/2024/AniGS/](https://lingtengqiu.github.io/2024/AniGS/)  
**Area**: 3D Vision  
**Keywords**: 3D Human Reconstruction, Gaussian Splatting, Single-image Generation, Video Diffusion, 4DGS

## TL;DR
Generates an animatable 3D human from a single image. It first employs adapted CogVideo to generate multi-view canonical pose images (including normals), then models multi-view inconsistency as temporal changes in 4DGS to extract a consistent canonical-space Gaussian model, and finally drives animation via SMPL-X skinning.

## Background & Motivation

**Background**: Creating animatable 3D humans from a single image is a core requirement for virtual avatars/digital humans. Existing methods like CharacterGen use multi-view generation + standard 3DGS reconstruction, but multi-view images inevitably present cross-view inconsistencies (clothing details, colors, geometry).

**Limitations of Prior Work**: (1) Multi-view images generated by video generation models exhibit view inconsistency—appearance details do not fully match across different angles. (2) Standard 3DGS assumes perfect consistency across multiple views; inconsistent inputs cause reconstruction blur and artifacts. (3) Generating canonical pose images requires pose control, but existing video generation models do not support precise pose conditioning.

**Key Challenge**: Multi-view generation inconsistency is inevitable (an inherent limitation of generative models), yet 3D reconstruction requires strict multi-view consistency.

**Goal**: To extract a consistent 3D canonical-space representation despite inconsistent multi-view inputs.

**Key Insight**: Reinterpreting multi-view inconsistency as "changes in the temporal dimension"—treating each view as a different time frame—and then modeling this "time-varying" appearance with the deformation field of 4DGS, allowing the canonical space to naturally extract a consistent 3D model.

**Core Idea**: Treat multi-view inconsistency as temporal variation and use the deformation field of 4DGS to absorb the inconsistency, facilitating consistent reconstruction in the canonical space.

## Method

### Overall Architecture
Input single image $\rightarrow$ CogVideo (with reference image guidance + SMPL-X pose conditioning + joint RGB/normal generation) $\rightarrow$ multi-view canonical pose images + normal maps $\rightarrow$ 4DGS reconstruction (HexPlane deformation field handling inconsistency) $\rightarrow$ canonical space 3DGS model $\rightarrow$ SMPL-X skinned animation.

### Key Designs

1. **Reference-Guided Multi-View Generation**:

    - **Function**: Generates 360° multi-view canonical pose images from a single image.
    - **Mechanism**: Adapts CogVideo to incorporate reference image guidance + SMPL-X rendered normals/depths as pose conditions. The first 3 blocks and the last 3 blocks of DiT handle RGB and normal modalities separately, while the middle 24 blocks are shared. Pre-trained on 100K in-the-wild videos and fine-tuned on 6,124 synthetic scans.
    - **Design Motivation**: Jointly generating RGB + normals provides additional geometric supervision for 3D reconstruction. Pre-training on in-the-wild videos yields better generalization than purely synthetic data.

2. **Inconsistency Handling with 4DGS**:

    - **Function**: Extracts a consistent canonical space under inconsistent multi-view inputs.
    - **Mechanism**: Uses a HexPlane + MLP deformation field to predict per-Gaussian shape/color offsets for each "view frame". The deformation field absorbs inconsistencies across views, leaving the canonical space as the "consensus" of multiple views.
    - **Design Motivation**: Standard 3DGS cannot handle inconsistent inputs, leading to blurriness. The deformation field of 4DGS provides an explicit modeling container for inconsistency.

3. **Shape Regularization**:

    - **Function**: Prevents needle-like artifacts during animation.
    - **Mechanism**: Normal $L_1$ loss constraints to ensure surface smoothness + anisotropy regularization to limit the extreme flattening of Gaussian ellipsoids.
    - **Design Motivation**: Gaussians in standard 3DGS easily degenerate into extremely thin ellipsoids, producing needle-like artifacts under new poses.

### Loss & Training
RGB $L_1$ + SSIM + Normal $L_1$ + anisotropy regularization. ~5 minutes for generation + ~5 minutes for optimization, enabling real-time rendering.

## Key Experimental Results

### Main Results

| Method | PSNR↑ | SSIM↑ | LPIPS↓ |
|------|-------|-------|--------|
| CharacterGen | 17.570 | 0.644 | 0.205 |
| En3D | 19.244 | 0.751 | 0.174 |
| **AniGS** | **21.475** | **0.857** | **0.137** |

### Ablation Study

| Setup | Effect |
|------|------|
| No normal regularization | More surface noise |
| No anisotropy regularization | Needle-like artifacts in new poses |
| Random initialization vs. Coarse mesh initialization | Coarse mesh significantly better |
| Standard 3DGS vs. 4DGS | 4DGS is clearer (handles inconsistency) |

### Key Findings
- **Using 4DGS to handle inconsistency is crucial**: PSNR improves from ~19 with standard 3DGS to 21.5 with 4DGS.
- **In-the-wild video pre-training > purely synthetic**: Results in better generalization quality for real human portraits.
- **10-minute end-to-end processing** (5 mins generation + 5 mins optimization), supporting real-time rendering.

## Highlights & Insights
- **The conceptual shift of "inconsistency $\rightarrow$ temporal variation $\rightarrow$ 4DGS" is highly elegant**—it does not attempt to eliminate inconsistencies, but instead embraces them and absorbs them using a deformation field.
- **Joint RGB + normal generation** provides a free geometric prior for 3D reconstruction.

## Limitations & Future Work
- Details on hands and feet are still insufficient (limited finger accuracy of SMPL-X).
- CogVideo generation occasionally produces significant inconsistencies (e.g., changes in clothing color).
- Animation quality is constrained by the expressive capability of SMPL-X skinning.

## Related Work & Insights
- **vs. CharacterGen**: Reconstructing inconsistent multi-views using standard 3DGS leads to blurriness. The 4DGS approach of AniGS improves PSNR by 4 dB.
- **vs. En3D**: Requires SDS optimization taking over 30 minutes, whereas AniGS only takes 10 minutes.
