# DA-Mamba: Learning Domain-Aware State Space Model for Global-Local Alignment in Domain Adaptive Object Detection

**Conference**: CVPR2026
**arXiv**: [2603.18757](https://arxiv.org/abs/2603.18757)
**Code**: To be confirmed
**Area**: Object Detection
**Keywords**: Domain adaptive object detection, state space model, Mamba, global-local alignment, feature alignment, CNN-SSM hybrid architecture

## TL;DR

This paper proposes DA-Mamba, a CNN-SSM hybrid architecture that achieves image-level and instance-level global-local domain-invariant feature alignment with linear complexity via two modules—Image-Aware SSM (IA-SSM) and Object-Aware SSM (OA-SSM)—attaining state-of-the-art performance on four domain adaptive detection benchmarks.

## Background & Motivation

**Domain Adaptive Object Detection (DAOD)** aims to transfer a detector trained on a labeled source domain to an unlabeled target domain, with the core challenge being the learning of domain-invariant feature representations.

**CNN locality bottleneck**: Existing CNN-based DAOD methods are limited by the local connectivity of convolutions—backbones extract features only within sliding windows, and detection heads cannot model spatial/semantic dependencies across all instances, restricting both region-to-region and object-to-object alignment to local regions.

**Transformer complexity**: Prior work has introduced Vision Transformers to capture global dependencies, but the quadratic complexity of self-attention incurs substantial computational and memory overhead; convolutional attention variants either rely on globally shared parameters (ignoring domain bias) or still carry implicit quadratic complexity.

**Neglected inter-instance spatial-semantic relationships**: Objects exhibit stable co-occurrence patterns (e.g., rider and bicycle) and hierarchical semantic associations (e.g., cat/dog as animals); ignoring these global dependencies weakens domain alignment.

**Opportunity from Mamba/SSM**: State space models (SSMs) offer linear-time long-range dependency modeling, providing an efficient means to inject global domain information into CNN-based detectors.

**Need for joint global-local alignment**: Neither purely local nor purely global alignment suffices; multi-granularity global-local feature alignment is required simultaneously at both the image level and instance level.

## Method

### Overall Architecture

DA-Mamba is a CNN-SSM hybrid architecture built upon the YOLO-World detector. Input images pass through ResBlocks to extract low-level features $C_3$, which enter the FPN downsampling pipeline: IA-SSM is inserted at each resolution to extract global domain information. After the FPN outputs multi-scale features $P_3/P_4/P_5$, OA-SSM is inserted at each layer of the detection head to model instance-level dependencies. The overall framework adopts adversarial training (GRL + domain discriminator) for domain alignment.

### Key Designs

**Image-Aware SSM (IA-SSM)**:

- Inserted into the backbone FPN, employing a **dual-stream pipeline**: a convolutional stream extracts local domain-invariant features, while an SSM stream captures global visual attributes.
- Introduces a learnable **image-level visual prompt** $\mathbf{v}^I \in \mathbb{R}^C$, broadcast to all spatial positions and concatenated with input features to inject domain information into both streams.
- Adopts a bottleneck structure (reduction ratio $r$) to reduce redundancy; the dual-stream outputs are concatenated and upsampled to restore the original dimension.

**Object-Aware SSM (OA-SSM)**:

- Inserted into the detection head, likewise employing a dual-stream pipeline, but designed with **pixel-level instance visual prompts** $\mathbf{v}^O \in \mathbb{R}^{B,C,H,W}$.
- Maps input features to a per-pixel class similarity matrix $\mathbf{W} \in \mathbb{R}^{B,H,W,K}$ via convolutional layers, which is multiplied with **class prototypes** $\mathbf{E} \in \mathbb{R}^{K,C}$ generated by a CLIP text encoder to produce instance-level prompts, partitioning the feature map into semantically consistent instance regions.
- Enables global modeling of spatial co-occurrence and semantic hierarchical relationships across all instances.

### Loss & Training

$$\mathcal{L} = \mathcal{L}_{cls}^S + \mathcal{L}_{cls}^T + \lambda^I \mathcal{L}_{adv}^I + \lambda^O \mathcal{L}_{adv}^O + \mathcal{L}_{reg}$$

- **Image-level adversarial loss** $\mathcal{L}_{adv}^I$: IA-SSM outputs are fed into a domain discriminator with GRL to render image-level features domain-indistinguishable.
- **Instance-level adversarial loss** $\mathcal{L}_{adv}^O$: OA-SSM outputs are fed into a domain discriminator with an instance mask (foreground regions with classification probability > 0.5), focusing on inter-instance relationships.
- Source domain: cross-entropy classification loss + regression loss; target domain: classification loss on high-confidence pseudo-labels.
- Hyperparameters: $r=2.0, \lambda^I=1.0, \lambda^O=0.5$.

## Key Experimental Results

### Main Results

**Cross-Weather (Cityscapes → Foggy Cityscapes)**:

| Method | mAP | Note |
|--------|-----|------|
| DA-Pro (NeurIPS'23) | 55.9 | Prev. SOTA |
| DT (CVPR'25) | 55.4 | — |
| DATR (TIP'24) | 53.4 | Transformer-based |
| Baseline (UDA) | 52.3 | — |
| **DA-Mamba** | **58.1** | **+2.2 vs SOTA, +5.8 vs baseline** |
| Oracle | 61.1 | Upper bound |

**Cross-FoV (Cityscapes → BDD100K)**: DA-Mamba achieves 48.7% mAP, surpassing Prev. SOTA DATR by 5.4%.

**Cross-Style (Pascal VOC → Clipart)**: DA-Mamba achieves 52.5% mAP, surpassing Prev. SOTA CAT by 3.4%, only 1.3% below Oracle.

**Cross-Style (Pascal VOC → Comic)**: DA-Mamba achieves 43.8% mAP, surpassing Prev. SOTA D-adapt by 3.3%.

### Key Findings

- **Vanilla Mamba vs. DA-Mamba**: Directly replacing with vanilla Mamba yields only 1.0–2.9% improvement, whereas DA-Mamba achieves 5.7–6.8%. The gap arises because standard Mamba employs a domain-agnostic state update strategy that cannot effectively align features under large domain distribution shifts.
- **High computational efficiency**: DA-Mamba requires only 148G FLOPs (53.1% of the Transformer-based DATR), achieves 14.1 FPS, and consumes only 1307M inference memory (40.8% of DATR), while outperforming it by 4.7% mAP.
- **Both the dual-stream pipeline and visual prompts are indispensable**: The convolutional stream provides local priors, the SSM stream provides global awareness, and visual prompts inject domain/class context; all three components are necessary to achieve optimal performance.
- **IA-SSM is more effective on higher-level features** ($C_5$: +2.0% vs. $C_3$: +1.5%), as higher-level features carry richer semantic information.

## Highlights & Insights

- First work to introduce Mamba/SSM into domain adaptive object detection, replacing Transformer quadratic complexity with linear complexity for global modeling.
- The dual-module design (IA-SSM + OA-SSM) handles image-level and instance-level alignment separately in an orthogonal and complementary manner, yielding joint improvements of 5.7–6.8%.
- The design of generating pixel-level semantic prompts via CLIP class prototypes in OA-SSM is elegant, incorporating VLM knowledge into the detection head with minimal overhead.
- The computational cost is minimal (comparable to a pure CNN baseline), yet performance surpasses both Transformer-based and VLM-based methods.
- Achieves comprehensive state-of-the-art across four benchmarks, with particularly significant gains in cross-FoV and cross-style scenarios.

## Limitations & Future Work

- Validated only on the single-stage detector YOLO-World; generalizability to two-stage detectors (e.g., Faster R-CNN) or DETR-based architectures remains unverified.
- Class prototypes rely on the CLIP text encoder, potentially limiting effectiveness for fine-grained categories not well covered by CLIP.
- The target domain uses only pseudo-labels for semi-supervised learning; pseudo-label quality directly impacts instance mask generation in OA-SSM.
- Experiments are conducted at a small scale (batch size=2, single V100 GPU); scalability to large-scale datasets and multi-GPU settings is unknown.
- Ablation of insertion positions covers only FPN layers; compatibility with different backbones (e.g., ResNet-50/101) is not explored.
- The effect of scan direction selection (Mamba's serialization strategy) on 2D image features is not analyzed in depth.
- No comparison with improved SSM variants such as Mamba-2.

## Related Work & Insights

- **Feature alignment series**: DA-Faster → SWDA → SIGMA++ → CAT → REACT, progressively refining alignment granularity from image-level to category-level to instance-level.
- **Semi-supervised learning series**: AT, TDD, and others reduce domain bias via pseudo-labels or style transfer, complementing feature alignment methods.
- **Transformer-based DAOD**: DATR and MTM leverage self-attention for global dependencies, but quadratic complexity leads to high computational cost (DATR: 279G FLOPs).
- **VLM-based DAOD**: DA-Pro and DA-Ada exploit semantic priors from vision-language models for domain semantic alignment, but at substantial inference overhead.
- **SSM/Mamba in vision**: VMamba (image classification), U-Mamba (medical segmentation); this work is the first to extend SSMs to DAOD.

## Rating

- Novelty: ⭐⭐⭐⭐ — First work to introduce SSMs into DAOD; the IA-SSM/OA-SSM designs are principled and well-targeted.
- Experimental Thoroughness: ⭐⭐⭐⭐ — Four benchmarks, detailed ablations (modules/pipelines/prompts/insertion positions/computational cost); validation on two-stage detectors is absent.
