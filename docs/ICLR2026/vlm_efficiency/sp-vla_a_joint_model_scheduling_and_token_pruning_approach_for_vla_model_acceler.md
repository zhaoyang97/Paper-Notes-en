# SP-VLA: A Joint Model Scheduling and Token Pruning Approach for VLA Model Acceleration

**Conference**: ICLR 2026  
**OpenReview**: [https://openreview.net/forum?id=RwdGIIjPlC](https://openreview.net/forum?id=RwdGIIjPlC)  
**Code**: https://github.com/ChildTang/SP-VLA  
**Area**: VLM Efficiency / Embodied AI / Model Acceleration  
**Keywords**: VLA Acceleration, Model Scheduling, Token Pruning, Embodied Reasoning, Temporal Redundancy

## TL;DR
SP-VLA categorizes VLA action sequences into "deliberative" and "intuitive" types. Deliberative types invoke the large model, while intuitive types are approximated by lightweight Ridge Regression. Simultaneously, spatial-semantic dual-perceptive token pruning is applied, achieving 1.5× lossless acceleration on LIBERO and 2.4× acceleration on SimplerEnv.

## Background & Motivation

**Background**: Vision-Language-Action (VLA) models unify visual perception, language understanding, and action generation, becoming a core paradigm for robot manipulation and embodied AI. Representative works such as DeepMind's RT series, OpenVLA, CogACT, and $\pi_0$ have demonstrated strong generalization across diverse robotic tasks. However, mainstream VLA models are massive—Google RT-X series exceeds 55 billion parameters, and even "lightweight" options like OpenVLA reach 7 billion—leading to severe inference latency that restricts deployment in real-time control scenarios (robotic arm manipulation, autonomous navigation, industrial assembly) which often require control frequencies of 10-30 Hz.

**Limitations of Prior Work**: Existing VLA acceleration methods (quantization, caching, early-exit mechanisms, etc.) almost entirely follow compression strategies designed for VLMs, optimizing VLA as if it were simply a "VLM that outputs actions." These methods focus only on single-step computational redundancy and ignore the intrinsic characteristics of VLA operating in sequential decision-making environments. Specifically, there is significant **temporal redundancy** between continuous action frames (adjacent actions are often highly similar) and substantial **spatial redundancy** in the visual input (large background regions are irrelevant to the current task).

**Key Challenge**: VLA acceleration faces challenges across two orthogonal dimensions that lack specialized solutions: ① The temporal dimension—how to utilize historical action information to reduce repeated large model invocations; ② The spatial dimension—how to prune redundant visual tokens while maintaining spatial position awareness. Existing methods do not provide targeted designs for these points.

**Goal**: To eliminate both temporal and spatial redundancy in VLA inference simultaneously, achieving a training-free, plug-and-play end-to-end acceleration.

**Key Insight**: The authors draw inspiration from human motor patterns—humans engage in deep thinking only at key nodes (grasping, turning) while executing other transitional actions via "intuition" (a phenomenon well-studied in cognitive science). By analyzing the velocity curves of robotic arms in 50 pick-and-place experiments, the authors observed that action sequences generated by VLA models also exhibit a four-stage pattern (target alignment → grasping → moving → placing). High-speed transition phases can be approximated by linear functions, whereas low-speed fine manipulation phases require the complex reasoning capabilities of the large model.

**Core Idea**: Categorize VLA action sequences by velocity into deliberative and intuitive types. The former utilizes the large model, while the latter employs a lightweight Ridge Regression proxy. Before entering the large model, spatial-semantic dual-perceptive pruning reduces the token count. Together, these mechanisms achieve frequency-adaptive acceleration.

## Method

### Overall Architecture

At each timestep, SP-VLA first determines the current action type and then decides which inference path to invoke. The framework consists of two parallel mechanisms: **Action-aware Model Scheduling** on the left to handle temporal redundancy, and **Spatial-Semantic Dual-Perceptive Token Pruning** on the right to handle spatial redundancy. Intuitive actions are directly output by a lightweight generator, bypassing the large model; deliberative actions enter the VLA but undergo token pruning before being fed into the LLM backbone.

```mermaid

    A["Environment Feedback + Hist. Action Buffer"] --> B["Action Type Judgment<br/>Velocity Threshold + Buffer Ratio"]
    B -->|Intuitive (High Speed)| C["Lightweight Ridge Regression Generator<br/>Linear Prediction + Validity Check"]
    B -->|Deliberative (Low Speed/Fine)| D["Spatial-Semantic Token Pruning<br/>Canny Edge ∪ Accu. Attention"]
    D --> E["VLA LLM Backbone (7B+)<br/>Fine Action Generation"]
    C --> F["Action Execution → Update Buffer"]
    E --> F
```

### Key Designs

**1. Action-aware Model Scheduling: Distinguishing Deliberative and Intuitive via Velocity Signals**

Existing VLA methods invoke the large model for every action step. However, actions in many timesteps (especially during high-speed transitional phases) can be numerically approximated by linear functions, making 7B parameter inference unnecessary. SP-VLA defines velocity thresholds $v_{min}$ and $v_{max}$. When all components of the end-effector satisfy $|a_i| > v_{min}$, it is classified as an intuitive action. This triggers the lightweight generator provided the ratio of VLA-generated actions in the buffer $N_G/N_A > \tau$. The trigger condition is formalized as:
$$\text{LWM} = \begin{cases} 1 & \text{if } a_{t-1} \in [v_{min}, v_{max}] \text{ and } N_G/N_A > \tau \\ 0 & \text{otherwise} \end{cases}$$
Intuitive actions are fitted using Ridge Regression on the action buffer $S_A = \{a_{t-n}, \ldots, a_{t-1}\}$. The parameter matrix $\beta^*$ is obtained by minimizing the L2-regularized linear regression loss $J(\beta) = \|X\beta - Y\|^2 + \lambda\|\beta\|^2$, yielding $\beta^* = (X^T X + \lambda I)^{-1} X^T Y$, which predicts the current action $a_t = x_t \beta^*$. The ingenuity of this design lies in the fact that the lightweight generator only operates within a window where the large model has "recently generated enough actions," ensuring directional calibration—intuitive execution is essentially a linear extrapolation in the direction of the large model's last invocation, rather than unconstrained drifting.

**2. Spatial-Semantic Dual-Perceptive Token Pruning: Joint Retention via Canny Edges + Cumulative Attention**

Token pruning methods in the VLM field (e.g., FastV, VisionZip) rely solely on semantic importance (cumulative attention scores). However, experiments show that VLA is extremely sensitive to **relative positions** and **object contours**. Rearranging tokens after sorting by attention scores alone leads to immediate task failure; retaining only semantically important tokens while discarding edge tokens also causes crashes. This indicates that VLA's spatial localization capability depends on the presence of contour tokens. Therefore, this paper defines the retained set as the **order-preserving union** of semantic and spatial tokens: the semantic set $T_{se}$ is filtered by cumulative attention $\text{AccuAttn} = \frac{1}{N}(e^T \otimes I_M)\text{vec}(\text{Attn})$ thresholds; the spatial set $T_{sp}$ is extracted via the Canny operator for contour tokens; the final $T_{select} = \mathcal{U}(T_{se}, T_{sp})$ maintains the original token order. Furthermore, the pruning ratio is dynamically adjusted based on velocity (pruning more at high speeds and disabling pruning during low-speed fine manipulation), creating a synergy where fewer tokens enter the large model during phases closer to the intuitive threshold.

**3. Synergy of the Mechanisms**

Ablation studies reveal the complementary relationship between the two mechanisms. Removing model scheduling alone decreases the average success rate by approximately 3.4% (LIBERO). Removing Canny spatial tokens alone causes the success rate to plummet from 74.9% to 23.9%. Removing pruning while retaining scheduling still yields a 1.35× speedup. This demonstrates that scheduling primarily contributes to the speedup ratio, while Canny tokens are a prerequisite for pruning to function effectively; neither is independently replaceable.

### Loss & Training

SP-VLA requires no retraining and is applied as an inference-stage plugin to existing VLA models (the paper uses CogACT and OpenVLA as baselines). Ridge Regression parameters are fitted online at each inference step (analytical solution, no backpropagation), incurring minimal computational overhead (<1K parameters). Velocity thresholds and buffer parameters $v_{min}, v_{max}, \tau$ are hyperparameters tuned manually across benchmarks. The velocity-aware retention rate $T_r(v)$ for token pruning retains all tokens at low speeds ($v < v_{pmin}$) and linearly decays to a minimum retention ratio at high speeds, forming a unified design language with the scheduling mechanism's velocity thresholds.

## Key Experimental Results

**Experimental Setup**: CogACT (SimplerEnv) and OpenVLA (LIBERO) serve as base models. All results are run on NVIDIA A100 (40GB), averaged over three random seeds. SimplerEnv includes Google-VM, Google-VA, and Bridge-VM settings to evaluate robustness against changes in color, material, lighting, and camera pose.

**LIBERO** (130 tasks, 2000 trajectories, OpenVLA as baseline):
- Lossless Acceleration: **1.35×** (Success rate 74.9% vs. baseline 74.6%)
- Speed Mode: **1.5×** acceleration with <3% success rate drop.
- Comparison: SparseVLM achieves 1.33× but with a slight decline; PruMerge fails completely on VLA (0% success rate).

**SimplerEnv** (CogACT as baseline):
- Average Acceleration: **2.4×** (vs. 1.93× for EfficientVLA), average success rate 75.05% is **higher** than the CogACT baseline of 74.8%.
- FLOPs reduced to 38.15%; inference frequency increased by **2.2×**, latency improved by **2.2×**.
- Outperformed all comparison baselines in subtasks such as PickCan, MoveNear, and Drawer.

**Real Robot** (Franka Research 3, Pick-and-Place tasks):
- End-to-end acceleration of **2.5×** with only a **1%** drop in success rate.
- 150 trajectories collected via the GELLO kit for fine-tuning, deployed in real physical environments to verify robustness.

**Ablation Highlights**: Removing Canny spatial tokens dropped the LIBERO success rate from 74.9% to 23.9%, validating the criticality of contour tokens for VLA spatial perception. Removing scheduling while retaining pruning reduced the speedup ratio to 1.21×, showing the two mechanisms are mutually reinforcing.

## Related Work & Insights

**VLA Acceleration**: DeeR-VLA introduces early-exit mechanisms to reduce LLM layer computation; QAIL integrates quantization into imitation learning fine-tuning; VLA-Cache caches background tokens to avoid repeated computation; PD-VLA/VLA-OFT introduce parallel decoding; Fast (Pertsch et al.) compresses actions by converting them to the frequency domain. These methods focus on VLM structural optimization and ignore the VLA-specific attribute that "action sequences have temporal dependencies." SP-VLA is the first VLA acceleration framework to model both temporal and spatial redundancy simultaneously.

**VLM Token Pruning**: Methods like SparseVLM, FastV, VisionZip, and PruMerge are effective for pure VLM tasks, but experiments show they either collapse in performance (PruMerge success rate drops to 0%) or offer limited speedup when migrated to VLA. The fundamental reason is the neglect of VLA's strong dependence on spatial token ordering—the direct motivation for the Canny spatial-perceptive pruning. Notably, FastV and SparseVLM performance improved significantly after incorporating Canny spatial tokens (+S) and relative position preservation (+R), indirectly validating the sensitivity analysis of VLA tokens.

**Action Categorization**: The "dual-system" theory in human motor cognition (Kahneman System 1/System 2) and the division of procedural/declarative memory in motor learning provide a cognitive science foundation for the intuitive/deliberative action dichotomy. Adapting this idea to VLA scheduling is one of the core innovations of this paper.

## Limitations & Future Work

Ridge Regression can only fit local linear segments and may underfit highly non-linear operations (e.g., complex grasping pose adjustments). Velocity thresholds for intuitive/deliberative switching require manual tuning for different tasks, and their generalizability remains to be verified. Additionally, the Canny operator may falsely extract contours in low-contrast or uneven lighting scenarios, affecting token selection quality. Current experiments are based on CogACT and OpenVLA; whether the approach migrates seamlessly to other architectures like $\pi_0$ or RT-2 (especially those with diffusion action heads) requires further validation. Future directions include learning-based adaptive thresholds, extending scheduling to multi-arm/dexterous manipulation, and exploring the introduction of scheduling-awareness during on-policy fine-tuning to further improve the fitting quality of the lightweight generator.

## Personal Thoughts

The core insight of SP-VLA is to truly utilize the "sequential decision-making" characteristic of VLA inference—not through single-frame compression, but through cross-frame scheduling. Methodologically, this opens a new dimension: VLA acceleration can stem not only from model structural optimization but also from **task-aware scheduling strategies**. While Ridge Regression is a relatively simple approximator for intuitive actions, it achieves a good engineering balance between being lightweight, interpretable, and capable of online updates.

More importantly, the discovery of VLA's sensitivity to spatial token ordering via dual-perceptive pruning—where simply rearranging token order leads to task failure—reveals a fundamental difference between VLA and VLM inference mechanisms. While VLMs focus on semantics, VLAs also rely on token positional topology for spatial reasoning. This conclusion is highly valuable for any future work attempting to migrate VLM token compression techniques to robotic control scenarios and suggests that future VLA architectures should consider explicitly introducing robustness for spatial position encoding.
