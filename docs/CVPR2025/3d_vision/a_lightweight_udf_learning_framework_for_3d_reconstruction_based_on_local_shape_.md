# A Lightweight UDF Learning Framework for 3D Reconstruction Based on Local Shape Functions

**Conference**: CVPR 2025  
**arXiv**: [2407.01330](https://arxiv.org/abs/2407.01330)  
**Code**: [https://jbhu67.github.io/LoSF-UDF.github.io/](https://jbhu67.github.io/LoSF-UDF.github.io/)  
**Area**: 3D Vision  
**Keywords**: Unsigned Distance Field (UDF), Point Cloud Reconstruction, Local Shape Functions, Lightweight Networks, Surface Reconstruction

## TL;DR
This paper proposes LoSF-UDF, a lightweight framework for learning Unsigned Distance Fields (UDFs) based on local shape functions. Trained only once on synthetic local point cloud patches (653KB parameters, 0.5GB data), it generalizes to reconstruct various types of 3D surfaces and exhibits robustness against noise and outliers.

## Background & Motivation
3D surface reconstruction is a core problem in computer vision and computer graphics. Signed Distance Fields (SDFs) and Occupancy Fields can only reconstruct watertight geometries, failing to handle open surfaces and non-manifold structures. Unsigned Distance Fields (UDFs), which lack a concept of inside/outside, can theoretically represent geometries of arbitrary topology and have received increasing attention in recent years.

However, existing UDF learning methods face two major bottlenecks: 1) Unsupervised methods (e.g., CAP-UDF, LevelSetUDF) require per-point-cloud iterative optimization, taking up to 15 minutes of training per shape; 2) Supervised methods (e.g., GeoUDF) rely on large-scale 3D shape datasets for training, meaning their generalization capability is limited by the training data distribution, and the data preparation cost is high (e.g., ShapeNet requires 120GB).

The core insight of this work is elegant: UDF is a local quantity that does not rely on global context. Within a local region, 3D shapes exhibit simple mathematical patterns—smooth regions can be approximated by quadric surfaces, and sharp features can be constructed using simple functions. Therefore, the network can be trained on local patches generated by mathematical functions, achieving generalization to various global shapes with a single training session.

## Method

### Overall Architecture
The pipeline of LoSF-UDF is divided into two stages: 1) training the UDF prediction network on a synthetic dataset of local patches; 2) for an arbitrary input point cloud, extracting a local patch around each query point, predicting the UDF values using the trained network, and finally extracting the mesh using DCUDF.

### Key Designs

1. **Local Shape Functions**:

    - **Smooth patches**: Based on differential geometry, the local geometry of any point on a regular surface can be approximated by a quadric surface: $z = \frac{1}{2}(\kappa_1 x^2 + \kappa_2 y^2)$, where $\kappa_1, \kappa_2$ are the principal curvatures. By adjusting the principal curvatures, four basic local geometries can be generated: elliptic, hyperbolic, parabolic, and planar.
    - **Sharp patches**: For non-differentiable points (creases, tips, corners, V-saddles), a unified functional form is designed: $z = 1 - h \cdot g(x,y)$, where $h$ controls the sharpness and $g$ represents different functions selected according to the feature type.
    - $m$ points are sampled within a circle of radius $r_0$ to generate a patch, and query points are sampled along the normal direction of the origin to calculate their ground-truth UDF values.
    - The entire training set requires only 0.5GB of storage, which is far smaller than GeoUDF's 120GB.

2. **Attention-based UDF Prediction Network**:

    - **Point-Net**: Extracts geometric features $\mathbf{f}_p$ of the local patch $\mathcal{P}$ using 4 ResNet blocks.
    - **Vectors-Net**: Extracts distance-related features $\mathbf{f}_v$ from the set of vectors from the query point to each patch point $\mathcal{V} = \{\mathbf{p}_i - \mathbf{q}\}$.
    - **Cross-Attention Module**: Uses patch features as Key-Value and vector features as Query, fusing the geometric features $\mathbf{f}_G$ most relevant to UDF estimation via cross-attention.
    - Concatenates the distance vector $\mathbf{d}$ and $\mathbf{f}_G$, which then pass through fully connected layers to output the UDF value, using softplus activation to ensure non-negativity.
    - The entire network has only 653KB of trainable parameters.

3. **Denoising Module**:

    - For noisy point clouds, directly calculated distance vectors will contain errors.
    - A lightweight module is designed to predict a distance correction $\Delta\mathbf{d}$, which is added to the original distance to improve the accuracy of UDF estimation.
    - L1 sparsity regularization is applied to constrain the correction.

4. **Integration with Unsupervised Methods**:

    - LoSF-UDF can serve as an initialization for unsupervised methods such as CAP-UDF and LevelSetUDF.
    - An integration loss function is designed with a time-decaying weight $\alpha_t$ that gradually decreases from 1 to 0.
    - It relies on LoSF for a reasonable initialization in the early stage and is refined by unsupervised losses in the later stage.

### Loss & Training
- UDF prediction loss: $\mathcal{L}_u = |\mathcal{U}(\mathbf{q}) - \mathcal{U}_\Theta(\mathbf{q})|$ (L1 loss)
- Denoising regularization: $\mathcal{L}_r = |\Delta\mathbf{d}|$
- Total loss: $\mathcal{L} = \mathcal{L}_u + \lambda_d \mathcal{L}_r$, where $\lambda_d = 0.01$
- Data augmentation: Random rotation, 20% of smooth patches randomly truncated to simulate open boundaries, and 30% of data augmented with Gaussian noise $\mathcal{N}(0, 0.1)$.
- During evaluation, point clouds are normalized to the $[-0.5, 0.5]$ bounding box, and local patches within radius $r=0.018$ are extracted.

## Key Experimental Results

### Main Results

| Dataset | Metric | LoSF-UDF | CAP-UDF | LevelSetUDF | GeoUDF | DUDF |
|--------|------|----------|---------|-------------|--------|------|
| ShapeNetCars (Clean) | CD↓ | **0.611** | 1.324 | 1.223 | 0.832 | 0.773 |
| ShapeNetCars (Noise) | CD↓ | **0.614** | 1.208 | 1.176 | 1.869 | 1.939 |
| ShapeNetCars (Outliers) | CD↓ | **0.705** | 2.918 | 2.763 | 2.598 | 2.949 |
| DeepFashion3D (Clean) | CD↓ | 0.548 | 0.885 | 0.881 | 0.625 | **0.506** |
| DeepFashion3D (Outliers) | CD↓ | **0.559** | 5.150 | 5.083 | 3.883 | 2.558 |
| Real ScanData | CD↓ | **1.551** | 2.101 | 1.637 | 1.762 | 4.207 |

### Ablation Study

| Configuration | CD | Description |
|------|-----|------|
| Without Points-Net and Cross-Attn | Higher | Fails to learn local geometric features |
| Without Cross-Attn | Medium | Lacks geometric-distance feature fusion |
| Full Model | Lowest | Cross-attention effectively fuses features |
| Without denoising module (noisy input) | High | Rough surface |
| With denoising module (noisy input) | Low | Smooth and stable surface |

### Efficiency Comparison

| Method | SRB Time (min) | Params | Storage (KB) |
|------|-------------|--------|----------|
| LoSF-UDF | 0.87 | 167K | **653** |
| GeoUDF | 0.08 | 253K | 990 |
| CAP-UDF | 15.87 | 463K | 1809 |
| LevelSetUDF | 15.08 | 463K | 1809 |
| LoSF+CAP-UDF | **6.84** | - | - |

### Key Findings
- Under noise and outlier conditions, the advantage of LoSF-UDF is most prominent—its CD metric is 3-4 times lower than the second-best method.
- When integrated with unsupervised methods, the convergence speed increases by 2-3 times (e.g., CAP-UDF drops from 15.87 minutes to 6.84 minutes).
- With only 653KB of parameters, it can achieve or even surpass methods requiring 120GB of training data.

## Highlights & Insights
- The core idea is extremely simple: UDF is a local quantity that can be trained using data generated by mathematical functions. This insight is built on a solid theoretical foundation of differential geometry.
- The "train once, apply everywhere" paradigm breaks the reliance of existing UDF methods on large-scale 3D datasets.
- The lightweight design is pushed to the extreme: 653KB parameters + 0.5GB training data, yet the performance is comparable to or even better than methods trained on hundreds of gigabytes of data.
- Its design as an initialization module is highly practical, acting as a plug-and-play accelerant for existing unsupervised methods.
- The design of the denoising module is clever—instead of denoising the point cloud, it corrects the distance vector with minimal computational cost.

## Limitations & Future Work
- Purely local methods cannot handle completion of large missing areas (which is the advantage of global methods).
- While the inference speed (0.87 minutes/model) is faster than unsupervised methods, it is an order of magnitude slower than GeoUDF (0.08 minutes).
- The choice of local patch radius $r$ needs to be adjusted according to the point cloud density. Although the authors provide a bias analysis method, human intervention is still required.
- Point cloud density is required to be at least 30 points/unit area, requiring additional upsampling preprocessing for extremely sparse point clouds.
- The function designs for sharp features are still limited to the four handcrafted types, which may miss some complex non-smooth geometries.

## Related Work & Insights
- The multi-scale Partition of Unity framework proposed by Ohtake et al. in 2003 inspired the idea of local surface reconstruction.
- GeoUDF was the first to learn UDF from a local perspective but trained on ShapeNet; this work further simplifies the training data to patches generated by mathematical functions.
- CAP-UDF and LevelSetUDF are representative unsupervised UDF methods; this work integrates with them as initialization to achieve complementarity.
- As the SOTA method for extracting meshes from UDFs, DCUDF is adopted by all methods to ensure a fair comparison.

## Rating
- Novelty: ⭐⭐⭐⭐⭐ The approach of synthesizing local patches with mathematical functions to train UDFs is novel and theoretically grounded.
- Experimental Thoroughness: ⭐⭐⭐⭐ Extensive coverage with multi-dataset, multi-metric comparisons, ablation studies, and integration experiments.
