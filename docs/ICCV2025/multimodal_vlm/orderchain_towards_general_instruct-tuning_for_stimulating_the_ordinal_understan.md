# OrderChain: Towards General Instruct-Tuning for Stimulating the Ordinal Understanding Ability of MLLM

## Meta Information
- **Conference**: ICCV 2025
- **arXiv**: [2504.04801](https://arxiv.org/abs/2504.04801)
- **Code**: [Project Page](https://order-chain.github.io/)
- **Area**: Multimodal VLM
- **Keywords**: Ordinal Regression, Multimodal Large Language Models, Chain-of-Thought, Progressive Reasoning, Unified Model

## TL;DR

This paper proposes OrderChain, a prompting paradigm that enhances the ordinal understanding capability of multimodal large language models (MLLMs) via task-aware prompts and a Range-Optimized Chain-of-Thought (RO-CoT), achieving for the first time a unified ordinal regression model across diverse tasks.

## Background & Motivation

Ordinal regression (OR) categorizes instances into ordered classes and is critical in tasks such as facial age estimation, image aesthetic assessment, and disease grading. Existing approaches face two fundamental challenges:

**Traditional methods require task-specific training**: Mainstream ordinal regression methods (ordinal distribution learning, instance comparison, CLIP-based approaches) remain effective but still require independently trained models per task due to varying category counts and ranges across tasks.

**MLLMs exhibit poor ordinal understanding**: Systematic evaluation reveals that LLaVA performs substantially worse than conventional SOTA methods on multiple ordinal regression benchmarks, under both zero-shot and LoRA fine-tuning settings. The primary reasons are: (1) lack of specificity modeling — domain knowledge and category boundary priors are neglected; and (2) lack of commonality modeling — the intrinsic ordering among categories, which is the essential shared structure of ordinal regression, is not captured.

## Method

### Overall Architecture

OrderChain comprises three core components: Task-aware Prompts, Range-Optimized Chain-of-Thought (RO-CoT), and the Category Recursive Division (CRD) method.

### Range-Optimized Chain-of-Thought (RO-CoT)

Exploiting the continuous and ordered nature of ordinal regression categories, RO-CoT adopts a coarse-to-fine paradigm for progressive prediction. The four-step pipeline is as follows:

1. **Format and set template**: Reformulate the original query into a general ordinal regression task template.
2. **Generate task definition as domain knowledge prompt**: The MLLM performs a preliminary identification of the task and generates its definition and reasoning strategy.
3. **Iterative loop**: At each step, CRD generates a finer candidate subset → task-aware prompts instruct the MLLM to select a subset → a termination condition is checked.
4. **Return final prediction**: The loop terminates when the candidate subset contains only a single category.

### Category Recursive Division (CRD)

CRD automatically partitions all candidate categories into progressively smaller subsets using a $k$-ary balanced tree:

$$T = \log_k(N_{init})$$

At step $i$, the maximum number of categories in each sub-candidate set is:

$$N_i = \frac{N_{init}}{k^i} + 1$$

The $j$-th candidate set at step $i$ is defined as $c_{i,j} = \{s_j, s_j+1, \ldots, \min(N_{init}, s_j + N_i - 1)\}$, with starting index $s_j = (j-1) \times N_i + 1$.

A binary tree is used for tasks with fewer categories (e.g., 5-class aesthetic assessment), while a ternary tree is applied to tasks with many categories (e.g., 80-class age estimation) to reduce CoT length.

### Task-Aware Prompts

**Category feature prompts** consist of two parts:
- **Description prompts**: Encode the range and quantity of categories, overcoming the fixed-dimension limitation of fully connected layers in conventional models.
- **Instruction prompts**: Specify the candidate categories to be refined at the current step, generated automatically by CRD.

**Domain knowledge prompts**: Generated by the MLLM itself as prior domain knowledge, serving as a preliminary task identification to guide subsequent predictions.

## Experiments

### Facial Age Estimation (Adience Dataset)

| Method | Accuracy (%) ↑ | MAE ↓ |
|--------|---------------|-------|
| OrdinalCLIP | 61.2 | 0.47 |
| Ord2Seq | 63.9 | 0.43 |
| L2RCLIP | 66.2 | 0.36 |
| LLaVA-1.5 (zero-shot) | 17.6 | 1.48 |
| LLaVA-1.5 (baseline) | 47.5 | 0.59 |
| **LLaVA-1.5 + OrderChain** | **93.2** | **0.12** |

### Diabetic Retinopathy Grading (DR Dataset)

| Method | Accuracy (%) ↑ | MAE ↓ |
|--------|---------------|-------|
| POE | 80.5 | 0.30 |
| Ord2Seq | 84.2 | 0.25 |
| LLaVA-1.5 (zero-shot) | 3.9 | 12.1 |
| LLaVA-1.5 (baseline) | 30.0 | 0.99 |
| **LLaVA-1.5 + OrderChain** | **85.7** | **0.23** |

### Historical Color Image Dating (HCI Dataset)

| Method | Accuracy (%) ↑ | MAE ↓ |
|--------|---------------|-------|
| NumCLIP | 69.6 | 0.35 |
| LLaVA-1.5 (baseline) | 61.4 | 0.50 |
| **LLaVA-1.5 + OrderChain** | **73.0** | **0.32** |

### Key Findings

1. **Milestone improvement on age estimation**: Accuracy of 93.2% surpasses the previous SOTA (L2RCLIP, 66.2%) by approximately 27 percentage points, with MAE reduced from 0.36 to 0.12.
2. **Robustness to imbalanced data**: On the severely imbalanced DR dataset, OrderChain effectively alleviates class imbalance through the balanced partitioning strategy of CRD.
3. **Difficulty with subjective labels**: Performance is relatively weaker on image aesthetic assessment, particularly for the "People" category — attributed to a positivity bias in MLLM pretraining toward human subjects.
4. **Ablation validation**: Domain knowledge prompts contribute +10.5% accuracy; category feature prompts yield a further +20%; RO-CoT ultimately brings accuracy to 93.2%.

## Highlights & Insights

1. **First exploration of ordinal regression with MLLMs**: Systematically reveals the deficiencies of MLLMs in ordinal understanding and provides an effective solution.
2. **Commonality–specificity modeling perspective**: CRD models the shared structure across all OR tasks (ordered categories), while task-aware prompts capture task-specific characteristics.
3. **Plug-and-play design**: Enhances existing MLLMs purely through prompt engineering without any modification to model architecture.
4. **Remarkable performance gain**: The leap from 47.5% to 93.2% on age estimation demonstrates the critical role of chain-of-thought reasoning in ordinal understanding.

## Limitations & Future Work

1. Performance is limited on tasks with subjective labels (e.g., aesthetic assessment), as pretraining biases in MLLMs are difficult to eliminate.
2. The branching factor $k$ of CRD must be manually selected based on the task.
3. Multi-step CoT inference introduces additional latency, making the approach unsuitable for real-time applications.
