# MacVQA: Adaptive Memory Allocation and Global Noise Filtering for Continual Visual Question Answering

**Conference**: AAAI 2026
**arXiv**: [2601.01926](https://arxiv.org/abs/2601.01926)  
**Code**: [https://github.com/HubuKG/MacVQA](https://github.com/HubuKG/MacVQA)  
**Area**: Multimodal VLM
**Keywords**: Continual Learning, Visual Question Answering, Noise Filtering, Memory Allocation, Prototype Learning

## TL;DR

This paper proposes MacVQA, a framework that enhances the robustness of visual features via Global Noise Filtering (GonF) and optimizes cross-task knowledge retention and update via Adaptive Memory Allocation (AMA) based on prototype retrieval and memory decay. MacVQA achieves 43.38% average accuracy (+3.57%) and 2.32% forgetting rate across 10 continual learning tasks on VQA v2.

## Background & Motivation

### State of the Field
Visual Question Answering (VQA) integrates visual and textual information to answer questions about images, with broad applications in autonomous driving, medical diagnosis, and accessibility assistance. Continual Learning for VQA has attracted growing attention, aiming to enable models to acquire new tasks while retaining previously learned knowledge, addressing the demands of continuously evolving environments and dynamic tasks.

### Limitations of Prior Work
Existing continual VQA learning methods suffer from several limitations:

**Regularization-based methods** (EWC, MAS): Preserve knowledge by protecting critical parameters, but struggle with modality conflicts in multimodal architectures and lack fine-grained interaction modeling.

**Replay-based methods** (ER, DER): Mitigate forgetting through sample replay, but are constrained by storage overhead and privacy concerns.

**Recent VQA-specific methods** each have their own shortcomings:
   - **VQACL**: Evaluates unseen skill–concept combinations but exhibits poor adaptability to dynamic tasks.
   - **PROOF**: Uses extensible projections but with limited scalability.
   - **QUAD**: Eliminates visual storage via alignment consistency distillation but is insufficiently robust to noisy features.
   - **ProtoGroup**: Stabilizes representations via multi-prototype grouping but incurs high computational cost and sensitivity to clustering parameters.

**Common deficiency**: Lack of attention to multimodal feature quality (noisy visual regions interfere with reasoning); low memory management efficiency, failing to balance retention, adaptation, and generalization.

### Core Idea
The problem is addressed from two complementary perspectives:
- **Feature side**: Eliminates irrelevant visual regions through global noise filtering to enhance the robustness of multimodal features.
- **Memory side**: Efficiently manages cross-task knowledge through adaptive memory allocation based on prototype retrieval and temporal decay strategies.

## Method

### Overall Architecture
MacVQA builds upon the VL-T5 backbone and comprises three core modules:
1. **Global Noise Filtering (GonF)**: Scoring → Weighting → Denoising Autoencoder → Global feature fusion, improving visual feature quality.
2. **Memory Pool**: Stores visual and textual prototypes as dynamic references.
3. **Adaptive Memory Allocation (AMA)**: Prototype retrieval → Gated fusion → Temporal interpolation update, optimizing knowledge acquisition and retention.

### Key Designs

#### 1. **Global Noise Filtering (GonF)**

GonF aims to eliminate noise and irrelevant region features from visual representations.

**Feature Extraction**:
- Visual features: A pretrained Faster R-CNN extracts $n$ region features $\mathbf{V} \in \mathbb{R}^{n \times d}$ ($d=2048$).
- Textual features: The input query is encoded into embeddings $\mathbf{Q} \in \mathbb{R}^{L \times d}$.

**Three-step Noise Filtering**:

**Step 1 – Feature Scoring**: Attention weights are assigned to each image region via linear transformation followed by softmax:

$$\omega_m = \frac{\exp(\text{score}(\mathbf{V}_m))}{\sum_{l=1}^{n} \exp(\text{score}(\mathbf{V}_l))}$$

**Step 2 – Global Feature Generation**: A global context vector is generated by weighted summation:

$$\mathbf{G} = \sum_{m=1}^{n} \omega_m \cdot \mathbf{V}_m$$

**Step 3 – Denoising + Fusion**: A Denoising Autoencoder (DAE) refines $\mathbf{V}$ into denoised features $\mathbf{V}'$, which are then fused with the global feature $\mathbf{G}$ to produce the final enhanced feature $\mathbf{V}''$.

**GonF Loss**: Reconstruction accuracy + attention distribution smoothness:

$$\mathcal{L}_{\text{GonF}} = \frac{1}{n} \sum_{m=1}^{n} \left( \|\mathbf{V}_m - \mathbf{V}'_m\|_2^2 - \theta_1 \omega_m \log \omega_m \right)$$

$\theta_1$ controls the trade-off between denoising precision and attention distribution smoothness (typically in $[0.1, 0.5]$).

**Design Motivation**: Not all image regions are relevant in VQA (e.g., when asked "what color is the car?", the background sky and trees constitute noise). GonF first scores regions globally to identify salient areas, then applies DAE denoising, and finally uses global information to complement local perspectives — forming a three-stage scoring → denoising → fusion pipeline.

#### 2. **Adaptive Memory Allocation (AMA)**

AMA maintains a memory pool containing a visual prototype set $\{\mathbf{V}_m\}$ and a textual prototype set $\{\mathbf{Q}_n\}$.

**Prototype Retrieval**:
- The multimodally fused hidden state $\mathbf{H}$ is projected into visual and textual subspaces.
- Top-$k$ most similar visual and textual prototypes are retrieved from the memory pool via cosine similarity:

$$\text{sim}(\mathbf{H}_v, \mathbf{V}_m) = \frac{\mathbf{H}_v \cdot \mathbf{V}_m}{\|\mathbf{H}_v\| \cdot \|\mathbf{V}_m\|}$$

**Gated Fusion**: A dynamic weight vector $\mathbf{g}$ controls the fusion ratio between the current input and retrieved prototypes:

$$\mathbf{g} = \sigma(\mathbf{W}_g \cdot [\mathbf{H}; \mathbf{Q}_p; \mathbf{V}_p])$$

The final fused feature is: $\mathbf{H}' = \mathbf{H} + \bm{\alpha} \cdot \mathbf{Q}_p + \bm{\beta} \cdot \mathbf{V}_p$

**Memory Update (Temporal Interpolation Strategy)**:

$$\mathbf{P}_i = \lambda \cdot \mathbf{P}_{i-1} + (1-\lambda) \cdot \mathbf{H}$$

$\lambda$ controls the balance between old memories and new context, enabling progressive knowledge accumulation.

**AMA Loss**:

$$\mathcal{L}_{\text{AMA}} = -\sum_{m=1}^{k} \text{sim}(\mathbf{H}_v, \mathbf{V}_{p_m}) - \sum_{n=1}^{k} \text{sim}(\mathbf{H}_q, \mathbf{Q}_{p_n}) + \theta_2(g_q + g_v - 1)^2 + \theta_3 \|\mathbf{H}' - \mathbf{H}\|_2^2$$

This comprises four terms: similarity maximization + gating balance regularization + update magnitude constraint.

**Design Motivation**: Traditional memory replay passively "replays old samples," whereas AMA actively "retrieves relevant knowledge and dynamically fuses it." The temporal interpolation strategy enables the memory pool to smoothly evolve with the task stream, balancing both retention and adaptation.

### Loss & Training

Total loss:

$$\mathcal{L}_{total} = \phi_1 \mathcal{L}_{\text{GonF}} + \phi_2 \mathcal{L}_{\text{AMA}} + \phi_3 \mathcal{L}_{\text{decoder}}$$

where $\phi_1 + \phi_2 + \phi_3 = 1$. The decoder loss is standard negative log-likelihood.

Training configuration:
- Backbone: VL-T5 (shared across all methods)
- Optimizer: Adam, learning rate 3e-5, gradient clipping 5
- Memory buffer size: 5000 (configurable)
- Two evaluation paradigms: standard testing (seen skill–concept combinations) and novel composition testing (unseen combinations)

## Key Experimental Results

### Main Results

**VQA v2 Standard Test (average accuracy/forgetting rate across 10 tasks)**:

| Method | AP(%) ↑ | AF(%) ↓ | Notes |
|--------|---------|---------|-------|
| Vanilla | 14.49 | 30.15 | Catastrophic forgetting |
| EWC | 15.77 | 28.38 | Regularization |
| ER | 36.99 | 4.80 | Experience replay |
| VQACL | 38.77 | 2.90 | VQA-specific |
| ProtoGroup | 39.81 | 2.87 | Multi-prototype grouping |
| **MacVQA** | **43.38** | **2.32** | GonF+AMA |

**Novel Composition Test**:

| Method | AP(%) ↑ | AF(%) ↓ |
|--------|---------|---------|
| VQACL | 35.40 | 4.90 |
| QUAD | 40.00 | 3.81 |
| **MacVQA** | **42.53** | **3.60** |

MacVQA outperforms the best baseline by +3.57% in accuracy and reduces forgetting by −0.55% on the standard test, with notable improvements across multiple task types: e.g., Color task 56.95% (vs. ProtoGroup 44.66%), Action task 58.13% (vs. 50.79%).

### Ablation Study

**Contribution of GonF and AMA modules**:

| GonF | AMA | AP(%) | AF(%) | Notes |
|------|-----|-------|-------|-------|
| × | × | 38.77 | 2.90 | Baseline (VQACL) |
| ✓ | × | 41.75 | 2.14 | Noise filtering reduces forgetting |
| × | ✓ | 40.97 | 2.34 | Memory allocation improves accuracy |
| ✓ | ✓ | **43.38** | **2.32** | Complementary synergy |

**Prototype Selection Strategy**:

| Strategy | Std. AP | Std. AF | Novel AP |
|----------|---------|---------|---------|
| Random | 40.29 | 3.46 | 41.25 |
| **Max-Similarity** | **43.38** | **2.32** | **42.53** |

Max-Similarity significantly outperforms random selection, validating the importance of similarity-based prototype retrieval.

### Key Findings

1. **Complementarity of GonF and AMA**: GonF excels at perception-oriented tasks (Recognition, Location), while AMA benefits memory-sensitive reasoning tasks (Color, Type). GonF's early-stage noise filtering prevents error propagation, and AMA's prototype-priority selection supports long-term memory retention.
2. **Memory buffer size sensitivity**: MacVQA consistently achieves the highest AP and lowest AF across all buffer sizes, indicating efficient memory utilization — simply storing more does not suffice.
3. **Hyperparameter sensitivity**: Vision-dominant tasks (Recognition, Location) perform best at $\alpha=1.0, \beta=0.4$; text-dominant tasks (Commonsense, Judge) perform best at $\alpha=0.4, \beta=1.0$ — confirming the necessity of modality-adaptive weighting.
4. **Qualitative analysis**: MacVQA correctly answers object–reasoning combinations unseen during training in novel composition tests (e.g., handling unseen teddy bear categories in Location tasks).

## Highlights & Insights

1. **Clarity of problem formulation**: Continual VQA is improved along two orthogonal dimensions — feature quality and memory management — each addressed by a dedicated module, resulting in a clean design.
2. **GonF's three-stage pipeline** (scoring → denoising → global fusion), while not individually novel in its components, is applied to the continual learning setting for the first time as a whole, yielding significant improvements.
3. **AMA's gated fusion + temporal interpolation update** constitutes a concise and practical memory management scheme: gating determines "how much to use," while temporal interpolation determines "how to update."
4. **The two evaluation paradigms** (standard + novel composition) comprehensively assess both retention and generalization capabilities of the model.
5. Hyperparameter analysis reveals the association between task type and optimal modality weights, providing a basis for adaptive strategies in practical applications.

## Limitations & Future Work

- Faster R-CNN as the visual feature extractor is relatively outdated; whether more modern encoders such as ViT or CLIP could be substituted remains unexplored.
- The task sequence of 10 tasks is fixed; the impact of different task orderings on results is not analyzed.
- The memory pool size (number of prototypes $M$, $N$) appears to be predefined; adaptive adjustment may be preferable.
- All methods share the VL-T5 backbone — performance on stronger backbones (e.g., BLIP-2, LLaVA) is unknown.
- The framework cannot handle online continual learning scenarios where task boundaries are unknown.

## Related Work & Insights

- The skill–concept combination testing paradigm introduced by VQACL serves as the standard evaluation protocol for continual VQA.
- The multi-prototype grouping idea in ProtoGroup is conceptually related to MacVQA's prototype memory pool, but MacVQA's gated fusion + temporal decay mechanism is more flexible.
- GonF's DAE denoising can be viewed as a form of data augmentation in feature space, complementary to knowledge distillation in continual learning.
- The trend of combining prototype learning with continual learning is growing — MacVQA represents yet another successful instance.
