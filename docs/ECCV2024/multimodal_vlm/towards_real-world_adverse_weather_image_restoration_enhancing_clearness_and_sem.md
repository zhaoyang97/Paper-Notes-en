# Towards Real-World Adverse Weather Image Restoration: Enhancing Clearness and Semantics with Vision-Language Models

**Conference**: ECCV 2024  
**arXiv**: [2409.02101](https://arxiv.org/abs/2409.02101)  
**Code**: [GitHub](https://github.com/jiaqixuac/WResVLM)  
**Area**: Multimodal VLM / Image Restoration  
**Keywords**: Adverse weather image restoration, vision-language model, semi-supervised learning, pseudo-labels, weather prompt learning

## TL;DR
This paper proposes WResVLM, a semi-supervised learning framework that utilizes vision-language models (VLMs) to provide clearness evaluation and semantic description supervision signals for real-world adverse weather images. It enhances clearness via VLM image evaluation coupled with weather prompt learning, and enhances semantics via description-aided semantic regularization. This approach comprehensively outperforms existing methods on real-world deraining, dehazing, and desnowing tasks.

## Background & Motivation

Adverse weather (rain, fog, snow) severely degrades the performance of outdoor vision systems. Existing image restoration methods are predominantly designed for a single type of weather. Recently, All-in-One methods (e.g., TransWeather, WeatherDiff) have attempted to address multiple weather conditions using a single model.

**Limitations of Prior Work**:

**Domain Gap Issue**: Existing methods are mainly trained on synthetic datasets, leading to severely insufficient generalization capabilities when applied to real-world scenarios. A significant distribution discrepancy exists between synthetic data and real-world weather degradation.

**Semantic Deficiency**: Existing methods primarily focus on restoring visual clearness while ignoring the semantic context of the scene. Consequently, the restored results offer limited help to downstream high-level vision tasks (e.g., detection, segmentation).

**Key Challenge**: Real-world adverse weather images lack corresponding clean ground-truth images, making direct supervised learning unfeasible. The core challenge is how to leverage unlabeled real-world data to train restoration models.

**Key Insight**: Leverage the capabilities of large-scale vision-language models (VLMs). Having been trained on massive weather-related images, VLMs possess the ability to evaluate image clearness and understand scene semantics. Thus, VLMs can be used to provide pseudo-supervision signals for real-world data, enabling the construction of a semi-supervised learning framework.

## Method

### Overall Architecture
WResVLM is a semi-supervised learning framework that trains an All-in-One image restoration model using both labeled synthetic data and unlabeled real-world data. The core of the framework consists of two VLM-enhanced modules: (1) **Clearness Enhancement**—selecting pseudo-labels via VLM image evaluation + modulating the restoration process through weather prompt learning; (2) **Semantic Enhancement**—providing semantic regularization via descriptions generated by the VLM. MSBDN is adopted as the backbone network.

### Key Designs

1. **VLM Image Evaluation and Pseudo-Label Generation**:

    - **Function**: Leverage the zero-shot capability of VLMs to evaluate the weather visibility quality of restored images and select optimal pseudo-labels.
    - **Mechanism**: Design weather-related image quality QA templates to prompt the VLM to score the images. Using a five-level MOS score (excellent-good-fair-poor-bad), the logits of the five rating tokens from the VLM are converted into a numerical score using softmax: $r^{vlm} = \sum_{i=1}^{5} i \times p_i$
    - **Design Motivation**: Existing image quality assessment methods (e.g., NIMA, MUSIQ) primarily target technical distortions (noise, blur) rather than weather-related visibility degradation. Having seen a vast number of weather images, VLMs can assess weather degradation more accurately.
    - **Pseudo-Label Update**: During training, the model's prediction is continuously compared against the current pseudo-label using VLM scores. If the prediction is superior, the pseudo-label database is updated.

2. **Weather Prompt Learning**:

    - **Function**: Learn weather condition representations in the CLIP space to guide the restoration model to generate clearer images.
    - **Mechanism**: Divided into two stages—(a) Prompt embedding learning: freeze CLIP parameters, learn four weather prompt vectors $\{t_c, t_r, t_h, t_s\}$ (clear/rainy/hazy/snowy), and optimize them via cross-entropy classification loss; (b) Restoration model optimization: maximize the cosine similarity between the restored image embedding and the "clear" weather prompt.
    - **Loss Function**: $\mathcal{L}_{wpl} = \frac{e^{cos(\mathcal{E}_I(\hat{y}), \mathcal{E}_T(t_c))}}{\sum_{t} e^{cos(\mathcal{E}_I(\hat{y}), \mathcal{E}_T(t))}}$
    - **Supplementary Regularization**: Utilizing only the weather prompt loss may introduce noisy artifacts. Therefore, an additional feature similarity loss $\mathcal{L}_{feat}$ (using Depth Anything to extract features) is introduced to align the features of the prediction with the pseudo-label/input.

3. **Description-Aided Semantic Enhancement**:

    - **Function**: Utilize VLMs to generate scene descriptions of weather images, providing semantic regularization by modifying the weather description while keeping the semantic content intact.
    - **Mechanism**: Use LLaVA to generate a *negative caption* containing weather descriptions for the input image (e.g., "A person is walking in heavy rain..."), and then use an LLM to convert it into a *positive caption* ("The weather looks good. A person is walking..."). The two descriptions share identical scene content but differ in weather conditions.
    - **Loss Function**: $\mathcal{L}_{sem} = \frac{e^{cos(\mathcal{E}_I(\hat{y}), \mathcal{E}_T(d_{pos}))}}{\sum_{d} e^{cos(\mathcal{E}_I(\hat{y}), \mathcal{E}_T(d))}}$, encouraging the alignment of the restored image with the "good weather" description.
    - **Design Motivation**: Unlike general weather prompts, these descriptions are specific to each individual image, thereby providing image-level semantic supervision.

4. **Training Strategy**:

    - **Function**: Pseudo-label initialization + iterative updates.
    - **Pseudo-Label Initialization**: Outputs from several existing weather-specific and All-in-One restoration methods are collected, and multiple VLM experts vote to select the best pseudo-label.
    - **Iterative Updates**: Training is conducted in multiple rounds (empirically set to 4 rounds). Each round uses a VLM for online evaluation, and between rounds, all VLMs are used to re-evaluate and update the pseudo-labels, weather prompts, and descriptions.

### Loss & Training
The total loss is a weighted combination of five terms:
$$\mathcal{L} = \mathcal{L}_{sup} + w_1 \mathcal{L}_{ps} + w_2 \mathcal{L}_{wpl} + w_3 \mathcal{L}_{sem} + w_4 \mathcal{L}_{feat}$$
Weights are configured as: $w_1=0.5, w_2=0.2, w_3=0.05, w_4=0.2$

Here, $\mathcal{L}_{sup}$ is the supervised appearance loss on synthetic data, $\mathcal{L}_{ps}$ is the pseudo-label loss ($L_1$), $\mathcal{L}_{wpl}$ represents the weather prompt learning loss, $\mathcal{L}_{sem}$ denotes the semantic regularization loss, and $\mathcal{L}_{feat}$ signifies the feature similarity loss.

### Key Findings
- VLM image evaluation ($r^{vlm}$) is the largest source of improvement, boosting MUSIQ from 54.08 to 56.68 (+2.60).
- Every component contributes positively, showing synergistic effects.
- In user studies, WResVLM outperforms all compared methods in both visibility and image quality dimensions.
- Using VLM evaluation to select pseudo-labels outperforms traditional quality assessment metrics such as NIMA, MUSIQ, and CLIP-IQA.
- Semantic regularization helps the model capture subtle weather context variations (e.g., transforming "foggy" to "overcast").

## Highlights & Insights
- This work is the first to systematically introduce VLMs into the field of adverse weather image restoration, serving both clearness evaluation and semantic guidance.
- The design of weather prompt learning is elegant—leveraging CLIP's built-in weather concept knowledge while learning only lightweight prompt vectors.
- Distilling high-level VLM semantic capabilities into low-level image restoration represents an intriguing cross-level capability transfer.
- The multi-VLM expert voting mechanism mitigates the bias issue of a single VLM.
- The negative-to-positive description conversion strategy (maintaining scene semantics while altering weather states) is cleverly designed.

## Limitations & Future Work
- The computational cost of using large VLMs for online evaluation remains high.
- The scale of real-world data collection is limited (around 2,000–2,400 images per weather condition), which may affect the generalization ability of the method.
- The backbone network, MSBDN, is relatively outdated; employing stronger backbones could potentially yield bigger improvements.
- The model only handles three weather conditions (rain, fog, and snow), omitting other adverse conditions such as dust storms and low-light environments.
- The evaluation relies entirely on no-reference metrics, lacking end-to-end validation on downstream real-world tasks (e.g., detection, segmentation).

## Related Work & Insights
- This work complements PromptIR (degradation condition prompting) and DA-CLIP (degradation info contrastive learning)—while the former integrates prompts inside the model, this work leverages VLMs at the training signal level.
- It relates to low-level vision applications of VLMs like CLIP-IQA and Q-Bench, but expands the application of VLMs to pseudo-supervision generation during the training stage.
- **Insight**: VLMs can act as a general "quality judge" and "semantic bridge," helping to resolve low-level vision tasks that lack labeled data.

## Rating
- Novelty: ⭐⭐⭐⭐ Multi-dimensionally incorporating VLMs into a semi-supervised weather restoration framework is highly innovative.
- Experimental Thoroughness: ⭐⭐⭐⭐ The ablation studies are comprehensive and systematic, but downstream task validation is missing.
