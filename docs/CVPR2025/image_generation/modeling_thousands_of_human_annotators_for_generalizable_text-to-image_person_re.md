# Modeling Thousands of Human Annotators for Generalizable Text-to-Image Person Re-identification

**Conference**: CVPR 2025  
**arXiv**: [2503.09962](https://arxiv.org/abs/2503.09962)  
**Code**: [https://github.com/sssaury/HAM](https://github.com/sssaury/HAM)  
**Area**: Autonomous Driving / Person Re-identification  
**Keywords**: Text-to-Image Person Re-identification, Human Annotator Modeling, Description Style Diversity, Prompt Learning, Large-scale Dataset Construction

## TL;DR
This paper proposes the Human Annotator Modeling (HAM) method. By extracting and clustering style features from human-annotated descriptions, it utilizes learnable prompts to enable MLLMs to simulate thousands of human annotation styles. Combined with Uniform Prototype Sampling (UPS) to further enhance style diversity, HAM automatically constructs a large-scale, high-quality text-image person ReID dataset, significantly improving the generalization ability of ReID models across multiple benchmarks.

## Background & Motivation

**Background**: Text-to-Image Person Re-identification (ReID) aims to retrieve target pedestrians from an image repository using textual descriptions. The core bottleneck of this task lies in the extremely high annotation cost of large-scale datasets, which limits the scale of existing manually annotated datasets and leads to insufficient model generalization capability.

**Limitations of Prior Work**: To address the annotation cost problem, recent works utilize MLLMs to automatically generate pedestrian descriptions. However, texts generated by MLLMs suffer from severe style homogenization—syntactic structures and vocabulary preferences tend to converge. Existing diversity-enhancement methods rely on manually designed description templates (e.g., 46 or 456 templates), but these templates only cover limited sentence structure variations and ignore style differences at the vocabulary level (e.g., the stylistic difference between "shoulder-length black hair" and "black hair").

**Key Challenge**: The description styles of human annotators are naturally diverse (different people have different description preferences for the same pedestrian), whereas the outputs of MLLMs are homogeneous. Template-based methods are heuristic, limited, and unable to learn vocabulary styles, making it fundamentally impossible to match the diversity of human annotations.

**Goal**: How to enable MLLMs to learn and simulate thousands of different human description styles to generate truly diverse pedestrian descriptions, thereby constructing high-quality, large-scale ReID datasets.

**Key Insight**: The authors observe that while the specific annotator for each description is unknown, "style features" can be extracted from the description texts. Then, description groups with similar styles can be identified through clustering, where each group represents an annotation preference. Prompt learning can then be used to let MLLMs learn the style of each group.

**Core Idea**: Utilizing style feature clustering combined with learnable prompts to achieve large-scale modeling of human annotation styles by MLLMs, replacing heuristic template-based methods.

## Method

### Overall Architecture
The overall method consists of three stages: (1) Extracting style features from existing human-annotated data and grouping descriptions with similar styles using clustering; (2) Training a learnable style prompt for each group to enable the MLLM to generate descriptions according to different styles; (3) Automatically generating diverse descriptions for a large-scale pedestrian image database using the trained MLLM to construct the HAM-PEDES dataset, which is used to train a more generalizable ReID model.

### Key Designs

1. **Style Feature Extraction and Clustering**:

    - **Function**: Extract "style" representations from human-annotated text that are independent of the specific pedestrian identity.
    - **Mechanism**: First, an LLM (Qwen2.5-7B) is used to replace pedestrian attribute words (e.g., clothing color, hairstyle) in the descriptions with vague general terms to eliminate identity information and retain only the description style. The processed text is then fed into a CLIP text encoder, which outputs the style features. Finally, KMeans clustering is performed on all style features to obtain $K_1$ clusters, with each cluster representing a description preference.
    - **Design Motivation**: Directly clustering the original descriptions is biased by the pedestrian's appearance content. Clustering after replacing attribute words can truly capture "how to say" rather than "what to say". This decoupling approach captures more complete style information (including syntax and vocabulary) than manual templates.

2. **Prompt Learning-based Annotator Modeling (HAM)**:

    - **Function**: Enable MLLMs to simulate description styles corresponding to different clusters.
    - **Mechanism**: Assign a learnable prompt vector $\mathbf{P}_i \in \mathbb{R}^{M \times D}$ ($M=10$ tokens) to each style cluster, and concatenate it with image tokens and text instruction tokens before feeding them into the LLM component of the MLLM. During training, the LLM and vision encoder are frozen, and only the $K_1$ prompt vectors and the vision-language projector are optimized using standard autoregressive loss. Each training sample only updates its corresponding cluster's prompt. During inference, a style prompt is randomly selected to generate a description in that style.
    - **Design Motivation**: Prompt learning has extremely few parameters, which preserves the original capabilities of the MLLM while learning a large number of styles at low cost. Freezing the main parameters avoids overfitting, while fine-tuning the projector helps better integrate style prompts.

3. **Uniform Prototype Sampling (UPS)**:

    - **Function**: Compensate for the non-uniform distribution of KMeans cluster centers to capture a broader range of styles.
    - **Mechanism**: Define a style feature space with a range of $[\boldsymbol{\mu}_s - \beta \boldsymbol{\sigma}_s, \boldsymbol{\mu}_s + \beta \boldsymbol{\sigma}_s]$ ($\beta=7$), uniformly and randomly sample $K_2$ vectors in this space as new cluster centers, and then assign the nearest $Q=200$ samples to each center. A sample can belong to multiple clusters or none at all. Finally, merge the $K_1$ clusters from KMeans and the $K_2$ clusters from UPS, resulting in $K_1 + K_2$ style prompts.
    - **Design Motivation**: Traditional clustering methods like KMeans and DBSCAN concentrate their centers in dense regions of samples, whereas UPS is independent of sample density and can cover style features in sparse regions, complementing KMeans.

### Loss & Training
Standard autoregressive cross-entropy loss is used to train the style prompts: $\mathcal{L}_{\text{HAM}} = -\mathbb{E}[\sum_m \log p(\mathbf{y}_{i,m} | \mathbf{x}_i, \mathbf{P}_{s_i}, \mathbf{y}_{i,<m})]$. The ReID model is trained using the SDM (Similarity Distribution Matching) loss.

## Key Experimental Results

### Main Results

| Pre-training Dataset | Data Volume | CUHK-PEDES R1 | ICFG-PEDES R1 | RSTPReid R1 |
|---|---|---|---|---|
| None | - | 12.65 | 6.67 | 13.45 |
| SYNTH-PEDES | 1.0M | 57.58 | 57.08 | 42.69 |
| LuPerson-MLLM | 1.0M | 57.61 | 38.36 | 51.50 |
| **HAM-PEDES (Ours)** | **0.1M** | **60.74** | **50.96** | **49.80** |
| **HAM-PEDES (Ours)** | **1.0M** | **70.15** | **59.63** | **58.85** |

Under the direct transfer setting, using only 0.1M data outperforms competing datasets of 1.0M scale; at the 1.0M scale, the CUHK-PEDES R1 reaches 70.15%, which is 12.54% higher than LuPerson-MLLM.

### Ablation Study

| Configuration | CUHK-PEDES R1 | ICFG-PEDES R1 | RSTPReid R1 |
|---|---|---|---|
| Static Description (No template) | 36.60 | 21.38 | 39.75 |
| Dynamic Description (46 templates) | 39.73 | 23.51 | 39.95 |
| Projector Fine-tuning + 6.8K templates | 42.99 | 24.59 | 38.55 |
| HAM+KMeans ($K_1=1000$) | 52.19 | 28.26 | 44.65 |
| HAM+UPS ($K_2=1000$) | 54.53 | 30.57 | 45.40 |
| HAM+KMeans+UPS (1000 each) | **55.34** | **31.89** | **46.05** |

### Key Findings
- HAM+KMeans achieves a 9.2% improvement on CUHK-PEDES R1 compared to the pure template-based method (Projector Fine-tuning + 6.8K templates), indicating that learning styles is significantly superior to manual templates.
- UPS alone performs better than KMeans (+2.34% on CUHK-PEDES) because it covers style features in sparse regions.
- Combining KMeans and UPS yields the best performance, confirming their complementarity. DBSCAN performs the worst as it is density-sensitive and thus unfriendly to sparse style features.
- By learning styles only on CUHK-PEDES, the generated diverse descriptions can generalize to ICFG-PEDES and RSTPReid.

## Highlights & Insights
- **Paradigm Shift from "Templates to Learning"**: While prior works increased diversity by designing more templates, this work uses prompt learning to directly learn styles from data, thoroughly breaking through the bottleneck of template quantity. This "data-driven instead of heuristic" concept can be transferred to other generation scenarios requiring diversity.
- **Clever Style Decoupling Design**: Replacing attribute words with LLM to separate identity and style information is simple yet highly effective. This decoupling concept can be applied to any scenario requiring the extraction of non-content features from annotated texts.
- **UPS Improvement on Clustering**: The idea of uniformly sampling prototypes after defining a feature space is simple and elegant, solving the common issue of distribution shift in traditional cluster centers, and can be extended to other tasks requiring uniform coverage of feature spaces.

## Limitations & Future Work
- Style learning relies on existing human-annotated datasets (CUHK-PEDES). If the annotators of the initial dataset are not diverse enough, the range of learned styles may also be limited.
- The method is only validated in the pedestrian ReID scenario; its generalizability to other image description tasks (such as general image captioning) has not been verified.
- Whether the learned styles can be transferred across different MLLMs has not been explored.
- During inference, the style prompt is randomly selected rather than adaptively chosen to match the input image.

## Related Work & Insights
- **vs LuPerson-MLLM**: LuPerson-MLLM uses 46 manual templates to enhance diversity, whereas this work replaces them with thousands of learned style prompts, substantially improving both diversity and quality.
- **vs SYNTH-PEDES**: SYNTH-PEDES uses attribute recognition and template filling to generate descriptions, which is constrained by the templates' syntax and cannot learn vocabulary-level style.
- **vs General MLLM Diversity Enhancement Methods**: Existing methods (such as character-driven or retrieval augmentation) focus on content diversity, while this work focuses on style diversity under the same semantic content, providing a novel perspective.
