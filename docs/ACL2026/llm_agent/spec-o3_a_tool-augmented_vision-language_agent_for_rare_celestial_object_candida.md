# Spec-o3: A Tool-Augmented Vision-Language Agent for Rare Celestial Object Candidate Identification

**Conference**: ACL 2026  
**arXiv**: [2601.06498](https://arxiv.org/abs/2601.06498)  
**Code**: [Project HomePage](https://github.com/jiaminghui/Spec-o3)  
**Area**: LLM Agent  
**Keywords**: Tool-augmented agent, Interleaved Multimodal Chain-of-Thought, Spectral inspection, Reinforcement learning, Domain-specific VLM

## TL;DR

Ours proposes Spec-o3, a tool-augmented vision-language agent that simulates the spectral inspection workflow of astronomers through Interleaved Multimodal Chain-of-Thought (iMCoT). Using a two-stage training of cold-start SFT + outcome-based RL, it improves macro-F1 in rare celestial object identification from 28.3% to 76.5%, with inference speeds ~50x faster than manual inspection.

## Background & Motivation

**Background**: Modern spectral survey projects (LAMOST, SDSS, DESI) generate massive amounts of data. Constructing catalogs for rare celestial objects requires a two-stage process—deep learning algorithms for candidate screening, followed by expert visual inspection (vetting). The visual inspection stage still relies heavily on humans.

**Limitations of Prior Work**: (1) Deep learning classifiers produce opaque probability scores and exhibit poor out-of-distribution generalization, making it difficult to gain expert trust; (2) Posterior explanation methods (Grad-CAM, SHAP, etc.) produce coarse feature attributions that cannot be reliably mapped to astrophysical structures; (3) Manual inspection is unscalable—for instance, the LAMOST CV catalog required experts to visually inspect 170,000 candidates to confirm only 323 targets.

**Key Challenge**: The number of candidates in next-generation surveys will continue to surge, but the speed of manual inspection cannot increase synchronously, becoming a major bottleneck in astronomy.

**Goal**: Design a trustworthy and highly generalizable automated inspection agent that inspects spectra like an astronomer.

**Key Insight**: The astronomer's inspection process is essentially "thinking while looking at the spectrum"—observing global morphology first, then repeatedly zooming into wavelength regions of interest to check details, and finally making a judgment. Combining VLMs with spectral visualization tools simulates this iterative process.

**Core Idea**: Interleaved Multimodal Chain-of-Thought (iMCoT)—alternating between text reasoning and fine-grained spectral plots rendered by tools, coupled with two-stage post-training to achieve expert-level inspection capabilities.

## Method

### Overall Architecture

Built on Qwen2.5-VL, the model takes a text prompt $T_0$ (including discriminative queries and expert diagnostic guides) and an initial global spectral image $I_0$ as input. The agent performs text reasoning within `<think>...</think>`, generates zoomed views $I_{t+1}$ of local wavelength regions via tool calls, and alternates iterations until a final judgment is provided in `<answer>...</answer>`. The trajectory is formalized as $\tau = (T_0, I_0, T_1, I_1, T_2, I_2, \ldots, T_N)$.

### Key Designs

1.  **Interleaved Multimodal Chain-of-Thought (iMCoT)**: Defines state $s_t = \{I_{\leq t}, T_{\leq t}\}$. The agent autonomously decides at each step whether to output the answer directly or use the visualization tool $Tool_t$ to obtain finer-grained evidence. Tool input consists of a wavelength range $\Delta\lambda_t = (\lambda_t^{\min}, \lambda_t^{\max})$ and an optional diagnostic label $l_t$, returning a locally re-rendered plot. **Design Motivation**: To precisely simulate the "global judgment → local verification → final decision" workflow of astronomers, making the reasoning process auditable and physically consistent.

2.  **Cold Start SFT**: Sampled ~4k spectra (SNR > 10) from the official LAMOST catalog, covering 5 rare object types (CV, CS, SS, MG, WD). Initial reasoning trajectories were first generated by GPT-5 according to expert guides, followed by three rounds of astronomer review (initial screening → revision → final vote) to obtain ~1k high-quality expert trajectories. During training, a token-level loss mask is applied to tool-returned content to prevent the model from memorizing visualization results. **Design Motivation**: Use a small amount of high-quality expert demonstrations to inject domain priors and tool-use capabilities.

3.  **Agentic RL**: Uses the GRPO framework for outcome-based RL, utilizing only labeled data (without requiring full trajectories). The reward function is designed based on prediction correctness and format compliance: Correct + Correct Format $\to r=1$, Correct + Format Violation $\to r=1-\alpha$, Incorrect + Correct Format $\to r=0$, Incorrect + Format Violation $\to r=-\alpha$. **Design Motivation**: Performance after cold-start is limited by scarce expert trajectories; RL leverages more abundant labeled data to further optimize tool-use strategies.

### Loss & Training

Cold start uses standard SFT loss (with loss masking for tool-return tokens). RL uses GRPO (8 rollouts/problem, max 8 tool calls/trajectory). Two-stage serial training is performed with Qwen2.5-VL-3B/7B as base models on 8×H100 GPUs.

### Key Findings

- **Two-stage training is interdependent**: Pure RL or pure SFT only achieves ~35-41% F1, while the combination jumps to 73-76%—cold start provides domain priors, and RL optimizes tool-use strategies.
- **Tools are critical**: Removing the tool drops the 7B model F1 from 76.5% to 55.8%; static global views are insufficient for detecting subtle diagnostic features.
- **Cross-survey zero-shot generalization**: Maintains 77-81% F1 on SDSS/DESI, while expert DL models drop by 14-20%, indicating Spec-o3 relies on transferable diagnostic evidence rather than survey-specific artifacts.
- **Cross-task zero-shot generalization**: Reaches 76.4% F1 on unseen O/B/A type spectra (o3: 60.9%), confirming the learning of a general tool-assisted inspection paradigm.
- **Inference efficiency**: ~0.2s/sample (8×H100), which is ~50x faster than expert manual inspection.

## Highlights & Insights

- **The first application of the "think-with-image" paradigm to scientific data analysis**, generalizing from natural images to astronomical spectra, demonstrating the massive potential of tool-augmented VLMs in vertical domains.
- The data construction process is extremely rigorous: GPT-5 generation → Astronomer screening → Revision → Dual-person audit → Final vote, ensuring high quality of cold-start data.
- **High efficiency of cold-start data**: Reducing SFT data from ~1k to ~200 trajectories resulted in only minor performance drops (CV F1: 80.7→77.8).
- The RL stage does not require explicit tool-use rewards; tool-use becomes sufficiently reliable after the cold-start phase.

## Limitations & Future Work

- Evaluation focuses on a limited number of rare object types, not yet covering broader spectral sub-classes.
- Expert inspection is abstracted as a "zoom-reason" loop; actual catalog construction also requires cross-matching with external databases and other modalities.
- Cold-start still requires expert participation, with a non-negligible barrier to entry for new tasks or surveys (though synthetic data pipelines have shown the possibility of reducing this requirement).
- Production-oriented risk control mechanisms (e.g., calibration, abstention, triage) are not yet provided.
- F1 on the WD task is relatively low (53.6%), possibly because white dwarf spectral features are subtler and require more refined diagnostic strategies.

## Related Work & Insights

- **o3's think-with-image**: Spec-o3 extends this paradigm from general VQA to scientific data analysis, linking abstract diagnosis to visual evidence.
- **GRPO (DeepSeek-R1)**: Extends outcome-based RL from mathematical reasoning to scientific tool-use scenarios.
- **Insight**: The key to vertical domain VLMs is not larger models, but tool-use and reasoning paradigms aligned with domain workflows.
