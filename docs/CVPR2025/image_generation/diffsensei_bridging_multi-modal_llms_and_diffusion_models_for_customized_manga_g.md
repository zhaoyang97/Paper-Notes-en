# DiffSensei: Bridging Multi-Modal LLMs and Diffusion Models for Customized Manga Generation

**Conference**: CVPR 2025  
**arXiv**: [2412.07589](https://arxiv.org/abs/2412.07589)  
**Code**: [https://jianzongwu.github.io/projects/diffsensei/](https://jianzongwu.github.io/projects/diffsensei/) (project page)  
**Area**: Image Generation  
**Keywords**: Manga Generation, Diffusion Models, MLLM, Character Customization, MangaZero

## TL;DR
This paper introduces a new task, "Customized Manga Generation," and proposes the DiffSensei framework, which uses an MLLM as a text-compatible identity adapter to bridge diffusion models. By utilizing masked cross-attention for precise layout control, DiffSensei significantly outperforms existing methods on the self-constructed large-scale MangaZero dataset (43K pages / 427K annotated panels).

## Background & Motivation

**Background**: Story visualization (generating visual narratives from text) has made progress in recent years. However, manga generation remains an under-explored direction due to its unique requirements (cross-panel character consistency, precise layout control, and dialogue integration). Existing methods primarily focus on low-level image style transfer and cannot generate customized manga from scratch.

**Limitations of Prior Work**: (1) Zero-shot character customization schemes easily lead to "copy-paste" effects, lacking variation in character expressions and poses; (2) Existing story visualization datasets lack character annotations and layout control information; (3) Character images generated by diffusion models tend to rigidly follow the pixel distribution of the input character image, even when multiple states of the same character are observed in the training data.

**Key Challenge**: The need to maintain character identity consistency while enabling their expressions, poses, and actions to dynamically change based on panel text. Pure image condition injection struggles to achieve such flexible control.

**Goal**: Propose the customized manga generation task and construct a complete solution with a dataset + framework.

**Key Insight**: Leverage the text-understanding capability of MLLMs in image editing, utilizing the MLLM as a text-compatible adapter for character features. This allows character features to be adjusted based on text prompts before being fed into the diffusion model.

**Core Idea**: Instead of generating images directly, the MLLM adjusts character feature vectors to align them with the panel text. These features are then injected into the correct spatial locations of the diffusion model through masked cross-attention.

## Method

### Overall Architecture
DiffSensei consists of two core components: (1) A diffusion-based image generator, built on SD, which receives panel text and character features to generate manga panels; (2) An MLLM identity adapter, which receives character reference images and panel description texts, outputting character feature vectors adjusted in accordance with the text. Additionally, it includes layout control (masked attention) and dialogue embedding modules.

### Key Designs

1. **MLLM Character Adapter (Text-Compatible Identity Adapter)**:

    - **Function**: Dynamically adjusts character features based on panel text descriptions to achieve flexible variations in expressions, poses, and actions.
    - **Mechanism**: Extracts features from character reference images using a visual encoder and inputs them into the MLLM along with the panel description text. The MLLM's text comprehension capability allows it to understand "what state the character should present in this panel," outputting modified character feature vectors. These vectors are then injected into the diffusion model via cross-attention.
    - **Design Motivation**: Directly injecting character image features into the diffusion model leads to rigid pixel copying. Using the MLLM as an intermediate layer enables semantic-based feature adjustment.

2. **Masked Cross-Attention**:

    - **Function**: Precisely controls the spatial layout of multiple characters within a panel.
    - **Mechanism**: Defines visual masks for each character and restricts character features to affect only their corresponding spatial regions in the cross-attention layers of the diffusion model. Unlike direct pixel-level conditional injection, masked attention operates at the feature level, allowing the diffusion model to freely generate details within the constrained boundaries.
    - **Design Motivation**: Manga requires precise positioning of multiple characters; simple global condition injection cannot support multi-character scenarios.

3. **MangaZero Dataset**:

    - **Function**: Provides the first large-scale training dataset supporting multi-character, multi-state manga generation.
    - **Mechanism**: Collects Japanese black-and-white manga containing 43,264 pages and 427,147 annotated panels. Each panel is labeled with character IDs, character regions, panel descriptions, and dialogue text. The same character displays different expressions and poses across different panels.
    - **Design Motivation**: The lack of multi-character, multi-state annotated data is a bottleneck in this field.

### Loss & Training
Based on the standard denoising loss of diffusion models, combined with a character consistency loss to ensure that generated characters match the identity of the reference images. The MLLM component learns text-conditional adjustments during joint training.

## Key Experimental Results

### Main Results

| Method | Character Consistency | Text Adherence | Visual Quality |
|------|-----------|-----------|---------|
| DiffSensei | **Best** | **Best** | **Best** |
| IP-Adapter + ControlNet | Second Best | Moderate | Good |
| StoryDiffusion | Moderate | Moderate | Moderate |

### Key Findings
- The MLLM adapter effectively solves the "pixel copying" problem, enabling the generated character's expressions and poses to dynamically change according to the panel text.
- Masked attention successfully supports precise layout control of up to 4 characters simultaneously.
- The multi-state annotations in the MangaZero dataset are crucial for training character variation capabilities.
- The framework can be applied to mangafy real portrait photos.

## Highlights & Insights
- The design concept of using the MLLM as a "semantic regulator" rather than a generator is ingenious—it does not alter the diffusion model's generation process, but only modifies the input conditions.
- The construction of the MangaZero dataset serves as an important infrastructural contribution to advancing manga and story visualization research.
- The layout control mechanism of masked cross-attention can be transferred to other generation tasks requiring precise multi-entity control.

## Limitations & Future Work
- Only targeted at black-and-white Japanese manga style; compatibility with colored manga and other styles remains unverified.
- Character pose variations are still limited by the pose distribution in the training data.
- Control over the position and style of dialogue bubbles remains relatively coarse.

## Related Work & Insights
- **vs IP-Adapter**: Achieves character consistency via image prompt injection but lacks text-driven dynamic adjustment. DiffSensei's MLLM adapter adds semantic-level control.
- **vs StoryDiffusion**: Focuses on coherent image sequences but lacks character annotation and layout control. DiffSensei provides manga-specific precise control.
