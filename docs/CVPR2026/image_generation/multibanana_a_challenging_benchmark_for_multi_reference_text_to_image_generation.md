# MultiBanana: A Challenging Benchmark for Multi-Reference Text-to-Image Generation

**Conference**: CVPR 2026
**arXiv**: [2511.22989](https://arxiv.org/abs/2511.22989)
**Code**: [GitHub](https://github.com/matsuolab/multibanana)
**Area**: Image Generation
**Keywords**: Multi-reference image generation, benchmark evaluation, cross-domain mixing, rare concepts, multilingual

## TL;DR

This paper introduces MultiBanana — the first large-scale benchmark for systematically evaluating multi-reference image generation, comprising 3,769 evaluation samples with up to 8 reference images across 5 difficulty dimensions (cross-domain, scale mismatch, rare concepts, and multilingual). The benchmark reveals complementary failure modes: closed-source models tend to overfit reference details, while open-source models tend to ignore reference subjects.

## Background & Motivation

Multi-reference image generation requires models to inherit the appearance of subjects from multiple reference images and render them in novel scenes. Although models such as GPT-Image-1 and Nano Banana have demonstrated this capability, evaluation benchmarks have lagged significantly behind:

1. Existing benchmarks restrict the number of reference images (typically 1–4), making it impossible to assess model behavior under larger reference sets.
2. Task definitions are ambiguous, distinguishing only "what to edit" or "how many references are given," without capturing the intrinsic challenges of heterogeneous reference combinations.
3. There is no systematic evaluation of challenging conditions such as cross-domain composition, scale mismatch, rare concepts, and multilingual prompts.

MultiBanana fills this critical gap, enabling fair comparison and meaningful progress measurement.

## Method

### Overall Architecture

Real and synthetic images are collected → low-quality and harmful images are filtered → hierarchical category taxonomy is applied → Gemini generates and validates editing instructions → human review is conducted → difficult reference category annotations are added → 3,769 evaluation samples are produced.

### Key Designs

1. **Multi-dimensional task definition**:
   - Single-reference: standard image editing (11 task types)
   - Dual-reference: subject + auxiliary reference
   - Multi-reference (3–8): 4 combination structures × 6 reference counts = 24 task types
   - Difficulty dimensions: cross-domain (28.2%), scale mismatch (36.0%), rare concepts (19.7%), multilingual (2.6%)

2. **Data construction pipeline**:
   - Real data: filtered from LAION-5B (aesthetic score > 6.25, resolution > 512px)
   - Synthetic data: generated by Nano Banana and GPT-Image-1 to compensate for category imbalances in person/object classes
   - Hierarchical taxonomy: 6 major categories (person / object / background / lighting / color tone / style) → 13 subcategories
   - Gemini generates instructions and evaluates visual plausibility; human annotators perform final verification

3. **VLM evaluation protocol**:
   - 5-dimensional criteria: instruction alignment (weight 3), reference consistency (weight 3), background–subject match (1), physical plausibility (1), visual quality (1)
   - Gemini 2.5 and GPT-5 serve as judges; Qwen3-VL is used as an open-source alternative
   - Scoring on a 10-point scale with a weighted total

## Key Experimental Results

### Main Results (average scores by task type)

| Model | Single-Ref | Dual-Ref | X Objects | X-1 + Background |
|---|---|---|---|---|
| GPT-Image-1 | 7.80 | 6.59 | 5.09 | 5.02 |
| Nano Banana | 7.82 | 4.89 | 4.45 | 3.58 |
| Qwen-Image | 7.50 | 3.70 | 2.26 | 2.03 |
| DreamOmni2 | 6.52 | 4.07 | 2.80 | 2.59 |

### Effect of Reference Count

| # References | GPT-Image-1 | Nano Banana | Qwen-Image |
|---|---|---|---|
| 3 | ~5.5 | ~4.8 | ~3.0 |
| 5 | ~5.0 | ~4.2 | ~2.5 |
| 8 | ~4.5 | ~3.8 | ~2.0 |

### Key Findings

- **Closed-source models**: attempt to satisfy all reference constraints but produce globally distorted scenes (overfitting to reference details leads to compositional collapse).
- **Open-source models**: generate visually clean images but frequently ignore multiple reference subjects (sacrificing faithfulness for visual quality).
- Background replacement is the most challenging task type for all models, regardless of reference count.
- All models exhibit significant performance degradation under cross-domain and scale-mismatch conditions.
- VLM judges correlate well with human ratings (GPT-5 Pearson $r = 0.69$, Cohen's $\kappa = 0.61$).

## Highlights & Insights

- MultiBanana is the first systematic benchmark for multi-reference image generation, filling an important gap in the field.
- It reveals complementary failure modes between closed-source and open-source models: a fundamental trade-off between reference faithfulness and visual coherence.
- The difficulty dimensions (cross-domain, rare concepts, etc.) are purposefully designed and effectively differentiate model capability boundaries.
- With 3,769 samples, 36 task types, and 5-dimensional evaluation, the benchmark substantially exceeds existing work in both scale and coverage.

## Limitations & Future Work

- Multilingual samples account for only 2.6% of the dataset (99 samples), limiting statistical power.
- Biases introduced by synthetic data are insufficiently discussed (e.g., Nano Banana-generated data is used to evaluate Nano Banana).
- The 10-point scoring granularity may be insufficient to distinguish subtle quality differences.
- Preliminary exploration of agent-based frameworks (e.g., IPR) yields limited gains; stronger pipeline strategies remain to be investigated.

## Related Work & Insights

- **vs. DreamBooth**: supports only single-reference inputs and does not address combinatorial challenges.
- **vs. OmniContext / DreamOmni2**: supports at most 3–4 reference images and lacks the difficult-reference combination dimensions.
- **vs. EditBench / EMU-Edit**: focuses on editing quality evaluation and does not address multi-reference composition.
