# Algorithmic Guarantees for Distilling Supervised and Offline RL Datasets

**Conference**: ICLR2026  
**OpenReview**: [https://openreview.net/forum?id=zueIXg5FP5](https://openreview.net/forum?id=zueIXg5FP5)  
**Code**: https://github.com/google-deepmind/loss_matching_dataset_distillation  
**Area**: Learning Theory / Dataset Distillation / Offline Reinforcement Learning  
**Keywords**: Dataset Distillation, Sample Complexity, Loss Matching, Bellman Loss, Anti-concentration Inequalities

## TL;DR
This paper provides the first set of provable algorithmic guarantees for dataset distillation **without training models**. For linear regression, it proves that convex loss matching using $\tilde O(d^2)$ randomly sampled regressors yields a synthetic dataset that maintains nearly identical MSE for any bounded linear model, complemented by a matching $\Omega(d^2)$ lower bound. The method is further extended to offline RL through Bellman loss matching, achieving similar guarantees and validation in toy RL environments.

## Background & Motivation
**Background**: The goal of dataset distillation (DD) is to compress a large training set $D_{\text{train}}$ into a tiny synthetic set $D_{\text{syn}}$ such that models trained on $D_{\text{syn}}$ achieve similar performance to those trained on $D_{\text{train}}$. Prevailing approaches utilize various "matching" heuristics—matching loss gradients, feature distributions, or training trajectories—typically embedded within bi-level optimization (simultaneously training the model and optimizing the synthetic set) or matching a set of fixed sampled networks.

**Limitations of Prior Work**: Most existing methods are **heuristic**, offering empirical gains but lacking theoretical guarantees. Few works provide guarantees, and those that do carry strong assumptions: Chen et al. (2024) proved efficiency for linear ridge regression but **assumed the availability of the optimal model on the training set**; Nguyen et al. (2021) avoided training models but **only proved convergence of synthetic feature vectors given synthetic labels**, rather than true performance guarantees. For offline RL, the situation is even less satisfactory—existing DD methods primarily follow **Behavior Cloning (BC)** (Lei et al. 2024, Light et al. 2024), which discards reward and next-state information inherent in offline data and often only works on data generated by expert policies. Furthermore, analyses like those by Lei et al. similarly require a **pre-trained policy model**.

**Key Challenge**: To date, there are **no DD algorithms proven to be efficient without training models**—for either supervised learning or offline RL. Existing guarantees either rely on the "crutch" of an existing optimal model or only provide partial proofs (feature convergence rather than performance).

**Goal**: (1) Design a DD algorithm for supervised regression that **requires no model training**, has a **convex** objective, and offers performance guarantees while characterizing exactly how many random sampled models are needed (upper and lower bounds); (2) Extend this framework to offline RL by replacing BC with Bellman loss matching to utilize reward/next-state information.

**Key Insight**: The authors adopt the paradigm of Zhao & Bilen (2023), which matches a **fixed set of randomly sampled networks** without model training, but they shift the matching target to the **loss values themselves** (loss matching) rather than gradients or features. A key insight is that for linear regression, the loss error $L^{\text{err}}_{\text{mse}}$ is a **convex function** with respect to the synthetic data points, allowing for efficient optimization. Furthermore, since the loss is a 4th-degree polynomial relative to the weights of the random linear regressors, **polynomial anti-concentration inequalities** (Carbery-Wright) can be used to prove that a few random regressors are sufficient to cover all possible regressors.

**Core Idea**: Replace bi-level training with convex loss matching on $\tilde O(d^2)$ randomly sampled models, transforming DD into an algorithmic problem with guaranteed sample complexity and provable tightness.

## Method

### Overall Architecture
The paper presents two **algorithms and accompanying sample complexity theorems** rather than a network architecture. Both algorithms share a common framework:

> **Randomly sample $k$ models** from a fixed distribution (linear regressors for supervised tasks, linear Q-value predictors for RL), and then **optimize only the synthetic dataset $D_{\text{syn}}$** to minimize the difference between its loss and the training set loss across these $k$ models. **No models are trained during this process.**

Formally, supervised regression requires that for all bounded linear regressors $f\in\mathcal F_0$ ($\|v\|_2\le 1$):

$$L^{\text{err}}_{\text{mse}}(D^{\text{sup}}_{\text{train}}, D^{\text{sup}}_{\text{syn}}, f) := \big(L_{\text{mse}}(D^{\text{sup}}_{\text{train}}, f) - L_{\text{mse}}(D^{\text{sup}}_{\text{syn}}, f)\big)^2 \le \varepsilon.$$

Offline RL replaces MSE with Bellman loss, requiring $L^{\text{err}}_{\text{Bell}}\le\varepsilon$ for all linear Q-value predictors $f\in\mathcal Q_0$, where:

$$L_{\text{Bell}}(D^{\text{orl}}, f) = \mathbb E_{(s,a,r,s')\leftarrow D^{\text{orl}}}\Big[\big(f(s,a) - r - \gamma \max_{a'\in A} f(s',a')\big)^2\Big].$$

The challenge lies in ensuring loss invariance for **all** $f$ while matching only a **finite set of sampled** $f$. The technical contribution involves proving that a small number of random $f$ samples suffice to cover the entire space and characterizing this "small number."

### Key Designs

**1. Loss Matching + Random Regressors: Converting DD into a Convex Problem without Training**

Addressing the issue that existing DD requires bi-level training or offers only partial guarantees, the authors fix $k$ sampled regressors $g_1,\dots,g_k$ (where each $g$ is sampled via $r\sim\mathcal N(0, 1/(d{+}1))$) and solve:

$$D^{\text{sup}}_{\text{syn}} = \arg\min_{D_{\text{syn}}} \sum_{j=1}^k L^{\text{err}}_{\text{mse}}(D^{\text{sup}}_{\text{train}}, D_{\text{syn}}, g_j)\quad(\text{Algorithm 1}).$$.

A critical property is that $L^{\text{err}}_{\text{mse}}(D_{\text{train}}, D_{\text{syn}}, g)$ is a **convex function** with respect to the points in $D_{\text{syn}}$ (using homogenization to fold labels into features: $\zeta(x,y)=(x_1,\dots,x_d,y)$, expressing loss as a difference of $\mathbb E[(r^\top\zeta)^2]$). Unlike prior methods where quality depends on model training, the synthetic set here is the solution to a clean convex problem backed by theorem.

**2. $\tilde O(d^2)$ Upper Bound and $\Omega(d^2)$ Lower Bound: Provable Tightness**

Theorem 4.1 establishes the upper bound: when $k = O(d^2\log(d(B{+}b)/\Delta)\log(1/\delta))$, with probability $1-\delta$, matching training loss within $\Delta' = \Delta k / O(d^2)$ on these $k$ regressors ensures $L^{\text{err}}_{\text{mse}}\le\Delta$ **for all** $f\in\mathcal F_0$. The proof uses **Carbery-Wright anti-concentration** on the 4th-degree polynomial of Gaussian variables representing the loss difference. Furthermore, Theorem 4.2 provides a **matching lower bound**: for any set of $<q(q{+}1)/2$ (where $q=d{+1}$) linear regressors, one can construct a $D_{\text{syn}}$ that matches their losses perfectly yet fails for another regressor $f_0$. This proves $\tilde O(d^2)$ is **tight within polylogarithmic factors**.

**3. Bellman Loss Matching: Extending Guarantees to Offline RL with an Exponential Cost**

To address the loss of reward/next-state info in BC-based RL DD, Algorithm 2 performs loss matching on Bellman losses for randomly sampled linear Q-value predictors $(f_j,\lambda_j)$. Theorem 4.3 guarantees $L^{\text{err}}_{\text{Bell}}\le\Delta$ for all $f\in\mathcal Q_0$ given $k=\exp(O(d\log d))\cdot\text{poly}(\cdots)$ predictors. The jump to exponential complexity stems from the $\max_{a'} f(s',a')$ term, which is **not** a low-degree polynomial, causing design 2's anti-concentration proof to fail and necessitating a "conditioning" argument.

**4. Decomposable Feature Mapping: Reducing RL Cost back to $\tilde O(d^2)$**

The authors observe that state-action features are often **decomposable** in practice, i.e., $\phi(s,a)=\phi_1(s)+\phi_2(a)$. Under this assumption, Theorem 4.4 proves that $k=\tilde O(d^2)$ predictors suffice, provided the optimization satisfies an additional first-moment constraint $\mathbb E_{D_{\text{syn}}}[(\phi_1(s),\phi_2(a),r,\phi_1(s'))]=\mathbb E_{D_{\text{train}}}[\cdots]$. This constraint remains linear, keeping the optimization **convex**.

### Loss & Training
There is no "training loss" in the traditional sense; only the synthetic dataset $D_{\text{syn}}$ is optimized. The target is $\sum_j L^{\text{err}}_{\text{mse}}$ for supervised tasks and $\sum_j \hat L^{\text{err}}_{\text{Bell}}$ for RL. Actual models (homogenized linear models or 2-layer NNs using Fitted-Q Iteration) are only trained on $D_{\text{syn}}$ during evaluation to verify performance.

## Key Experimental Results

### Main Results

| Scenario | Dataset / Environment | Synthetic Size $N_{\text{syn}}$ | Samples $k$ | Result (vs Baselines) |
|------|-------------|----------------------------|----------------|----------------------|
| Supervised Regression | Red/White wine, Boston Housing | $\{20,50,100\}$ | 100 | MSE on $D_{\text{syn}} \approx D_{\text{train}}$, far better than $D_{\text{rand}}$, superior/equal to leverage-score sampling $D_{\text{lev}}$. |
| Offline RL | Cartpole / Mountain Car / Acrobot | Variable $N_{\text{syn}}$ | 20 | $D_{\text{syn}}$ policy significantly outperforms $D_{\text{rand}}$; matches $D_{\text{train}}$ in Cartpole and Acrobot as $N_{\text{syn}}$ increases. |

### Ablation Study / Key Findings
- **$D_{\text{syn}}$ vs $D_{\text{rand}}$**: $D_{\text{syn}}$ significantly leads, proving loss matching captures useful information beyond random sub-sampling.
- **Sample Count $k$**: While the RL theoretical bound is exponential, $k=20$ is sufficient in practice due to the decomposable structure of hidden feature spaces.
- **Linear vs Nonlinear**: Although guarantees are for linear models, the algorithm remains effective when using 2-layer neural networks for evaluation.
- **Failure on D4RL**: The method fails on standard D4RL benchmarks because these are designed to distinguish advanced algorithms like CQL from FQI. Since this distillation matches Bellman loss (tied to FQI), it inherently lacks the conservative regularization needed for D4RL.

## Highlights & Insights
- **First Guarantee without training**: Unlike prior work requiring optimal model "crutches," this provides the first complete package of "no training + performance guarantees + convex solvability."
- **Matching Bounds**: The $\tilde O(d^2)$ upper and lower bounds prove that the number of sampled models is tight within logarithmic factors.
- **Statistical Mechanics in DD**: The use of Carbery-Wright anti-concentration to prove that a few random "probes" cover the entire model space provides a reusable template for other matching-based problems.
- **Honest Negative Results**: Actively reporting failure on D4RL and explaining it via Bellman matching vs CQL adds credibility and points toward future research on conservative loss matching.

## Limitations & Future Work
- **Linearity Constraint**: Theories are limited to linear regression and Q-value predictors; neural network results remain empirical.
- **Worst-case RL Complexity**: Generally requires an exponential number of predictors unless decomposable feature assumptions are met.
- **D4RL Applicability**: Requires adaptation to more complex loss functions (like CQL) to handle standard offline RL benchmarks.
- **Scale**: Experiments are limited to small UCI datasets and toy RL environments.

## Related Work & Insights
- **vs Chen et al. (2024)**: They prove efficiency for ridge regression but assume the optimal model is known; this work removes that requirement.
- **vs Nguyen et al. (2021)**: They prove feature convergence; this work proves end-performance invariance for any bounded model.
- **vs Light/Lei et al. (2024)**: Previous RL DD methods rely on BC; this utilizes Bellman loss to capture rewards and transitions.
- **vs Matrix Sketching**: Standard sketching requires $1/\Delta$ samples; this "matching" approach requires only $\log(1/\Delta)$ random models.
