# Annotations Mitigate Post-Training Mode Collapse

**Conference**: ICML 2026  
**arXiv**: [2605.09995](https://arxiv.org/abs/2605.09995)  
**Code**: Not explicitly disclosed by the authors  
**Area**: LLM Pre-training / Post-training Alignment / Generative Diversity  
**Keywords**: Mode collapse, SFT, Semantic entropy, Annotation anchoring, Diversity-quality trade-off

## TL;DR
The authors find that SFT aligns models with a low-entropy semantic prior, causing a "reverse scaling" where larger instruction models become more "boring." They propose "annotation-anchored training": assigning semantic tags to documents during pre-training and masking the loss on the tag portion during SFT. This allows the model to sample semantics before generating responses during inference, reducing the semantic diversity gap by 85% while maintaining instruction-following capabilities.

## Background & Motivation
**Background**: The current mainstream alignment pipeline involves unsupervised pre-training on massive web data followed by SFT (and RLHF) on a relatively narrow instruction dataset to sculpt base models into "helpful and well-formatted" assistants.

**Limitations of Prior Work**: While the output quality of base models varies, their semantic coverage is broad. After SFT, several responses generated by the model under the same prompt become highly similar in theme, names, locations, and style—this is known as "semantic mode collapse." Even worse, the authors replicated and extended findings from NoveltyBench: while base models become more semantically diverse as they scale, SFT models collapse more as they grow larger. This collapse cannot be eliminated by diversity prompting strategies like brainstorming or multiple sampling.

**Key Challenge**: The optimization objective of SFT is to "match the model distribution to the post-training data distribution." However, the post-training data itself is a low-entropy semantic set (reflecting the few modes preferred by annotators). Maximum likelihood training indiscriminately injects this low-entropy semantic prior into the model. That is, SFT simultaneously changes two things: "how to write a response given a semantic" (desired) and "which semantics will be expressed" (undesired), with the two entangled.

**Goal**: Decouple these two distributions, enabling post-training to only update the conditional response behavior $Q^\star(y\mid x,z)$, while anchoring the semantic distribution $R(z\mid x)$ to the high-entropy state of pre-training.

**Key Insight**: The authors introduce an explicit semantic variable $z$ (a set of key-value style tags such as topic/location/entities/genre) and factorize response generation as $P^\star_R(y\mid x)=\int R(z\mid x)\,Q^\star(y\mid x,z)\,dz$. As long as the high-entropy nature of $R$ is preserved during training, diversity will not collapse.

**Core Idea**: Assign annotations to each chunk during pre-training and concatenate them into interleaved sequences like `<z>x`; mask the loss for the $z$ portion during SFT; during inference, let the model output the annotation first and then the response. The sampling diversity of the annotation naturally inherits from the pre-training distribution.

## Method
The entire method, called annotation-anchored training, is divided into four stages: "annotation, pre-training, post-training, and inference." The core trick is extremely simple: training data formats are slightly modified, loss masks are slightly adjusted, and the rest remains a standard autoregressive LM without introducing any new modules or losses.

### Overall Architecture
- **Offline**: Use Qwen3-30B-A3B-Instruct as an annotator to extract semantic tags in the form of `<key>:<value>` (topic, domain, action, entities, location, etc.) for each chunk of pre-training corpora and for each target response in SFT data.
- **Pre-training**: Divide each document into chunks $x_1,\dots,x_n$ by double-newlines and construct interleaved sequences $\langle z_1\rangle x_1 \langle z_2\rangle x_2 \cdots \langle z_n\rangle x_n$. Perform next-token prediction without masking any tokens. This step allows the model to learn both "generating annotations based on context" and "generating text based on annotations."
- **Post-training (SFT)**: Training samples become `prompt <annotation> response`. Loss is backpropagated only on response tokens; annotation tokens are entirely masked. Thus, the response distribution is updated by instruction data, but the annotation distribution is frozen in the pre-training state.
- **Inference**: Directly sample—the model naturally outputs an annotation first (with sampling diversity from the pre-training distribution) and then generates a response conditioned on it. Only the response part is kept for evaluation.

### Key Designs

1.  **Explicit semantic variable z as a bridge for distribution factorization**:
    -   **Function**: Splits response generation into two steps: "decide what semantics to write" and then "decide how to express them," allowing the two distributions to be controlled independently.
    -   **Mechanism**: The authors define the pre-training distribution as $P(y)=\int R(z)Q(y\mid z)dz$ and the post-training distribution as $P^\star(y\mid x)=\int R^\star(z\mid x)Q^\star(y\mid x,z)dz$, noting that collapse occurs when $R^\star$ has much lower entropy than $R$. The anchored target is changed to $P^\star_R(y\mid x)=\int R(z\mid x)Q^\star(y\mid x,z)dz$—preserving the pre-training semantic prior while absorbing post-training conditional response capability. $z$ is expressed using a set of variable-length `<key>:<value>` tags, which are natural language tokens 100% compatible with standard LMs.
    -   **Design Motivation**: Traditional methods like entropy regularization or KL constraints apply constraints to the entire response distribution, failing to distinguish "which part to change vs. which to keep"; an explicit $z$ directly addresses the issue by locking only the "semantic marginal distribution," allowing "conditional response" to vary freely.

2.  **Chunk-level tagging + Interleaved sequences**:
    -   **Function**: Enables the model to learn a high-entropy but locally coherent $z\mid x$ conditional distribution, which is the source of annotation diversity during subsequent inference.
    -   **Mechanism**: Using global annotations for a whole document loses local signals, so the authors split chunks by double-newlines, extract tags for each chunk independently, and arrange them as interleaved `<z_i>x_i` for standard autoregressive training. The model thus learns the conditional chain of "previous text → next semantic → next text"; this set of conditional distributions seamlessly transfers as the format prior for "prompt → annotation → response" during SFT.
    -   **Design Motivation**: The annotator itself is noisy and cannot be perfectly accurate for every tag; however, averaged over chunk-level multi-tags, the overall annotation distribution entropy remains high, which is exactly what needs to be preserved—making the method robust to individual tagging errors.

3.  **Annotation-masked SFT + Anchored Inference**:
    -   **Function**: Updates the capability of "how to respond given semantics" during fine-tuning without polluting the "how semantics are sampled" distribution.
    -   **Mechanism**: SFT data follows the format `prompt <annotation> response`, where the loss for the annotation portion is fully masked (with a 0.3% exception in the paper where only tag values are masked to stabilize the format). Since annotation tokens do not participate in gradient updates, the model's prediction of $p(z\mid x)$ maintains the high-entropy distribution learned during pre-training; only $p(y\mid x,z)$ is shaped by SFT data. During inference, decoding with temperature 1 allows the model to sample an annotation first and then generate a response, bringing semantic diversity into the final output through the randomness of the annotation.
    -   **Design Motivation**: This is the critical "one line of code" in the entire method—it tells the training algorithm "what to learn and what to protect." It is equivalent to imposing an implicit KL constraint on the response distribution, but more precise than explicit KL because it only constrains $R$ and not $Q$.

### Loss & Training
- **Pre-training**: Standard next-token loss, no mask.
- **SFT**: Next-token loss, but masked at annotation token positions.
- **Hyperparameters**: Annotations occupy a portion of the total token budget ("annotations replace content tokens" to keep FLOPs/token matched); LR is tuned via validation perplexity; trained on Chinchilla-optimal token counts (12B tokens for 0.6B model, 20B for 1B, 50B for 2.5B).

## Key Experimental Results

### Main Results
Compared against standard SFT on four diversity benchmarks: Stories / NoveltyBench / WildChat / InfinityChat. For Stories, an LLM judge extracts tags for 8 attributes to calculate semantic entropy; for dialogue, pairwise cosine distance of Qwen3-Embedding-0.6B is used.

| Evaluation Metric | Model Scale | Standard SFT | Annotation-Anchored | Remarks |
| :--- | :--- | :--- | :--- | :--- |
| Stories Semantic Entropy | 2.5B | Significant collapse (far below base) | Gap with base reduced to ~15% | 6× less collapse |
| NoveltyBench / WildChat / InfinityChat | 0.6B / 1B / 2.5B | Full-scale collapse | Full-scale higher than SFT | Consistent across benchmarks |
| Inference Sampling | temp 0.6~1.1 | Quality drops without diversity gain | Diversity-quality Pareto frontier shifted | See Fig 6 |

| Task Performance Evaluation | 0.6B | 1B | 2.5B | Description |
| :--- | :--- | :--- | :--- | :--- |
| Average across 9 items (ARC/BoolQ/HellaSwag, etc.) (SFT) | 53.1 | 57.7 | 62.4 | Standard Baseline |
| Same as above (Annotated) | 54.5 | 56.6 | 62.3 | Gap ≤ 1 point across scales |
| GSM8k (SFT / Annotated) | 11.3 / 10.8 | 19.4 / 18.9 | 35.4 / 36.4 | Reasoning ability nearly lossless |

### Ablation Study

| Configuration | Main Conclusion |
| :--- | :--- |
| Anchored SFT only (no annotated pre-training) | Performance drops significantly, proving injection of high-entropy distribution during pre-training is necessary. |
| Increasing SFT data volume | Standard SFT diversity decreases further; Annotated maintains or improves. |
| Increasing validation likelihood | Standard SFT: Higher likelihood leads to lower diversity (strong negative correlation); Annotated: Positive correlation. |
| Different temperature (0.6~1.1) | Annotated consistently shows higher diversity than SFT across all temperatures with comparable quality. |

### Key Findings
- The phenomenon "tighter fit to post-training data → worse diversity" holds across various hyperparameters and data volumes; annotation-anchored flips this negative correlation into a positive one, indicating it solves collapse mechanistically rather than masking it with tricks.
- The reverse scaling phenomenon (instruction models becoming narrower as they grow) only appears under the SFT pipeline; annotation-anchored fully restores positive scaling (larger models are more diverse).
- At the 2.5B scale, the semantic diversity gap on Stories is closed by 85%, suggesting that the "upper bound" of collapse is not an inevitable consequence of SFT, but an result of poorly designed optimization objectives.

## Highlights & Insights
- **Elegant Distribution Factorization**: Using a simple $R \cdot Q$ decomposition to conceptually separate "semantic prior" and "conditional response." This factorized perspective not only explains reverse scaling but also directly provides a solution—a rare combination of "clear theory + extreme engineering simplicity."
- **Mask loss as Anchor**: The technique where annotation tokens do not participate in gradient updates is equivalent to imposing an implicit KL constraint on $R$, but at zero cost and with higher precision than explicit KL or entropy regularization.
- **Extensible Paradigm**: The authors suggest in the final paragraph that annotations do not have to be topics/entities; they could be "proof strategies" for math problems or "algorithmic logic" for code. Essentially, it serves as a template for "any latent variable where you want to maintain diversity," providing a new model for CoT or reasoning path diversity.

## Limitations & Future Work
- Annotations require a relatively strong LLM for extraction (Qwen3-30B-A3B used in the paper), representing a non-trivial cost for small teams; however, the authors emphasize the annotator does not need to be perfectly accurate, provided the distribution entropy is high enough.
- Experiments peaked at 2.5B scale and 50B tokens, still a distance from true frontier models with 70B+ parameters or trillion tokens; SFT data formats (annotation token ratio, tag schema) might need retuning as scale increases.
- Inference incurs additional overhead for annotation generation (albeit short); tradeoffs are needed for latency-sensitive deployments.
- The annotation schema is manually designed and coupled with task types; how to automatically discover the "dimensions of $z$ that should be diverse" remains an open question.

## Related Work & Insights
- **vs NoveltyBench (Zhang et al. 2025b)**: They first reported the reverse scaling phenomenon but only provided a diagnosis; this paper provides both a mechanistic explanation and an engineering solution, turning the "problem" into a "method."
- **vs Entropy Regularization / KL-constrained SFT**: Those methods constrain the entire response distribution, failing to distinguish which parts to preserve; this paper uses explicit $z$ to pinpoint the anchoring of semantic marginal distributions, offering a finer-grained tool.
- **vs Latent variable / CVAE Conversational Models**: Both share the goal of introducing latent variables to increase conditional diversity; the difference is that this paper targets "preserving the pre-training semantic prior" rather than "user-controllable attributes," leading to entirely different applications.
- **vs Verbalized Sampling / Diverse Beam Search**: These are inference-time diversity tricks orthogonal to this paper and can be stacked.

## Rating
- **Novelty**: ⭐⭐⭐⭐⭐ Combining "distribution factorization + loss mask" on SFT is a novel and minimalist perspective.
- **Experimental Thoroughness**: ⭐⭐⭐⭐ Solid results across 4 diversity benchmarks, 9 capability benchmarks, and multiple temperatures; however, scale is capped at 2.5B.
- **Writing Quality**: ⭐⭐⭐⭐⭐ Clear concepts, formulas align with diagrams, and the factorization argument is very elegant.
- **Value**: ⭐⭐⭐⭐⭐ Directly inspiring for LLM alignment, creative generation, and synthetic data diversity; likely to become a default component for next-generation alignment pipelines.
