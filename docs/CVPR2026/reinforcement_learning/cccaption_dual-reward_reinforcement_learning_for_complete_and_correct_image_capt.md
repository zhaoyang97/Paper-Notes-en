# CCCaption: Dual-Reward Reinforcement Learning for Complete and Correct Image Captioning

**Conference**: CVPR 2026  
**arXiv**: [2602.21655](https://arxiv.org/abs/2602.21655)  
**Code**: [https://github.com/ZhijiangTang/CCCaption](https://github.com/ZhijiangTang/CCCaption)  
**Area**: Reinforcement Learning  
**Keywords**: image captioning, reinforcement learning, completeness, correctness, dual-reward

## TL;DR
This paper proposes CCCaption, a dual-reward reinforcement learning framework that jointly optimizes completeness (via a visual query set generated by multiple MLLMs) and correctness (via hallucination detection on sub-queries decomposed from the caption) for image captioning. A 2B model trained under this framework surpasses a 32B baseline.

## Background & Motivation
Image captioning is a fundamental task in vision-language understanding, yet existing model training relies heavily on human-annotated reference captions. Human annotations inevitably reflect subjective preferences and varying levels of expertise, making ground-truth captions inherently incomplete or even incorrect. The authors argue that a high-quality caption should satisfy two objective properties: **completeness** (whether all salient visual facts in the image are covered) and **correctness** (whether the described content is consistent with the image).

Existing RL methods such as CapRL use a single MLLM to generate queries for measuring completeness, which suffers from single-model bias and insufficient coverage. More critically, an unconstrained completeness-only reward encourages the model to describe more details to maximize the reward, but this tends to introduce more hallucinations — experiments show that reward continues to rise in later training stages while correctness drops significantly. Therefore, a robust captioning objective must simultaneously enforce both completeness and correctness.

**Core Idea**: Design a symmetric dual-reward mechanism where completeness is measured by multi-MLLM query coverage rate (analogous to recall), and correctness is measured by the grounding degree of sub-queries decomposed from the caption in the image (analogous to precision), with joint optimization.

## Method

### Overall Architecture
CCCaption is built on the GRPO reinforcement learning algorithm and consists of three core components: (1) a Completeness Reward that incentivizes captions covering more visual facts; (2) a Correctness Reward that penalizes captions containing hallucinations; and (3) a Dynamic Query Sampling strategy to improve training efficiency. A training dataset, CCaption-44k, is also constructed.

### Key Designs

1. **Completeness Reward**:

    - **Function**: Approximates the essential information set $\mathcal{B}_\mathbf{x}$ of an image using a visual query set, rewarding captions that can answer more queries.
    - **Mechanism**: $\mathcal{R}_\text{comp}(\mathbf{x}, \hat{\mathbf{y}}) = \frac{1}{|\mathcal{Q}_\mathbf{x}|}\sum_{\mathbf{q} \in \mathcal{Q}_\mathbf{x}} \mathbb{I}(M_J(\hat{\mathbf{y}}, \mathbf{q}))$, where $M_J$ is a frozen third-party judge model that determines whether a caption can answer a given query.
    - **Design Motivation**: To address the insufficient coverage of single-MLLM query generation, a multi-MLLM query generation algorithm is introduced. The diversity of the query set $\mathcal{V}(\mathcal{Q}_\mathbf{x})$ is defined as the variance of embedding cosine similarities; low-contribution queries are filtered out iteratively to ensure diversity and completeness, ultimately constructing CCaption-44k (44k samples, averaging 10 queries per image).

2. **Correctness Reward**:

    - **Function**: Decomposes the generated caption into a sub-query set $\mathcal{Q}_{\hat{\mathbf{y}}}$, detects hallucinations, and applies penalties accordingly.
    - **Mechanism**: $\mathcal{R}_\text{corr}(\mathbf{x}, \hat{\mathbf{y}}) = \frac{1}{|\mathcal{Q}_{\hat{\mathbf{y}}}|}\sum_{\mathbf{q} \in \mathcal{Q}_{\hat{\mathbf{y}}}} M_J(\mathbf{x}, \mathbf{q})$. The caption is decomposed into atomic queries, and a judge model scores the factual accuracy of each query against the original image.
    - **Design Motivation**: Completeness and correctness form a symmetric structure — the former measures image-query coverage of the caption (recall), while the latter measures the grounding of caption-queries in the image (precision). Their joint constraint prevents the model from "answering more queries while introducing more hallucinations."

3. **Dynamic Query Sampling**:

    - **Function**: Dynamically adjusts query sampling probabilities during training to reduce sampling of "easy" queries that contribute little to the gradient.
    - **Mechanism**: $\tilde{\mathcal{Q}} = \{\mathbf{q} \in \mathcal{Q}_c \mid u_\mathbf{q} \sim \text{Bernoulli}(c(\mathbf{q}))\}$, where $c(\mathbf{q})$ is the normalized contribution score, initialized as $1 - \frac{1}{m}\sum \mathbb{I}(M_J(\mathbf{x}, \mathbf{q}))$ and updated per epoch based on rollout accuracy variance.
    - **Design Motivation**: Under the GRPO framework, queries that nearly all rollout captions answer correctly yield negligible advantage and gradient, wasting computational resources.

### Loss & Training
The total reward is a weighted sum of the two rewards: $\mathcal{R}(\mathbf{x}, \hat{\mathbf{y}}) = \alpha \mathcal{R}_\text{comp} + (1-\alpha) \mathcal{R}_\text{corr}$, which is substituted into the GRPO RL objective for optimization. The backbone model is Qwen3-VL-2B, and the training data is CCaption-44k.

## Key Experimental Results

### Main Results

| Evaluation Framework | Metric | CCCaption-2B | Qwen3-VL-2B | Qwen3-VL-32B | CapRL-3B | Gain |
|---------------------|--------|-------------|-------------|-------------|---------|------|
| CapArena | Avg. ELO | **46.39** | 41.39 | - | 17.56 | +5.0 vs 2B baseline |

| Hallucinations | Avg. | **70.57** | 70.19 | 69.87 | 66.91 | +0.70 vs 32B |

### Ablation Study

| Configuration | Effect | Notes |
|--------------|--------|-------|
| Completeness only | reward ↑ but correctness ↓ | hallucinations surge in later stages |
| + Correctness reward | significant improvement | effectively suppresses hallucinations |
| + Dynamic Query Sampling | best overall | further improves training efficiency |
| Single MLLM vs. multi-MLLM queries | multi-MLLM superior | improved diversity increases coverage |

### Key Findings
- CCCaption-2B outperforms Qwen3-VL-32B across all three evaluation frameworks, demonstrating the effectiveness of the dual-reward RL approach.
- Optimizing completeness alone leads to a surge of hallucinations in later training stages (correctness continuously declines); the correctness reward effectively curbs this trend.
- Dynamic query sampling significantly improves training efficiency by increasing the sampling probability of high-variance queries.

## Highlights & Insights
- The symmetric definition of completeness and correctness is elegant — the former measures recall and the latter measures precision, making them naturally complementary.
- Multi-MLLM query generation combined with diversity-based filtering is an effective solution to single-model bias.
- The paper reveals the "reward hacking" phenomenon in RL-based captioning — where reward increases but quality degrades — and provides a practical remedy.

## Limitations & Future Work
- Query generation and correctness evaluation rely on a frozen judge MLLM, whose biases propagate into the reward signal.
- The CCaption-44k dataset is relatively small in scale; larger and more diverse query datasets may yield further improvements.
- The method has only been validated on image captioning; its applicability to video captioning or multi-turn dialogue remains to be explored.

## Related Work & Insights
- CapRL proposes using VQA capability as a caption quality metric; this paper extends that idea by adding a correctness constraint.
- The GRPO algorithm provides an efficient within-group relative optimization framework for RL-based captioning.
- The dual-reward (completeness + correctness) paradigm can be generalized to quality evaluation in other generative tasks.
- Early encoder-decoder methods such as Show and Tell depend on human annotations; this work overcomes that limitation through RL.
- Compared to the coarse-grained keyword-checking approach of SC-Captioner, query-based evaluation is more comprehensive.

## Supplementary Details
- The training dataset CCaption-44k covers 44k images with an average of 10 queries per image, generated by multiple MLLMs including Claude, CogVLM2, and MiniCPM-V.
- In the CapArena evaluation, Qwen3-VL-32B serves as the judge model; CCCaption-2B comprehensively outperforms baselines across the Claude/CPMV/Cog2 sub-evaluations.
- Case studies show that CCCaption-2B effectively avoids both hallucinations and omissions, outperforming 32B-scale models.
- The diversity metric $\mathcal{V}$ uses the variance of cosine similarities among query embeddings; the threshold $\tau$ controls the minimum diversity requirement for the query set.
- $\alpha$, which balances completeness and correctness, is a critical hyperparameter.

## Key Terminology
- **Query Coverage**: Measuring caption completeness via the coverage rate of a query set.
- **Sub-caption Query**: Atomic semantic facts decomposed from a long caption into individual queries.
- **Reward Hacking**: The phenomenon in RL where reward increases while actual quality degrades.
- **GRPO**: Group Relative Policy Optimization, an advantage estimation method based on within-group relative performance.
