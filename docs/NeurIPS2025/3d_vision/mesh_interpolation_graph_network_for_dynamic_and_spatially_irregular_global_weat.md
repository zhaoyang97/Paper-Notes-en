# Mesh Interpolation Graph Network for Dynamic and Spatially Irregular Global Weather Forecasting

**Conference**: NeurIPS 2025
**arXiv**: [2509.20911](https://arxiv.org/abs/2509.20911)  
**Code**: [Available](https://github.com/compasszzn/MIGN)  
**Area**: 3D Vision / Spatiotemporal Forecasting
**Keywords**: Graph Neural Networks, Global Weather Forecasting, Mesh Interpolation, Spherical Harmonics, Spatial Generalization

## TL;DR

This paper proposes MIGN, a framework that maps irregular weather station data onto a regular HEALPix mesh via a mesh interpolation strategy for message passing, and introduces parameterized spherical harmonics positional encoding to enhance spatial generalization, achieving significant improvements over existing methods on global weather forecasting tasks.

## Background & Motivation

Existing data-driven weather forecasting models primarily focus on **regular grid data** (e.g., ERA5), such as FourCastNet, Pangu, and GraphCast. However, real-world weather station observations present two core challenges:

**Spatial irregularity**: Global weather stations are distributed highly unevenly, with most concentrated in North America and Western Europe, resulting in dramatic density variations across latitudes and longitudes. Existing GNN methods struggle to simultaneously learn from high-density and low-density regions.

**Dynamic distribution**: The number and locations of weather stations change over time (new stations built or decommissioned), causing models trained on fixed station sets to overfit and fail to predict at unseen locations.

Most existing GNN methods (e.g., DyGrAE, STAR) focus on regional forecasting (e.g., Europe, North America), neglecting the coupling of global weather systems, and typically assume a fixed set of stations. **This work is the first to systematically study global weather forecasting with spatially irregular and dynamically changing station networks.**

## Method

### Overall Architecture

MIGN adopts an **Encoder–Processor–Decoder** architecture:
- **Encoder**: Maps irregular station information onto regular HEALPix mesh nodes via message passing
- **Processor**: Performs standard GNN message passing on the regular mesh
- **Decoder**: Maps predictions from the mesh back to target station locations

### Key Designs

1. **Mesh Interpolation Strategy**

   **Function**: Aligns spatially irregular weather station data to a regular spherical mesh.

   **Mechanism**: HEALPix is used to partition the sphere into equal-area pixels, forming a hierarchically refined uniform mesh. The encoder aggregates information from station nodes to their nearest mesh nodes via message passing:

   $\mathbf{h}_{v_h}^{(E)} = \text{AGG}^{(E)}(\{\mathbf{m}_{v_s \to v_h}^{(E)} : v_s \in \mathcal{N}(v_h)\})$

   where messages are generated by applying an MLP to the hidden states of station nodes. Mesh node features are initialized to zero, achieving "interpolation" through message passing.

   **Design Motivation**: On a regular mesh, spatial adjacency relationships are well-defined and node positions are fixed, enabling direct application of standard GNN/CNN/Transformer architectures. This avoids the learning imbalance caused by density variation on irregular graphs.

2. **Spherical Harmonics Location Embedding**

   **Function**: Provides parameterized continuous positional encoding for each location on the sphere.

   **Mechanism**: Location information is modeled as a spherical function $f(\lambda, \phi)$, expanded using real spherical harmonic bases:

   $SH(\lambda, \phi) = \bigoplus_{n \geq 0} \bigoplus_{m=-n}^{n} w_n^m Y_n^m(\lambda, \phi)$

   where $w_n^m$ are learnable coefficients shared across all nodes. The final node representation is $\mathbf{h} = [x; SH(\lambda, \phi)]$.

   **Design Motivation**: Non-parameterized positional encodings (e.g., raw coordinates) provide limited location information and generalize poorly to unseen regions. Spherical harmonics are naturally suited for spherical data analysis, with different orders capturing spatial variation patterns at different scales. Since different meteorological variables exhibit distinct spatial variation patterns in the same region, independent positional encodings are learned for each variable.

### Loss & Training

MSE loss is used: $\mathcal{L}_{train} = \sum_{s \in \mathcal{D}_{train}} \|\hat{Y}_s^{t+1} - Y_s^{t+1}\|^2$

The model is trained with the Adam optimizer, batch size 4, hidden dimension 64, learning rate 0.001, and 2 GNN layers. The mesh refinement level is set to 3 (768 mesh nodes), with 10-nearest-neighbor graph construction and maximum spherical harmonics order $N=2$.

## Key Experimental Results

### Main Results

Evaluated on the NOAA GSOD global observation dataset across 6 meteorological variables, compared against 13 spatiotemporal baseline models.

| Variable | Metric | MIGN | Best Baseline | Gain |
|----------|--------|------|---------------|------|
| MAX TEMP | MSE | 8.47 | 9.74 (STGCN) | 13% |
| MIN TEMP | MSE | 8.01 | 9.44 (STGCN) | 15% |
| DEWP | MSE | 7.92 | 9.25 (STGCN/DyGrAE) | 15% |
| SLP | MSE | 20.09 | 23.83 (DualCast) | 15% |
| WDSP | MSE | 8.38 | 8.60 (STGCN) | 3% |
| MXSPD | MSE | 19.73 | 20.25 (HD-TTS) | 3% |

### Ablation Study

| Configuration | Description |
|---------------|-------------|
| Full MIGN | Best performance |
| w/o spherical harmonics encoding | Significant performance drop, validating the importance of positional encoding |
| w/o mesh interpolation | Performance drop, validating the necessity of regularized alignment |
| Multi-step forecasting (3-day input → 4-day output) | MIGN outperforms baselines at all forecast steps |

### Key Findings

- **Spatial generalization**: Half of the stations are randomly selected for training, with evaluation on unseen stations. DyGrAE and STAR exhibit high MAE in Europe and North America, whereas MIGN achieves significantly lower errors in these regions, demonstrating strong generalization to unseen locations.
- **Regional robustness**: Most methods struggle to perform well simultaneously in both dense and sparse observation regions; MIGN yields more stable results across regions with varying observation density.

## Highlights & Insights

- The approach elegantly combines classical mesh interpolation ideas from geoscience with GNN message passing, representing a **physics-prior-driven network design**
- Spherical harmonics encoding is continuous, differentiable, and naturally suited to spherical geometry, making it far more principled than naive coordinate-based encodings
- The framework is highly flexible: the GNN modules in the encoder, processor, and decoder can be replaced with any existing method

## Limitations & Future Work

- Currently limited to single-step forecasting (next day); longer-range prediction requires further investigation
- The HEALPix mesh resolution is fixed; adaptive multi-resolution meshes may be needed
- Temporal sequential dependencies across stations are not modeled (e.g., via RNN/Transformer for the temporal dimension)
- Fusion with reanalysis data such as ERA5 remains unexplored

## Related Work & Insights

- GraphCast also employs a mesh structure but targets regular grid data with static edges; the core contribution of MIGN lies in handling irregular and dynamic station data
- Spherical harmonics have broad applications in geoscience (magnetic fields, gravity fields); this work introduces them as learnable positional encodings for GNNs, a strategy transferable to other spherical data tasks
