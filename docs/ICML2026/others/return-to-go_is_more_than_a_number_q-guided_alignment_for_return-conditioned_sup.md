# Return-to-Go is More Than a Number: Q-Guided Alignment for Return-Conditioned Supervised Learning

**Conference**: ICML 2026  
**arXiv**: [2605.29028](https://arxiv.org/abs/2605.29028)  
**Code**: To be confirmed  
**Area**: Reinforcement Learning / Decision Transformer  
**Keywords**: Offline Reinforcement Learning, Conditioned Sequence Models, Return Alignment, Q-Learning, Decision Transformer

## TL;DR
This paper addresses the insufficient alignment of return-to-go (RTG) in conditioned sequence models (e.g., Decision Transformer) by proposing the Q-align DT framework. Through an RTG-to-behavior alignment loss (enforcing monotonic correspondence between RTG and Q-values) and RTG-perturbed training of the Q-function (forming a positive feedback loop), the method achieves SOTA performance on D4RL and significantly reduces alignment error (68.9 vs. QCS 102.3 on HalfCheetah-medium).

## Background & Motivation

**Background**: Conditioned Sequence Models (CSMs) such as the Decision Transformer (DT) frame offline RL as a supervised learning problem, utilizing return-to-go (RTG) as a conditional signal to guide the strategy in generating trajectories of specific return levels, achieving impressive empirical performance on D4RL.

**Limitations of Prior Work**: Ideally, RTG should control the return level of trajectories generated by the policy, but **many CSMs are severely insensitive to RTG**—the actual returns of generated trajectories remain nearly constant even when the input RTG is modified (e.g., on HalfCheetah). This indicates that the models essentially ignore the RTG signal. Existing methods either directly replicate the return distribution of the behavioral policy or treat RTG as a standard token without structurally establishing a correspondence between RTG and policy behavior.

**Key Challenge**: CSMs lack explicit constraints on the RTG-behavior mapping. In an ideal scenario, higher RTG should correspond to trajectories with higher returns (a partial ordering), yet existing methods cannot enforce monotonicity. Furthermore, since offline RL datasets are fixed, directly constructing trajectories that satisfy a total ordering is infeasible.

**Goal**: To enable a single CSM to learn a family of RTG-conditioned policies such that returns of generated trajectories under different RTG conditions precisely track target RTG values while maintaining competitive task performance.

**Key Insight**: The authors observe that an auxiliary Q-function can provide return estimation information, thereby guiding the CSM to learn RTG-behavior alignment. The key innovation is using the **monotonicity** of the Q-function as a constraint target rather than its **absolute value**, which avoids the common over-optimization issues in offline RL.

**Core Idea**: Explicitly constrain policy behavior changes via an RTG-to-behavior alignment loss to ensure that changes in RTG align with the direction of return changes estimated by the Q-function. Simultaneously, co-train the Q-function with RTG perturbation techniques to create a positive feedback loop.

## Method

### Overall Architecture
Two core components are optimized jointly: (1) the DT policy network $\pi_\theta(s, \text{RTG})$ and (2) dual Q-functions $Q_\psi(s, a)$. The policy receives the sequence $\tau_t = (\text{rtg}_{t-k+1}, s_{t-k+1}, a_{t-k+1}, \ldots, \text{rtg}_t, s_t)$. During inference, all RTG tokens can be modified to $\tau_t^g$ (by adding an offset $g$) to achieve fine-grained control over policy behavior. The overall training objective includes supervised learning loss (tracking the dataset) and alignment loss (RTG-behavior monotonicity).

### Key Designs

1. **RTG-to-Behavior Alignment Loss (Relative Ranking Constraint)**:

    - **Function**: Forces the policy to learn a partial ordering where higher RTG must map to behaviors with higher returns as evaluated by the Q-function.
    - **Mechanism**: The RTG monotonicity is formulated as a constrained optimization: $\min_\theta L_{SL}(\theta)$ s.t. $\frac{\partial Q_\psi(s, \pi_\theta(s, \text{RTG}))}{\partial \text{RTG}} \geq 0$. To avoid the overhead of direct gradient computation, a zero-order estimation $\frac{\partial Q}{\partial \text{RTG}} \approx \frac{Q(s, \hat{a}^\delta) - Q(s, \hat{a})}{\delta}$ is used (where $\hat{a}^\delta$ is the predicted action with RTG perturbed by $\delta$). This is converted into a directional ranking constraint $\text{sgn}(\delta) (Q(s, \hat{a}^\delta) - Q(s, \hat{a})) \geq 0$. The loss is defined as $L_{\text{Align}} = \sum_{i=t-k+1}^t I_\mathcal{C} \cdot |Q_\psi(s_i, \hat{a}_i^\delta) - Q_\psi^\perp(s_i, \hat{a}_i)|$, where the indicator function $I_\mathcal{C}$ activates only when the constraint is violated, and $Q_\psi^\perp$ serves as a reference with stopped gradients.
    - **Design Motivation**: Constraining relative order is more conservative than optimizing absolute Q-values, preventing the policy from being pushed toward out-of-distribution high-value actions (a common offline RL issue). Using RTG perturbation instead of point-wise Q-gradients is computationally efficient and more stable.

2. **RTG Perturbation + Dual Q Co-training**:

    - **Function**: Improves Q-function learning so it can correctly evaluate policy behavior across the entire RTG spectrum.
    - **Mechanism**: If the Q-function is trained only on the static distribution of the dataset, it is limited to the return range covered by the data and cannot provide effective guidance for policies under higher RTG conditions. Ours adopts Bellman consistency constraints with RTG perturbation: the Q-function learns $y_i' = r_i + \gamma \min_{m=1, 2} Q_{\psi_m'}^\perp(s_{i+1}, \hat{a}_{i+1}^{', \Delta\text{RTG}})$, where $\hat{a}_{i+1}^{', \Delta\text{RTG}}$ is the action predicted by the target policy after adding a fixed offset $\Delta\text{RTG}$ to the RTG. Conditioned on higher RTG to generate higher-return action candidates, this provides high-quality Bellman targets for Q-function learning.
    - **Design Motivation**: Creates positive feedback—a better Q-function improves the policy via alignment loss, and the improved policy generates higher-quality demonstrations via RTG perturbation, allowing the Q-function to learn more accurate value estimates, which in turn continues to provide feedback to the policy.

3. **Overall Training Objective + Stability Design**:

    - **Function**: Combines alignment loss with supervised learning loss while ensuring training stability via dual Q-functions and stop-gradient operations.
    - **Mechanism**: The total loss is $\mathcal{L}_{\text{total}}(\theta) = L_{SL}(\theta) + \lambda_e L_{\text{Align}}(\theta)$, where $L_{SL}(\theta) = \sum_i \|s_i - \hat{s}_i\|^2 + \|a_i - \hat{a}_i\|^2$ is the standard CSM supervision loss (jointly predicting states and actions). On the Q-function side, standard Double Q-learning practices (two Q-functions + min operation to prevent overestimation) are employed, and stop-gradient operations keep reference Q-values stable.
    - **Design Motivation**: Borrowed stability techniques from standard offline RL ensure that training does not become unstable due to RTG perturbation and joint optimization.

### Key Findings
- **Significant Boost in Alignment**: On HalfCheetah-medium, Q-align DT achieves an alignment error of 68.9 vs. 102.3 for the runner-up QCS, intuitively demonstrating the resolution of the RTG insensitivity issue.
- **Superiority in both Performance and Alignment**: The total score in the Gym domain is 856.9 vs. 812.3 for QCS (a 5.5% improvement), showing that alignment improvements do not sacrifice task performance.
- **Impact of RTG Perturbation**: Ablation studies show that performance drops when $\Delta\text{RTG} = 0$, indicating that sufficient perturbation is vital for Q-function learning; however, excessive perturbation introduces instability, requiring a balance.
- **Zero-shot Generalization**: On the HalfCheetah-Vel (velocity control) task, control over different speeds is achieved solely by modifying RTG values without retraining, proving that the model has learned a truly structured policy family.

## Highlights & Insights
- **From Relative Ranking to Monotonicity Constraints**: The indicator function $I_\mathcal{C}$ applies penalties only when partial ordering is violated, ensuring monotonicity while avoiding over-constraint. This is more stable than direct absolute Q-gradients (solving over-optimization).
- **Dual Role of RTG Perturbation**: Visually, it generates high-quality targets for Q-function learning, but functionally, it improves the effectiveness of the alignment loss by altering policy behavior under high RTG conditions, forming a tight actor-critic positive feedback loop.
- **Unity of Theory and Empirics**: Theoretically proven that alignment constraints reduce the complexity of the hypothesis class $\Pi$ (from $O(|S| |G| \log |A|)$ to $O(|S| |G|)$), explaining why constraints improve sample efficiency and alignment.
- **Transferable Design**: The method is fully generic and applicable to any CSM architecture; RTG perturbation techniques can be generalized to other conditional modeling problems (e.g., dynamic control, goal-conditioned RL).

## Limitations & Future Work
- Requires pre-training Q-functions and maintaining dual Q-networks, increasing computational costs.
- Improvement is relatively limited in extremely sparse reward tasks (e.g., AntMaze), where sparse signals restrict Q-function learning.
- $\Delta\text{RTG}$ requires manual hyperparameter tuning; optimal values vary significantly across tasks, lacking an adaptive mechanism.
- Assumes reasonable coverage in the offline dataset; may fail in extremely non-uniform distributions (containing only very high or very low return trajectories).
- Future Work: Learning $\Delta\text{RTG}$ instead of fixed offsets or using meta-learning for dynamic adjustment; automatically reducing alignment constraint weights based on data coverage; extending to discrete or mixed action spaces.

## Related Work & Insights
- **vs. DT**: DT treats RTG only as a numerical token without structural constraints; Ours explicitly establishes a monotonic correspondence between RTG and returns, representing a major improvement over DT.
- **vs. QT** (Hu 2024): QT directly maximizes Q-values to improve performance, but this causes the policy to collapse into high-value regions within the data distribution, degrading alignment; Ours balances this through alignment constraints and RTG perturbation to achieve both alignment and avoidance of over-optimism.
- **vs. RADT** (Tanaka 2025): RADT enhances RTG sensitivity by adding attention layers, which increases parameter count; Ours is more lightweight (adding only alignment loss and RTG perturbation) and achieves better alignment and performance.
- **vs. IQL / CQL**: Inherits conservative offline RL design philosophies but adapts them by improving the core condition of RTG, opening a new direction for conditioned policy learning.
