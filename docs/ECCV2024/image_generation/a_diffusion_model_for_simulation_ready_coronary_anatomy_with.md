# A Diffusion Model for Simulation Ready Coronary Anatomy with Morpho-skeletal Control

**Conference**: ECCV 2024  
**arXiv**: [2407.15631](https://arxiv.org/abs/2407.15631)  
**Code**: None  
**Area**: Image Generation  
**Keywords**: Coronary artery generation, Latent Diffusion Models, Topological regularization, Morpho-skeletal guidance, Virtual interventional simulation  

## TL;DR
Controllable generation of 3D multi-tissue coronary artery segmentation maps is achieved using Latent Diffusion Models (LDM). Topological interaction loss ensures anatomical plausibility, and decoupled control over cross-sectional morphology and branch structure is obtained through dual-channel morpho-skeletal conditioning. Additionally, Adaptive Null Guidance (ANG) is proposed to efficiently enhance conditional fidelity using a non-differentiable regressor, ultimately supporting counterfactual anatomical editing for finite element simulation.

## Background & Motivation
Virtual interventional simulations, such as coronary artery stenting, require physics-based 3D anatomical structures. Existing methods face a trade-off between realism and controllability: (1) Parametric geometries (e.g., cylinders) are controllable but fail to capture complex 3D micro-morphological details (e.g., calcifications, lumen irregularities); (2) Digital twins reconstructed from medical images are realistic but uneditable, preventing counterfactual reasoning. Device designers require a method that preserves patient-level anatomical complexity while enabling precise control over local morphology (e.g., calcification area curves) and global skeletal structures (e.g., bifurcation topologies), allowing comparative simulation experiments to reveal which anatomical features affect stent deployment outcomes.

## Core Problem
How to ensure that 3D multi-tissue (lumen, outer wall, calcification) coronary artery segmentation maps generated by diffusion models simultaneously satisfy three constraints: (1) Topological correctness—calcifications and the lumen must be enclosed by the outer wall; (2) Controllable local cross-sectional morphology; and (3) Controllable global branching skeletal structures? Furthermore, how can these conditional constraints be efficiently reinforced while preserving generation quality?

## Method
The overall mechanism adapts the standard LDM framework in three layers: regularizing the latent space with a topological loss during the VAE stage, injecting morpho-skeletal condition signals via channel concatenation during the LDM training stage, and reinforcing conditional fidelity with a guidance strategy during the sampling stage.

### Overall Architecture
The input is a 3D multi-channel coronary segmentation map $\mathbf{x} \in \mathbb{R}^{4 \times 128 \times 128 \times 128}$ (4 tissue classes: lumen, vessel wall, calcification, background), which is encoded into a latent representation $\mathbf{z}$ by a VAE. The diffusion model is trained in the latent space. During denoising, the morphological condition map $\mathbf{y}_m$ and skeletal condition map $\mathbf{y}_s$ are injected into the 3D U-Net via channel concatenation. Guidance strategies can be applied during sampling to enhance conditional compliance. The generated latent representation is decoded to produce a 3D segmentation map that can be directly used for finite element simulation.

### Key Designs

1. **Topological Interaction Loss**: A 2D slice-wise topological constraint is integrated into VAE training. Key pixels that violate the condition "calcification/lumen must be enclosed by the vessel wall" are identified (via intersection of neighborhoods dilated with a 4-connected kernel), and a cross-entropy loss is applied to these pixels to correct their labels to the vessel wall. This is computationally much more efficient on 3D data than persistent homology (PH) methods, reducing the topological violation rate from around 16–18% in the training set to approximately 0.5–1%.

2. **Morphological Conditioning**: A morphological regressor $\mathcal{M}$ extracts 2D cross-sectional morphological feature curves from the segmentation map (e.g., variation of lumen area and calcification area along the arterial axis). These curves are normalized and downsampled to construct the condition map $\mathbf{y}_m \in \mathbb{R}^{m \times h \times w \times d}$, which is concatenated into the denoising network. This enables the model to learn to generate a 3D artery of corresponding morphology given a specific cross-sectional area curve.

3. **Skeletal Conditioning**: A skeletal regressor $\mathcal{S}$ (Kimimaro library based on the TEASAR algorithm) extracts the lumen skeleton heatmap $\mathbf{y}_s \in \mathbb{R}^{1 \times h \times w \times d}$, which is concatenated to the latent representation after Gaussian blurring and max pooling. During training, the skeletal condition is set to zero with a probability of 0.2 to jointly train an unconditional model. This allows the model to control the number, position, and shape of the branches.

4. **Adaptive Null Guidance (ANG)**: Unlike traditional CFG which uses fixed null conditions (e.g., zero vectors), ANG dynamically updates the morphological null condition at each denoising step based on the current denoised output. Specifically, the current output is decoded, its morphology is measured using a non-differentiable regressor $\mathcal{M}$ to calculate the deviation from the target morphology, and the null condition is set as $\mathbf{y}_m^{\varnothing} = \hat{\mathbf{y}}_m + (\hat{\mathbf{y}}_m - \mathbf{y}_m)$ (i.e., "current morphology + morphology error"). Consequently, the null condition always points in the direction "away from the target," adaptively amplifying the guidance strength. Skeletal guidance still employs standard CFG (with an empty mask as the null condition). ANG requires no backpropagation, supports non-differentiable regressors, and is computationally far more efficient than loss-based methods.

### Loss & Training
- **Total VAE Loss**: $\mathcal{L} = \mathcal{L}_R + \mathcal{L}_{KL} + \lambda_T \mathcal{L}_T$, where $\mathcal{L}_T$ is the topological interaction loss
- **LDM Denoising Loss**: $\ell_2$ denoising loss under the standard EDM framework, with noise levels sampled from a log-normal distribution and loss weighting $\lambda(\sigma) = 1/c_{out}(\sigma)^2$ ensuring equal weighting across different noise scales
- **Guidance Loss** (when using loss guidance): $\mathcal{L}_m = \|\mathbf{y}_m - \bar{\mathcal{M}}(\hat{\mathbf{x}}_0)\|_2^2$, $\mathcal{L}_s = \|\mathbf{y}_s - \bar{\mathcal{S}}(\hat{\mathbf{x}}_0)\|_2^2$
- Evaluated regressors for five types of guidance strategies: CG-Soft (soft differentiable), DPS-Soft/DPS-NN (differentiable/neural network regressors), CFG (unconditional model), and ANG (non-differentiable regressor)
- Dataset comprises 222 3D patches extracted from 62 CCTA scans, with resolutions of $60\mu\text{m}/0.2\text{mm}$, augmented by random rotations

### Ablation Study
- **Topological loss is highly effective**: Adding the topological interaction loss to the VAE reduces lumen topological violations from 17% to 0.5% (an order of magnitude reduction), similarly benefiting the LDM-generated samples.
- **Joint conditioning outperforms individual conditioning**: Combining morphological and skeletal conditioning significantly improves skeleton fidelity (0.48 vs 3.2 MAE) while maintaining morphological fidelity (4.5 vs 4.0 MAE).
- **ANG is the optimal guidance strategy**: It is the most computationally efficient among all regressor-based guidance methods (46s vs 66–89s), outperforms other methods in both morphological and skeletal fidelity, and requires no backpropagation.
- **CFG fails on this task**: As the guidance scale increases, CFG yields low-quality segmentation maps, demonstrating that fixed null conditions are unsuitable for controlling continuous morphological properties.
- **Morphological conditioning implicitly improves the skeleton**: Applying only morphological conditioning reduces skeleton MAE from 3.2 to 1.2, as the lumen area curve implicitly encodes branching information.

## Highlights & Insights
- **The core insight of ANG is highly elegant**: The null condition should not be random or fixed, but rather a "mirror deviation of the current state." By adaptively constructing the null condition from measurement errors, the guidance direction is constantly pushed from the "current morphology" toward the "target morphology." This is far more logical for controlling continuous attributes than CFG's fixed zero condition.
- **Guidance using non-differentiable regressors** is highly practical and challenges the common assumption that guidance must involve backpropagation. As long as conditional alignment can be measured, null guidance is feasible without gradients.
- **Pragmatic topological regularization**: By avoiding expensive persistent homology (PH) and instead utilizing simple neighborhood dilation, key pixel detection, and cross-entropy, the 3D multi-component topological constraints are successfully addressed.
- **End-to-end to simulation**: Generated segmentation maps can directly undergo ABAQUS finite element simulation (stent deployment balloon expansion), demonstrating clinical utility.
- **Decoupled morpho-skeletal control**: The same morphological curve behaves differently under different skeletons (area increase + branch $\rightarrow$ bifurcation, area increase + no branch $\rightarrow$ lumen enlargement), showcasing true decoupled capability.

## Limitations & Future Work
- **Morphological features are restricted to predefined directions**: Cross-sectional features are coded strictly along the arterial centerline, failing to capture complex radial or circumferential morphological variations.
- **Resolution is limited by 3D voxels**: The $128^3$ voxel grid limits the precision of segmentation maps, while higher resolutions remain computationally prohibitive.
- **Sampling requires decoding at every step**: Although ANG avoids backpropagation, it still requires decoding latent representations back to segmentation maps to measure morphology at each step, adding computational overhead (46 seconds for 100 steps).
- **Residual errors in topological regularization**: The approach does not completely eliminate topological violations (e.g., a remaining 2.61% violation rate for calcifications), necessitating post-processing.
- **Extremely small dataset**: Evaluated on only 222 patches from 62 CCTAs, meaning the generalization capability remains unverified.

## Related Work & Insights
- **vs. Parametric Geometric Methods** (Dong et al., Madani et al.): These methods approximate coronary arteries using primitives like cylinders, which are controllable but lack realistic micro-morphological details. Ours maintains patient-level 3D complexity while incorporating morpho-skeletal control.
- **vs. Template Deformation Methods** (Beetz et al., Pham et al./svMorph): Template methods require anatomical correspondence and consistent topology, which fails for multi-material coronary arteries with irregular calcification distributions. Ours bypasses the correspondence issue through implicit representation and topological regularization.
- **vs. General Diffusion Guidance** (CFG / Classifier Guidance): Experiments demonstrate that standard CFG fails to control continuous morphological attributes (as fixed null conditions are unsuitable), and CG is computationally expensive (66s + 12.5GB). ANG achieves the best trade-off between efficiency and performance for this specific task.

## Insights & Connections
- **ANG can generalize as a universal continuous condition guider**: The core idea—adaptively constructing the null condition from measurement errors—is not limited to medical scenarios. It can be extended to control any continuous attributes (e.g., pose angles, object dimensions, material properties), making it worthy of development as a general framework.
- **Transferable topological regularization**: Constraining the topological validity of multi-class segmentations using simple neighbor relationships can be directly applied to other multi-tissue anatomical structures (such as brain structures or cardiac chambers).
- **Conditional diffusion generation with small datasets**: Generating high-quality controllable anatomy using only 222 training samples paired with conditioning and guidance demonstrates that introducing conditional signals in medical scenarios can heavily compensate for data scarcity.

## Rating
- Novelty: ⭐⭐⭐⭐ The ANG guidance algorithm is innovative, offering a fresh perspective by tailoring diffusion guidance specifically for continuous volume control, though the overall pipeline is a combination of existing techniques.
- Experimental Thoroughness: ⭐⭐⭐⭐ The ablation design is systematic (evaluating 5 guidance strategies, condition combinations, and topological ablations), but the dataset is extremely small (62 cases) and lacks external validation.
- Writing Quality: ⭐⭐⭐⭐⭐ The paper is well-structured, with a rigorous logical progression from problem definition to methodology and ablation studies, accompanied by high-quality illustrations.
- Value: ⭐⭐⭐⭐ It holds direct application value for virtual interventional simulations, and the concept of ANG provides valuable insights for the broader conditional diffusion control community.
