# Learning by Neighbor-Aware Semantics, Deciding by Open-form Flows: Towards Robust Zero-Shot Skeleton Action Recognition

**Conference**: CVPR 2026
**arXiv**: [2511.09388](https://arxiv.org/abs/2511.09388)
**Code**: [https://github.com/cseeyangchen/Flora](https://github.com/cseeyangchen/Flora)
**Area**: Image Generation
**Keywords**: Zero-shot learning, skeleton action recognition, flow matching, cross-modal alignment, semantic calibration

## TL;DR

Flora achieves robust skeleton–semantic cross-modal alignment via neighbor-aware semantic calibration, and constructs a distribution-aware open-form classifier using noise-free flow matching, attaining state-of-the-art performance on zero-shot skeleton action recognition—particularly under low-data training regimes.

## Background & Motivation

Zero-shot skeleton action recognition aims to enable models to recognize skeleton action categories unseen during training, which is critical in practice since collecting large-scale datasets covering all action categories is infeasible. Existing methods generally follow an "align-then-classify" paradigm but suffer from two fundamental problems:

1. **Unreliable semantic anchors**: Whether using LLM-generated descriptive semantics (biased due to lack of explicit skeleton guidance) or parameter-efficiently fine-tuned semantics (prone to overfitting to seen categories), both yield rigid and flawed semantic anchors. Point-to-point cross-modal alignment becomes unstable—some categories are correctly aligned while others are inadvertently misaligned.
2. **Rigid classifiers**: Generative methods synthesize unseen-class features to train linear classifiers, but the resulting decision boundaries are static and cannot adapt to new categories. Embedding-based methods match via cosine similarity, but compressing features into a single vector leads to information loss and coarse-grained classification.

The root cause is that semantic bias and static classifiers jointly constrain generalization in zero-shot settings. The authors' core insight is that although individual semantic anchors may be biased (like mislabeled landmarks on a map), their neighborhood relationships with surrounding anchors remain reliable. Building on this, Flora proposes a new paradigm: *first actively calibrate semantics using neighborhood information, then bridge the modal distribution gap with flow matching*.

## Method

### Overall Architecture

Flora comprises a **learning phase** and a **decision phase**. In the learning phase, each class semantic is first calibrated using contextual information from neighboring classes via neighbor-aware semantic attunement, followed by cross-modal VAE alignment under a geometric consistency objective. In the decision phase, noise-free flow matching establishes a distributional transport bridge between semantic and skeleton latent distributions, enabling fine-grained classification through token-level velocity field prediction.

### Key Designs

1. **Neighbor Semantic Attunement**:
    - *Function*: Actively corrects biased semantic representations generated by LLMs to improve robustness.
    - *Mechanism*: For each semantic feature $\mathbf{F}_{a_y}$, the top-$k$ neighboring class semantics are selected by cosine similarity, and their information is aggregated via a graph-based fusion to obtain a contextualized semantic $\mathbf{O}_{a_y} = \mathbf{F}_{a_y} + \frac{\tau}{k} \sum w_i \mathbf{F}_i$, where $\tau$ prevents over-smoothing and $w_i$ are similarity weights. This expands point-wise semantics into directionally aware regional semantics.
    - *Design Motivation*: Analogous to navigation—even if a landmark's position on a map is erroneous, one can still determine the approximate location by referencing stable surrounding landmarks. The reliable topological relationships of the neighborhood are exploited to correct individual biases.

2. **Geometric Consistency Alignment**:
    - *Function*: Achieves robust cross-modal alignment between skeleton and semantic representations in the latent space.
    - *Mechanism*: A dual-VAE architecture is retained, but the conventional KL divergence regularization toward a standard Gaussian prior is replaced by directly aligning the geometric structure of the two modal distributions (matching means and variances: $\mathcal{L}_{Geo} = \|\mu_s - \mu_a\|_2^2 + \|\sigma_s^2 - \sigma_a^2\|_2^2$). Intra- and cross-modal reconstruction objectives are also preserved.
    - *Design Motivation*: Conventional approaches regularize both modalities toward a standard Gaussian, which achieves alignment at the cost of inter-class discriminability. Directly constraining distributional geometric consistency reduces the modality gap while retaining discriminative structure.

3. **Noise-free Open-form Flow Classifier**:
    - *Function*: Enables fine-grained, scalable zero-shot classification via distributional transport based on flow matching.
    - *Mechanism*: Flow matching is generalized from a generative to a discriminative setting. The source distribution $\mathcal{N}_a$ is set directly to the semantic latent distribution—without Gaussian approximation or noise injection—and the target distribution is the skeleton latent distribution $\mathcal{N}_s$. A token-level velocity field $v_\theta(z_t, t)$ is learned, with contrastive regularization applied to increase velocity prediction error for mismatched class pairs, rendering transport paths discriminative across categories. At inference, the velocity error $\varepsilon_y = \|v_\theta(z_t^y, t) - v_y^*\|_2$ is computed for each candidate class, and the class with minimum error is selected.
    - *Design Motivation*: The semantic-to-skeleton transport paths naturally differ across categories, as both source and target distributions vary by class, endowing the velocity field with inherent discriminative power. Compared to static linear classifiers, the flow classifier is plug-and-play extensible to new categories; compared to cosine similarity, it preserves token-level fine-grained information.

### Loss & Training

Training proceeds in two stages: the alignment objective $\mathcal{L}_{Align} = \mathcal{L}_{Re} + \lambda_{Align} \cdot \mathcal{L}_{Geo}$ is optimized first; parameters are then frozen before training the contrastive flow objective $\mathcal{L}_{ConFlow}$, which jointly incorporates the flow matching loss and a contrastive regularization term $\lambda_{Flow}$. For GZSL inference, a threshold $\gamma$ is introduced to determine whether a sample belongs to the seen or unseen class domain based on the velocity error ratio.

### Key Findings

- Flora performs particularly strongly on the NTU-120 110/10 split (ZSL 80.7%), substantially outperforming the previous SOTA (InfoCPL, 74.8%), demonstrating a clear advantage in scenarios with larger category sets and fewer unseen classes.
- With only 1% of training data, Flora still achieves 84.2% (NTU-60 55/5), demonstrating exceptional low-data generalization—primarily attributable to the flow classifier's independence from synthetic feature-based static classifier training.
- Under the GZSL setting, Flora consistently improves the H-measure, reflecting better balance between seen and unseen class performance.

## Highlights & Insights

- **Extending flow matching from generative to discriminative settings** is the paper's most central contribution. Conventional flow matching is used to generate samples from noise; Flora is the first to propose using the velocity field of a flow for classification, entirely without noise or conditional constraints—a highly elegant design.
- **Neighbor semantic calibration** is conceptually simple yet effective. Rather than training increasingly complex alignment models to accommodate biased semantics, the approach performs "preprocessing" on the semantic side, leveraging neighborhood topology for bias correction. This idea is highly transferable and applicable to any cross-modal alignment task.
- The flow classifier natively supports open-set extension (new categories require only their semantics) and provides token-level fine-grained discrimination—two properties with significant value for future open-world recognition.

## Limitations & Future Work

- Semantics still rely on LLM-generated textual descriptions; although calibration is applied, the fundamental semantic–action gap is not fully resolved.
- At inference, the flow classifier requires computing the velocity error for each candidate class, resulting in linear growth in computational cost as the number of categories increases.
- The two-stage training strategy (alignment first, then flow) has not been explored under end-to-end joint optimization, leaving potential room for further improvement.
- Experiments are primarily conducted on NTU/PKU datasets; generalization at larger scale or across domains is not sufficiently validated.

## Related Work & Insights

- **vs. STAR/PURLS**: These methods directly generate fine-grained semantic descriptions via LLMs for alignment, whereas Flora introduces neighborhood context at the semantic calibration stage, yielding greater robustness.
- **vs. FS-VAE**: Both are based on a Cross-VAE framework, but FS-VAE employs frequency-domain analysis; Flora replaces KL regularization with geometric consistency and introduces the flow classifier, achieving higher H-measure performance.
- **vs. CrossFlow/FlowTok**: These cross-modal flow matching works still apply KL divergence regularization to approximate the source distribution as Gaussian; Flora entirely removes noise injection and conditional constraints.
- The flow classifier paradigm can inspire tasks such as multimodal retrieval and cross-modal matching.

## Rating

- Novelty: ⭐⭐⭐⭐⭐ — First to extend flow matching to discriminative zero-shot classification; the noise-free, unconditional design is highly elegant.
- Experimental Thoroughness: ⭐⭐⭐⭐ — Three datasets with multiple split protocols and compelling low-data experiments, though cross-domain evaluation is absent.
- Writing Quality: ⭐⭐⭐⭐ — Clear logical structure, vivid analogies (map navigation), and complete mathematical derivations.
- Value: ⭐⭐⭐⭐ — Represents meaningful progress in zero-shot skeleton action recognition; the flow classifier concept has strong transfer potential.
