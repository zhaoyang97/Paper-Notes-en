# Learning to Generate and Extract: A Multi-Agent Collaboration Framework for Zero-shot Document-level Event Arguments Extraction

**Conference**: AAAI 2026
**arXiv**: [2603.02909](https://arxiv.org/abs/2603.02909)
**Code**: [github](https://github.com/GJZhang2866/GenExtract)
**Area**: Information Extraction / Event Argument Extraction
**Keywords**: Zero-shot Learning, Document-level Event Argument Extraction, Multi-Agent Collaboration, Reinforcement Learning, Synthetic Data

## TL;DR

This paper proposes a "Propose-Evaluate-Revise" multi-agent collaboration framework (comprising a generator agent and an evaluator agent) to address zero-shot document-level event argument extraction (ZS-DEAE). The generator agent synthesizes training data for unseen event types, while the evaluator agent provides log-likelihood-based quality scores to guide reinforcement learning for iterative optimization, simultaneously improving synthetic data quality and extraction performance.

## Background & Motivation

### Problem Definition

Document-level Event Argument Extraction (DEAE): Given a document $d$, event type $e$, trigger word $t$, and predefined role set $R_e$, extract the argument text spans corresponding to each role from $d$. Zero-shot DEAE (ZS-DEAE): The training set contains only annotated data for seen event types $E_s$; at test time, argument extraction must be performed on unseen event types $E_u$, where $E_s \cap E_u = \emptyset$.

### Limitations of Prior Work

**Knowledge Transfer Methods**: Transfer learning based on shared semantic spaces or prototype networks performs far below supervised models in document-level zero-shot scenarios.

**Direct LLM Application**: Models such as GPT-4o and DeepSeek R1 perform poorly on ZS-DEAE (F1 ≈ 10–24%) due to the strict boundary-matching requirement (Span-F1).

**Synthetic Data Quality Issues**:
   - Data generated by prompting LLMs with only event type names struggles to capture contextual and structural relationships of unseen events.
   - Generated content tends to feature simple sentence structures, dense arguments, and limited contextual richness (as illustrated by the GPT-4o generation examples in Figure 1).
   - The absence of quality assessment mechanisms allows noisy samples to degrade downstream performance.

### Core Motivation — Illustrative Analysis

The event types "inspect people organization" and "physical investigate inspect" both involve an "inspect" action. The former emphasizes the inspection of persons or organizations, while the latter emphasizes physical observation through perception or instrumentation. However, LLM-generated examples frequently fail to distinguish clearly between these event types, and the generated contexts tend to be linguistically simple and argument-dense, lacking the contextual richness and structural complexity required for DEAE.

## Method

### Overall Architecture

The framework simulates the human collaborative cognitive process through a three-stage "Propose-Evaluate-Revise" cycle:

1. **Propose**: The generator agent synthesizes document-level contexts, trigger words, and role–argument pairs for unseen event types and their role sets.
2. **Evaluate**: The evaluator agent extracts arguments from the synthetic data, assesses semantic consistency, and outputs log-likelihood-based quality scores.
3. **Revise**: Evaluation results are converted into reward signals to optimize both agents via policy gradient methods.

### Key Designs

#### 1. **Generator Agent**

Based on LLaMA-3.1-8B or Qwen-2.5-7B, fine-tuned with LoRA (rank=8, scaling=32, dropout=0.05).

Input prompt: $E_{\text{in}}(e, R_e)$ = "Given the event type: $e$ and the following roles: $R_e$, please generate a coherent context..."

Output format: $E_{\text{out}}(d, t, A_e)$ = "Context: $d$, Trigger: $t$, Role-Arguments: $A_e$"

Training objective (autoregressive):

$$\mathcal{L}_g = -\log P(E_{\text{out}} | E_{\text{in}})$$

**Design Motivation**: Leverage knowledge acquired from seen events to transfer data generation capability to unseen event types, with prompt formatting to standardize inputs and outputs.

#### 2. **Evaluator Agent**

Employs Bart-Gen (a conditional generation model based on BART-large) that takes document $d$ and a template sentence with `<arg>` placeholders as input, and outputs the filled template.

Quality scores are based on log-likelihood:

$$\ell_i = \log P(x_i | c_i)$$

Normalized score:

$$\alpha_i = \frac{\ell_i - \mu}{\delta}$$

where $\mu$ and $\delta$ are the mean and standard deviation of log-likelihoods over the entire synthetic dataset $D_{\text{syn}}$.

**Design Motivation**: High-quality samples should exhibit strong semantic consistency between their argument-filled sentences and the document context; log-likelihood thus serves as a natural quality indicator.

#### 3. **Event Structure Constraint**

The generator agent is observed to produce a disproportionately large number of null arguments (roles with no corresponding argument are labeled None). The evaluator agent assigns high scores to correctly predicted None labels, creating a feedback loop that accumulates bias.

**Solution**: A penalty term is introduced based on the null argument ratio $\rho_i$:

$$p_i = \begin{cases} 0 & \text{if } \tau - \varepsilon \leq \rho_i \leq \tau + \varepsilon \\ |\rho_i - \tau| & \text{otherwise} \end{cases}$$

where $\tau$ and $\varepsilon$ are the expected value and standard deviation of the null argument ratio in the training set. The final score is:

$$\alpha_i = \frac{\ell_i - \mu}{\delta} - p_i$$

**Design Motivation**: Constraining the null argument ratio within the distribution of the training data prevents the generation of structurally incomplete event instances.

#### 4. **Reinforcement Learning Optimization (Revise)**

The normalized score $\alpha_i$ serves as the reward signal; both agents are jointly optimized via policy gradient:

$$\mathcal{G}_{i+1} = \mathcal{G}_i + \gamma_1 \nabla_{\mathcal{G}} \mathbb{E}[\alpha]$$

$$\mathcal{E}_{i+1} = \mathcal{E}_i + \gamma_2 \nabla_{\mathcal{E}} \mathbb{E}[\alpha]$$

Gradient computation:

$$\nabla_{\mathcal{G}} \mathbb{E}[\alpha] = \mathbb{E}[\alpha_i \nabla_{\mathcal{G}} \log P(E_{\text{out}} | E_{\text{in}})]$$

$$\nabla_{\mathcal{E}} \mathbb{E}[\alpha] = \mathbb{E}[\alpha_i \nabla_{\mathcal{E}} \log P(x | c)]$$

**Design Motivation**: RL enables learning of data quality preferences without explicit annotation; high rewards guide both agents toward a better understanding of unseen event types.

### Loss & Training

- The generator agent is first pre-trained on $D_s$ using the autoregressive objective.
- The evaluator agent is first trained on $D_s$ using annotated data.
- Five rounds of agent interaction are performed; results are averaged over three random seeds, reporting the best round.
- Evaluation metric: Span-F1 (exact span matching).

## Key Experimental Results

### Experimental Setup

- Datasets: RAMS and WikiEvents; three zero-shot settings are constructed: RAMS2RAMS, RAMS2Wiki, and Wiki2Wiki.
- Generator agent: LLaMA-3.1-8B / Qwen-2.5-7B (LoRA fine-tuned).
- Evaluator agent: BART-large.
- Baselines: 6 DEAE models, 4 zero-shot models, 7 LLMs (including CoT variants).

### Key Findings

1. **Substantial Improvements over Prior Methods**: Across all three zero-shot settings, Ours (LLaMA) outperforms the strongest baseline Bart-Gen by 7.53, 3.86, and 6.14 F1 points, respectively.
2. **Poor Direct LLM Performance**: Models such as GPT-4o and DS-R1 perform far below trained small models on Span-F1 due to difficulties with boundary matching.
3. **RL Reward is the Primary Factor**: Removing the RL reward causes the largest performance drop across all settings.
4. **Structure Constraint is Effective**: Removing the structure constraint increases the null argument ratio and degrades data quality.
5. **Transferability of Synthetic Data**: Augmenting other DEAE models with the synthetic data yields significant gains; data generated directly by LLaMA sometimes proves detrimental (TabEAE W2W: 12.48).
6. **Limited Interaction Rounds**: Optimal performance is achieved within 1–2 rounds; additional rounds lead to decreased diversity and performance degradation.

## Highlights & Insights

1. **"Propose-Evaluate-Revise" Paradigm**: By simulating human collaborative cognition, the generator and evaluator mutually improve through an adversarial interaction process.
2. **Elegant Design of the Structure Constraint**: The paper identifies and resolves the "null argument bias" problem — a feedback loop in which the evaluator assigns high scores to None predictions.
3. **Transferability of Synthetic Data**: The generated data not only serves the framework's own training but also augments other DEAE models, confirming genuine improvements in data quality.
4. **Small Models Outperform Large Models**: An 8B model significantly surpasses 70B LLaMA, GPT-4o, and DeepSeek R1 through the multi-agent collaboration framework.
5. **In-depth Diversity Analysis**: Synthetic data diversity across lexical, semantic, logical, and syntactic dimensions is analyzed as a function of interaction rounds.

## Limitations & Future Work

1. **Diversity Decay**: Additional interaction rounds lead to declining lexical, semantic, and syntactic diversity as models converge toward high-likelihood patterns.
2. **Single Evaluation Dimension**: The evaluator agent scores solely based on log-likelihood, without explicit assessment of factual accuracy or logical consistency.
3. **Limited Dataset Scale**: Experiments are conducted on RAMS and WikiEvents, which are relatively small; performance on larger-scale datasets remains unknown.
4. **Reliance on Event Type Overlap**: The zero-shot setting permits role sharing to preserve event schemas; completely disjoint role configurations have not been tested.
5. **Capacity Imbalance between Agents**: The generator uses an 8B LLM while the evaluator uses BART-large; this scale discrepancy may affect collaborative dynamics.

## Related Work & Insights

- **RAMS/WikiEvents**: Standard benchmarks for document-level event argument extraction.
- **Bart-Gen (Li 2021)**: A conditional generation framework for event extraction; serves as the foundation of the evaluator agent in this work.
- **VIPER/PAIE/TabEAE**: Baseline methods representing various approaches to event extraction.
- **RL for NLP**: Applying reinforcement learning to optimize text generation quality.
- **Implication for Zero-shot Information Extraction**: Multi-agent collaboration may be more effective than single-model direct inference for zero-shot IE scenarios.
