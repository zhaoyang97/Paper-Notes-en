# DoraCycle: Domain-Oriented Adaptation of Unified Generative Model in Multimodal Cycles

**Conference**: CVPR 2025  
**arXiv**: [2503.03651](https://arxiv.org/abs/2503.03651)  
**Code**: [https://github.com/showlab/DoraCycle](https://github.com/showlab/DoraCycle)  
**Area**: Image Generation  
**Keywords**: Domain Adaptation, Unified Generative Models, Cycle Consistency, Unpaired Training, Multimodal Cycles

## TL;DR
DoraCycle is proposed to achieve unpaired domain adaptation of unified multimodal generative models using two multimodal cycles (text $\to$ image $\to$ text and image $\to$ text $\to$ image). Utilizing only unpaired target domain data, it achieves performance close to fully paired training (FID 27.44 vs 24.93), and is virtually lossless with 10% paired + 90% unpaired data (FID 25.37).

## Background & Motivation

**Background**: Unified multimodal generative models such as Show-o can simultaneously perform text-to-image and image-to-text generation. However, adapting them to a new target domain (e.g., a specific painting style or a unique character identity) typically requires paired text-image data.

**Limitations of Prior Work**: (1) Paired text-image data in the target domain is difficult to collect (especially for specific characters/styles). (2) Methods like DreamBooth require fully paired data, and their alignment quality highly relies on manual annotations. (3) Existing domain adaptation approaches are designed for single-modality models and cannot leverage the bidirectional generation capabilities of unified models.

**Key Challenge**: Since unified models inherently possess bidirectional generation capabilities (text $\leftrightarrow$ image), can this symmetry be exploited to perform self-supervised learning from unpaired data?

**Goal**: To leverage the bidirectional capabilities of unified models to achieve domain adaptation on unpaired target domain data via cycle consistency.

**Key Insight**: Design two cross-modal cycles—T cycle (text $\to$ image $\to$ text) and I cycle (image $\to$ text $\to$ image)—applying reconstruction losses in the same modality space at the cycle endpoints. An EMA model is introduced to stabilize the generation of pseudo intermediate data, and gradient surgery is applied to balance the optimization directions of the two cycles.

**Core Idea**: Leverage the text $\leftrightarrow$ image bidirectional generative ability of unified multimodal models to achieve unpaired domain adaptation through dual cycle consistency of "text $\to$ image $\to$ text" and "image $\to$ text $\to$ image".

## Method

### Overall Architecture
Unpaired target-domain text + unpaired target-domain image $\to$ T cycle: text $\to$ pseudo-image generated by EMA model $\to$ reconstructed text by the model (CE loss) $\to$ I cycle: image $\to$ pseudo-text generated by EMA model $\to$ reconstructed image by the model (token CE loss) $\to$ gradient surgery to balance both cycles.

### Key Designs

1. **Dual Multimodal Cycles**:

    - **Function**: Achieve self-supervised domain adaptation from unpaired data.
    - **Mechanism**: The T cycle enforces text $\to$ image $\to$ text consistency (ensuring that generated images preserve textual semantics), while the I cycle enforces image $\to$ text $\to$ image consistency (ensuring that generated descriptions can reconstruct the original image). Together, they cooperatively cover bidirectional alignment.
    - **Design Motivation**: Ablation studies show that using the I cycle alone (FID 28.93) or the T cycle alone (FID 36.63) is inferior to the dual-cycle approach (FID 27.44), proving that they are complementary.

2. **EMA Stabilization**:

    - **Function**: Generate stable pseudo intermediate data.
    - **Mechanism**: An EMA model (slowly updated with $\alpha = 0.999$) is employed to generate intermediate pseudo data (pseudo-images for the T cycle, pseudo-text for the I cycle) to prevent training collapse caused by noisy pseudo data generated by the active model itself.
    - **Design Motivation**: Direct generation of pseudo data using the active model leads to error accumulation and mode collapse.

3. **Gradient Surgery**:

    - **Function**: Prevent conflicting gradient directions between the two cycles.
    - **Mechanism**: Compute the gradient directions of the T cycle and I cycle. When their directions conflict (negative dot product), the T cycle gradient is projected onto the direction orthogonal to the I cycle gradient.
    - **Design Motivation**: The two cycles optimize reconstruction quality in different modalities, which may lead to conflicting directions; gradient surgery ensures they do not cancel each other out.

### Loss & Training
$\mathcal{L} = \mathcal{L}_{real} + \mathcal{L}_{syn}$, where the T cycle uses token-level CE to reconstruct text, and the I cycle uses image token CE to reconstruct images. LoRA with rank=32 is applied to attention layers 7-24. $\beta = 0.1$ is used as the weight for the T cycle.

## Key Experimental Results

### Main Results

| Method | Data Type | FID-1K↓ | CIDEr↑ | T2I Align↑ |
|------|---------|---------|--------|-----------|
| DreamBooth | 10% Paired | 33.22 | 32.74 | 3.25 |
| DreamBooth | 100% Paired | 24.93 | 41.55 | 4.13 |
| **DoraCycle** | **100% Unpaired** | **27.44** | **38.17** | **3.84** |
| **DoraCycle** | **10%P+90%U** | **25.37** | **40.90** | **4.12** |

### Ablation Study

| Cycle | FID↓ | Description |
|------|------|------|
| I cycle only | 28.93 | Insufficient Text $\to$ Image direction |
| T cycle only | 36.63 | Insufficient Image $\to$ Text direction |
| I+T Dual Cycle | **27.44** | Complementary, achieves best results |
| 10% Paired + 90% Unpaired | **25.37** | Close to 100% Paired (24.93) |

### Key Findings
- **100% unpaired achieves near fully-paired quality**: FID 27.44 vs 24.93, with a gap of only about 10%.
- **Minimal paired + massive unpaired is optimal**: Just 10% paired data is sufficient to close the gap (25.37 vs 24.93).
- **Spontaneous conceptual association**: After training, the model can annotate an unseen "black cat" with domain-specific tokens, showing the spontaneous generalization of domain concepts.

## Highlights & Insights
- **Utilizing the symmetry of unified models for self-supervision** is highly elegant—bidirectional generation naturally provides the conditions for cycle consistency.
- **Highly significant for real-world scenarios**: Collecting paired data for many target domains (e.g., custom artistic styles, specific characters) is difficult, and DoraCycle makes such adaptation feasible.

## Limitations & Future Work
- The quality of pseudo data generated by the EMA model relies on the capabilities of the base model; if the base model has zero prior knowledge about the target domain, the cycle cannot start.
- Identity-specific tasks still require 1-3 paired images (purely unpaired is insufficient), whereas style transfer can be completely unpaired.
- The method is only validated on Show-o, and remains untested on other unified models (e.g., Chameleon, Emu).

## Related Work & Insights
- **vs DreamBooth**: Requires fully paired data. DoraCycle achieves close performance using only 10% paired + 90% unpaired data.
- **vs CycleGAN**: Classic cycle consistency but targeted towards image-to-image. DoraCycle extends cycle consistency to cross-modal scenarios.
