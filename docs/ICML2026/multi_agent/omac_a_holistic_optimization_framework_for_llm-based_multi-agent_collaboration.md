# OMAC: A Holistic Optimization Framework for LLM-Based Multi-Agent Collaboration

**Conference**: ICML 2026  
**arXiv**: [2505.11765](https://arxiv.org/abs/2505.11765)  
**Code**: https://github.com/xiwenchao/OMAC  
**Area**: LLM Agent / Multi-Agent Systems / Code Generation  
**Keywords**: Multi-Agent Systems, Collaborative Optimization, Contrastive Reasoning, Prompt Evolution, Supervised Optimization

## TL;DR
This paper formalizes the optimization space of multi-agent systems (MAS) into five dimensions (two functional + three structural), and applies a dual-actor algorithm—"Semantic Initializer generation + Contrastive Comparator improvement"—to perform supervised optimization on each dimension. It then iteratively and jointly optimizes multiple dimensions, consistently outperforming baselines such as DyLAN, ADAS, and AFlow on HumanEval, MMLU, and MATH.

## Background & Motivation

**Background**: Multi-agent systems (MAS) have demonstrated capabilities surpassing single agents in tasks such as code generation (AgentVerse), reasoning (LLM Debate), and decision-making (Sun 2024). However, most existing MAS rely on manual design—agent roles are determined by human priors or directly generated by LLMs, and collaboration structures use fixed centralized/decentralized/hierarchical topologies. A few automated approaches, such as DyLAN (dynamic agent team selection), ADAS (prompt evolution), AFlow (MCTS architecture search), and G-Designer/MaAS (architecture search), only optimize a single aspect.

**Limitations of Prior Work**: (1) DyLAN uses an unsupervised "agent importance score," lacking supervised signals derived from training data; (2) ADAS / AFlow / G-Designer / MaAS only optimize one aspect (prompt *or* architecture); (3) None of these methods can simultaneously optimize agent functionality (prompt/few-shot) and collaboration structure (candidate selection / dynamic participation / communication flow), lacking a unified framework.

**Key Challenge**: MAS are essentially information flow graphs—both nodes (agents) and edges (communication links) can be optimized. However, existing methods either only modify nodes or only edges, and there is no general algorithm that can handle both simultaneously.

**Goal**: To construct a unified framework that can use the same algorithm to supervise and optimize any dimension of MAS, and iteratively and jointly optimize multiple dimensions.

**Key Insight**: By conceptualizing the MAS collaboration process as an information flow graph, the authors identify five core optimizable dimensions—two concerning nodes (agents) and three concerning the graph (structure); all five can be reduced to "optimizing a segment of LLM instruction prompt (with optional few-shot examples)."

**Core Idea**: Employ a pair of LLM-driven actors—Semantic Initializer to explore the semantic space and generate diverse initial prompt sets, and Contrastive Comparator to generate improved prompts by contrasting high- and low-scoring pairs—for supervised contrastive reasoning optimization on each dimension, then iteratively optimize multiple dimensions one at a time.

## Method

### Overall Architecture
OMAC takes as input an existing MAS configuration (multiple agents + collaboration topology) and a training set with supervised evaluation metrics (e.g., HumanEval Pass@1). The framework consists of two layers: (1) **Single-Dimension Optimization Algorithm**—select one of the five dimensions, use the Semantic Initializer to generate $n$ candidate agent/controller prompts, run the full MAS collaboration on the training set to obtain performance scores; sample a positive and negative pair based on upper/lower thresholds $h, l$ and feed them to the Contrastive Comparator, which performs contrastive reasoning to generate improved candidates to add to the set; repeat for a preset number of iterations. (2) **Multi-Dimension Joint Optimization**—select multiple dimensions to jointly optimize, iterating serially by "fixing others, optimizing one," to avoid attribution confusion for the Contrastive Comparator when multiple dimensions change simultaneously.

### Key Designs

1. **Partitioning the Five-Dimensional Optimization Space**:

    - **Function**: Systematically divides all optimizable parts of MAS into five mutually exclusive dimensions—Fun-1 (optimizing prompts/few-shot for existing agents), Fun-2 (constructing new agents), Str-1 (candidate agent selection controller), Str-2 (stepwise dynamic participation controller), Str-3 (agent communication flow controller).
    - **Mechanism**: Treat MAS as an information flow graph, with nodes as agents and edges as communication links; Fun-1/2 optimize node capabilities (modify existing nodes / add new nodes), Str-1/2/3 optimize graph structure (global team selection / local stepwise selection / edge routing). All five dimensions reduce to "optimizing an LLM prompt," so the same algorithm applies, only the context description changes.
    - **Design Motivation**: Previous works each covered only one dimension (DyLAN optimizes Str-1, ADAS/AFlow mainly combine Str-3 + Fun-2, etc.), lacking a unified coordinate system. By clarifying the dimensions, the authors find all five have independent improvement potential and can be combined.

2. **Semantic Initializer + Contrastive Comparator Dual-Actor Algorithm**:

    - **Function**: Uses two LLM-driven actors for supervised optimization on each dimension—the former for exploration (generating diverse initial sets), the latter for exploitation (contrastive improvement).
    - **Mechanism**: The Semantic Initializer receives context (task description + current MAS configuration + dimension specification + a one-shot example) and number $n$, prompting the LLM to generate diverse candidates in the semantic space while preserving functionality. Each candidate is evaluated on the training set, and a positive/negative pair is sampled based on top-$\lfloor n h \rfloor$ / bottom-$\lfloor n l \rfloor$ thresholds for the Contrastive Comparator, which performs contrastive reasoning—"Why is A better than B? Reinforce A's strengths, remove B's weaknesses, and generate a new version better than A." The new candidate is added to the set, and the process repeats.
    - **Design Motivation**: Simply prompting the LLM is unsupervised exploration, not fully utilizing training set scores. Contrastive reasoning uses "performance difference" as a supervision signal, leveraging the LLM's own reasoning for attribution—a lightweight, gradient-free "pseudo RL." Changing only one dimension per contrastive pair avoids attribution confusion.

3. **Iterative Multi-Dimension Joint Optimization**:

    - **Function**: Rotates optimization across multiple dimensions, changing only one per round while fixing others, to avoid combinatorial explosion and attribution failure in the Comparator.
    - **Mechanism**: First, run single-dimension optimization independently for each dimension and select the most beneficial ones; during joint optimization, optimize dim-1 and keep the best, then switch to dim-2 and optimize with dim-1 fixed, then return to dim-1, and so on, until the iteration limit is reached. The paper shows that jointly optimizing the two most beneficial functional dimensions, or the strongest functional + strongest structural dimension, yields the best results.
    - **Design Motivation**: Iterative rather than parallel optimization ensures clear attribution for the Contrastive Comparator—each contrastive pair changes only one dimension, with others fixed at their current optimum, making the cause of differences interpretable and avoiding confusion from "multiple variables affecting performance." Ablation shows that letting the Comparator reason over multiple changing dimensions yields smaller gains and higher variance.

### Loss & Training
OMAC does not update model parameters; all "optimization" is prompt engineering. The supervision signal is the MAS's task metric on the training set (HumanEval Pass@1 / MMLU Accuracy / MATH Accuracy). The base LLM is gpt-3.5-turbo-1106, temperature 0.8; the Semantic Initializer generates 3 candidates per round; contrastive reasoning iteration limit is 3; thresholds $l=h=0.5$; each experiment is run 3 times and reports mean ± std.

## Key Experimental Results

### Main Results
Benchmark tasks: HumanEval (code generation, Pass@1), MMLU (general reasoning, Accuracy), MATH (arithmetic reasoning, Accuracy). Default MAS configuration from DyLAN (7 agents for code, 7 for reasoning, 4 for arithmetic), fully connected topology.

| Task | Strongest Baseline | Baseline Score | OMAC Best Single-Dim | Dimension |
|------|-------------------|---------------|----------------------|-----------|
| HumanEval (Pass@1) | AFlow | 85.63 | 89.25 ± 1.30 | Fun-1.4 |
| MMLU (Accuracy) | ADAS | 69.02 | 74.22 ± 2.22 | Fun-1.4 |
| MATH (Accuracy) | AFlow | 32.49 | 35.17 ± 1.96 | Fun-1.1 |

Joint optimization (MATH task, 3 iterations):

| Optimization Strategy | Performance Gain (vs. default MAS) |
|----------------------|------------------------------------|
| Best Single Dimension | ~2.9% |
| Two Strongest Dimensions, 3 Iterations | ~9.6% |

### Ablation Study
OMAC-C: Removes the Contrastive Comparator, only uses the Semantic Initializer to generate the initial set and selects the highest score.

| MATH Dimension | OMAC-C | OMAC | Comparator Gain |
|---------------|--------|------|----------------|
| Str-1 | 32.64 | 33.34 | +0.70 |
| Str-2 | 32.67 | 33.41 | +0.74 |
| Str-3 | 32.76 | 33.70 | +0.94 |
| Fun-1.1 | 34.20 | 35.17 | +0.97 |
| Fun-2 | 32.71 | 33.95 | +1.24 |

### Key Findings
- **All five dimensions offer independent improvement**: Average single-dimension gains are 3.6% (HumanEval), 2.8% (MMLU), 4.9% (MATH), confirming the five-way split captures orthogonal optimization directions.
- **Functional dimensions generally yield higher gains than structural**: Fun-1.x delivers the highest single-dimension improvements across all tasks, indicating that modifying agent prompts is more direct than changing collaboration topology.
- **Joint optimization yields more than the sum of single dimensions**: On MATH, best single-dimension gain is 2.9%, joint is 9.6%, indicating synergy between structure and function optimization. "Selecting the two strongest dimensions" consistently outperforms random or weakest combinations.
- **Comparator is indispensable**: Removing contrastive reasoning (OMAC-C) reduces performance in all dimensions, proving supervised contrastive reasoning is more efficient than pure exploration; however, OMAC-C still outperforms DyLAN, showing the value of diverse exploration by the Semantic Initializer.
- **Reduced inference cost**: Dynamic agent selection and communication flow optimization allow OMAC to use fewer agents at inference than baselines, significantly reducing token consumption.

## Highlights & Insights
- **Formalizing MAS optimization space as a five-dimensional coordinate system**: Previously, each MAS optimization paper defined "optimization" differently; this work provides a clear graph-theoretic coordinate system (node capability × graph structure) that covers existing work and is cleanly extensible.
- **Contrastive reasoning as a lightweight supervision signal**: No gradients or RL training needed; the LLM's own reasoning translates "performance gap" into "prompt improvement," making it a nearly universal paradigm transferable to any "optimizing natural language segment" scenario.
- **"One dimension at a time" iterative principle**: This seemingly simple engineering choice reflects a clear understanding of LLM attribution limitations—changing multiple variables simultaneously leads to incorrect causal attribution, as quantified by ablation.
- **Compatible with any MAS base design**: OMAC takes "existing MAS configuration" as input and outputs "optimized MAS," so any manually designed MAS (including future, more complex ones) can be further improved by OMAC.

## Limitations & Future Work
- **Dependence on supervised signals from training set**: Not directly applicable to open-ended tasks without clear metrics (e.g., open-domain dialogue quality, long-term agent planning); only limited supplementary experiments on open tasks like GAIA.
- **Optimization quality limited by LLM's own reasoning ability**: Main experiments use GPT-3.5; weaker LLMs as Comparator may yield unstable contrastive reasoning; appendix includes GPT-4 experiments but lacks space for details.
- **Combinatorial explosion in joint optimization**: Fully joint optimization across all five dimensions requires $5^k$ times the compute of single-dimension ($k$ is iteration rounds), so only the top two or three dimensions can be selected, precluding truly comprehensive joint optimization.
- **Does not address agent role conflicts**: After Fun-2 (adding new agents), MAS may have overlapping or conflicting roles; the paper does not discuss detection or resolution.
- **Empirical training data subset sampling**: Appendix notes that evaluating candidates on a subset of training data saves compute, but subset size and sampling strategy lack theoretical analysis.

## Related Work & Insights
- **vs DyLAN (2024)**: DyLAN uses unsupervised Agent Importance Score to optimize only candidate selection (Str-1); OMAC uses supervised contrastive reasoning across five dimensions and outperforms DyLAN on Str-1.
- **vs ADAS / AFlow**: Both mainly perform architecture search (prompt evolution / MCTS), optimizing Fun-2 + part of Str-3; OMAC uses a lighter contrastive reasoning algorithm and consistently outperforms across broader dimensions.
- **vs G-Designer / MaAS**: Pure structure search methods; OMAC is not weaker on structural dimensions (Str-1/2/3 all outperform them) and can additionally optimize functional dimensions.
- **vs gradient-based methods (SFT / prompt tuning)**: Single-agent optimization approaches, unable to handle multi-step MAS collaboration; OMAC requires no gradients, relying on LLM reasoning instead.
- **vs RL-based MAS optimization (Shao 2024, Liu 2025)**: Typically limited to single-step interaction or shared policies; OMAC naturally handles multi-step, role-specialized MAS.

## Rating
- Novelty: ⭐⭐⭐⭐ The five-dimensional split and dual-actor contrastive reasoning algorithm are clear conceptual contributions; while individual components are not disruptive, their combination forms a new paradigm.
- Experimental Thoroughness: ⭐⭐⭐⭐ Three classic benchmarks + two challenging benchmarks (MBPP/GAIA) + ablation + multiple baseline comparisons, with fairly complete hyperparameter studies.
- Writing Quality: ⭐⭐⭐⭐ Clear framework, intuitive diagrams, few formulas but each design's "why" is well explained.
- Value: ⭐⭐⭐⭐ A plug-and-play optimization suite for practical MAS, with a paradigm transferable to any "optimizing natural language instructions" scenario.
