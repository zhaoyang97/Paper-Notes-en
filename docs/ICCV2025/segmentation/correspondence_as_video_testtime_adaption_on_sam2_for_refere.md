# Correspondence as Video: Test-Time Adaption on SAM2 for Reference Segmentation in the Wild

**Conference**: ICCV 2025
**arXiv**: [2508.07759](https://arxiv.org/abs/2508.07759)
**Code**: [https://github.com/wanghr64/cav-sam](https://github.com/wanghr64/cav-sam)
**Area**: Segmentation / Few-Shot Segmentation / Cross-Domain Segmentation
**Keywords**: SAM2, reference segmentation, pseudo-video, diffusion-based transition, test-time adaptation, few-shot segmentation

## TL;DR
This paper represents the correspondences between reference-target image pairs as a pseudo-video sequence generated by a diffusion model, leverages SAM2's interactive video object segmentation (iVOS) capability for segmentation, and combines lightweight test-time fine-tuning to handle geometric variation. The proposed method outperforms state-of-the-art approaches by approximately 5% mIoU on cross-domain few-shot segmentation without requiring any meta-training.

## Background & Motivation
Although SAM/SAM2 exhibit strong segmentation capabilities, domain gaps and category novelty remain persistent challenges in downstream domains such as medical imaging and remote sensing. Reference segmentation—segmenting a target image given a reference image and its mask—offers a promising adaptation paradigm. However, existing methods (FSS/CD-FSS) predominantly rely on meta-learning, which demands substantial episodic training data and computational resources. A key insight motivating this work is that SAM2 already possesses iVOS capability: given annotations on a few frames, it can track and segment objects throughout an entire video. If a reference-target image pair can be treated as video frames, SAM2's iVOS capability can be directly exploited, bypassing the need for meta-training.

## Core Problem
The central challenge is how to transform discrete reference-target image pairs into a continuous pseudo-video sequence processable by SAM2. Two sub-challenges arise: (1) **semantic gap**—iVOS tracks the same instance, whereas reference segmentation must handle intra-class variation across different instances of the same category; (2) **geometric variation**—pose, scale, and occlusion differences between reference and target images may far exceed the smooth-motion assumption of iVOS.

## Method

### Overall Architecture
CAV-SAM (Correspondence As Video for SAM) comprises two core modules: (1) **DBST**, which employs a diffusion model to generate intermediate transition frames between the reference and target images, constructing a semantically smooth pseudo-video sequence; and (2) **TTGA**, which extracts prototype vectors via test-time fine-tuning to activate target objects in pseudo-video frames as additional prompts for SAM2, thereby handling geometric variation. No meta-training is required throughout.

### Key Designs
1. **DBST (Diffusion-Based Semantic Transition)**: Built upon DiffMorpher, DBST generates a semantic transition sequence between the reference and target images using a diffusion model. Specifically, the diffusion model is independently fine-tuned with LoRA on each image to obtain $\Delta\theta_r$ and $\Delta\theta_t$. The LoRA parameters are then linearly interpolated as $\Delta\theta_\alpha = (1-\alpha)\Delta\theta_r + \alpha\Delta\theta_t$, while the latent noise obtained via DDIM inversion is spherically linearly interpolated. Intermediate frames are generated at different values of $\alpha$ (9 frames spanning 0.2–0.8), yielding a semantically smooth pseudo-video. A key optimization is the removal of the unnecessary visual refinement module in DiffMorpher—basic semantic transition is sufficient for SAM2—significantly reducing computational cost.

2. **TTGA (Test-Time Geometric Alignment)**: A lightweight test-time fine-tuning procedure is performed using only the reference image and its mask (fine-tuning only the FPN neck of the SAM2 image encoder, for 100 steps). An Augmented Cyclic Consistency (ACC) loss is proposed: prototype vectors predict pseudo-labels on augmented images, and the results are used to verify predictions on the original image. After fine-tuning, the encoder produces improved features; prototype vectors then activate target regions in pseudo-video frames via cosine similarity combined with Otsu thresholding, generating pseudo-labels as additional prompts for SAM2 to compensate for geometric variation.

3. **Key Insight—Simple Concatenation Already Approaches SOTA**: Even naive concatenation of reference and target images allows SAM2 to achieve 60.68 mIoU, approaching the CD-FSS SOTA of ~61. This demonstrates the substantial untapped potential of iVOS models for reference segmentation. DBST and TTGA further improve performance to 64.06.

### Loss & Training
- DBST: LoRA rank = 16, lr = 2e-4, 200 steps, DDIM inversion with 20 steps
- TTGA: lr = 1e-3, cosine annealing, 100 steps, fine-tuning FPN neck only
- Loss: $\mathcal{L} = \mathcal{L}_{aug} + \mathcal{L}_{cyc}$ (BCE loss)
- SAM2-tiny is used as the base model

## Key Experimental Results

| Method | Training Requirement | Deepglobe | ISIC | Chest X-Ray | FSS-1000 | Avg (1-shot) |
|--------|----------------------|-----------|------|-------------|----------|--------------|
| SSP (ECCV22) | Large-scale meta-train | 40.48 | 35.09 | 74.23 | 79.03 | 57.20 |
| APSeg (CVPR24) | Meta-train + SAM | 35.94 | 45.43 | 84.10 | 79.71 | 61.30 |
| DR-Adaptor (CVPR24) | Meta-train | 41.29 | 40.77 | 82.35 | 79.05 | 60.86 |
| **CAV-SAM** | **TTA only** | **39.11** | **50.36** | **86.97** | **79.78** | **64.06** |

- Average mIoU surpasses SOTA by approximately **5%** (61.30 → 64.06 for 1-shot)
- Stronger performance in the 5-shot setting: 69.14 avg, outperforming APSeg (65.09) by 4.05
- Largest gain on the most challenging Chest X-Ray benchmark: 84.10 → 86.97 (+2.87)
- Simple concatenation baseline already achieves 60.68; DBST and TTGA progressively raise this to 64.06
- DEVA can substitute for SAM2: 49.57 → 59.93

### Ablation Study
- DBST contributes +2.0 mIoU; TTGA contributes +1.38 mIoU
- Heuristic approaches (mixup/affine augmentation) perform worse than the concatenation baseline (52.21/56.84 vs. 60.68), confirming the importance of natural semantic transitions
- ACC outperforms ABC (64.06 vs. 61.54), demonstrating that cyclic consistency is more robust than bidirectional consistency
- DBST is insensitive to visual quality—although the lightweight variant produces visually inferior outputs compared to full DiffMorpher, segmentation performance remains consistent

## Highlights & Insights
- **Highly creative perspective shift**: Reframing reference segmentation as an iVOS problem on pseudo-videos entirely circumvents the complexity of meta-learning frameworks.
- **The finding that SAM2 concatenation already approaches SOTA** is particularly informative—it suggests that iVOS models have implicitly learned powerful inter-image correspondence capabilities.
- **Diffusion models as semantic bridges**: Rather than generating visually appealing images, diffusion models are used to construct natural semantic transitions, representing a novel application angle.
- **Completely meta-training-free**: Only 100 steps of test-time fine-tuning are required, substantially reducing data and computational demands.
- **Graceful handling of semantic inconsistency**: When the reference and target belong to different categories, DBST naturally generates a "meaningless" transition, TTGA activates no regions, and SAM2 produces no segmentation—the system fails gracefully by design.

## Limitations & Future Work
- Generating pseudo-videos with a diffusion model incurs non-trivial overhead (LoRA training + DDIM inversion)
- Performance on Deepglobe (region segmentation rather than object segmentation) lags behind meta-learning methods
- The number of pseudo-video frames ($N_v = 9$) is fixed; longer transition sequences may yield further improvements
- The capacity of SAM2-tiny may limit segmentation precision; larger SAM2 variants could deliver better results
- One hundred steps of test-time fine-tuning remains too slow for real-time applications

## Related Work & Insights
- **vs. APSeg/VRP-SAM**: These methods introduce meta-learning prompt encoders into SAM, requiring substantial episodic training; CAV-SAM requires no meta-training whatsoever.
- **vs. CD-FSS methods (PATNet/IFA/DR-Adaptor)**: These methods require meta-training on large datasets; CAV-SAM replaces this with diffusion-based transition and TTA.
- **vs. SAM2Long**: SAM2Long addresses error accumulation in long videos; CAV-SAM addresses the transformation of discrete image pairs into pseudo-videos—different problem settings, yet both represent innovative applications of SAM2.
- **Potential extensions**: The pseudo-video paradigm can be extended to other vision tasks requiring pairwise correspondence, such as image retrieval, registration, and change detection.
- Using diffusion models as "semantic bridges" is a novel angle worth exploring in other cross-domain and cross-modal tasks.
- A combination with SAM2Long—DBST-generated pseudo-videos paired with SAM2Long's tree-search inference—could yield a more robust inference pipeline.

## Rating
- Novelty: ⭐⭐⭐⭐⭐ — The perspective of "correspondence as video" is a genuinely creative reframing; using diffusion models to generate semantic transition sequences represents a wholly novel application angle.
- Experimental Thoroughness: ⭐⭐⭐⭐ — Evaluated on 4 CD-FSS datasets with comparisons against multiple baselines, ablations of heuristic vs. diffusion-based transitions, and ACC vs. ABC.
- Writing Quality: ⭐⭐⭐⭐ — Problem analysis is clear (Figure 2's decomposition of semantic gap and geometric variation is well-structured); method description is systematic.
