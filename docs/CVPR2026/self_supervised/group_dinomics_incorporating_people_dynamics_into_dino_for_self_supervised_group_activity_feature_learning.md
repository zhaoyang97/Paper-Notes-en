# Group-DINOmics: Incorporating People Dynamics into DINO for Self-supervised Group Activity Feature Learning

**Conference**: CVPR 2026
**arXiv**: [2604.04467](https://arxiv.org/abs/2604.04467)  
**Code**: [https://github.com/tezuka0001/Group-DINOmics](https://github.com/tezuka0001/Group-DINOmics)  
**Area**: Self-supervised Learning
**Keywords**: group activity, self-supervised learning, DINO, optical flow, activity retrieval

## TL;DR

This paper proposes leveraging DINOv3 with two self-supervised pretraining tasks — individual optical flow estimation and group-relevant object localization — to learn group activity features (GAF), achieving substantial improvements over existing methods without any group activity annotations.

## Background & Motivation

Group activity analysis has important applications in sports analytics, robotics, and surveillance. Self-supervised GAF learning eliminates the need for large-scale manual annotation and predefined activity categories. However, existing methods (e.g., HRN, GAFL) rely solely on local image reconstruction as the pretraining objective, embedding only local appearance cues (e.g., clothing texture) while lacking two critical capabilities: (1) motion dynamics of individual persons (local dynamics); and (2) global features such as the spatial configuration of the group.

Although DINOv3 balances local and global features, direct application remains insufficient: its general-purpose features, trained on static images, contain substantial local cues irrelevant to group activities (e.g., floor texture) and lack temporal motion representations.

## Method

### Overall Architecture

DINOv3 extracts image features → Transformer encoder + MLP → temporal pooling to obtain GAF. During training, two pretraining tasks supervise the estimation of individual optical flow and group-relevant object positions from the GAF.

### Key Designs

1. **Individual Optical Flow Estimation**: The model estimates per-person $xy$ optical flow values from the GAF, encouraging it to encode local dynamic features. An auxiliary branch is designed to estimate optical flow directly from single-frame features, addressing the limitation that DINOv3 is trained only on static images. This shortens the backpropagation path and drives DINOv3 to learn motion-aware representations.

2. **Group-Relevant Object Localization with Inpainting**: During training, group-relevant objects (e.g., balls) are inpainted in the input images, and the model estimates object positions from the GAF. Inpainting prevents the model from relying on local appearance cues of the objects, instead forcing it to infer object positions from global context (i.e., the spatial configuration of the group), thereby embedding global structural features.

3. **Two-Stage Training**: Stage 1 trains for 50 epochs with the optical flow loss; Stage 2 trains for 30 epochs with the object localization loss. This staged optimization avoids conflicts between the two objectives.

### Loss & Training

The optical flow loss is $L_F = L_{F,G} + L_{F,I}$ (estimated from GAF and single-frame features, respectively); the object localization loss is $L_O = L_{O,G} + L_{O,I}$. Pseudo-labels are generated by RAFT (optical flow) and YOLOX (detection) and are used only during training.

## Key Experimental Results

### Main Results

| Dataset | Method | Hit@1 | Hit@3 |
|---------|--------|-------|-------|
| VBD | GAFL (Prev. SOTA) | 61.1 | 82.4 |
| VBD | **Ours** | **82.7** | **93.0** |
| NBA | GAFL | 24.7 | 50.4 |
| NBA | **Ours** | **43.9** | **72.0** |

### Ablation Study

| Configuration | VBD Hit@1 | NBA Hit@1 |
|---------------|-----------|-----------|
| No pretraining tasks | 43.0 | 22.6 |
| Optical flow loss only | 75.4 | 34.1 |
| Object localization loss only | 74.0 | 40.3 |
| Two-stage training (full) | **82.7** | **43.9** |

### Key Findings

- Hit@1 improves by 21.6 (VBD) and 19.2 (NBA) over GAFL, representing a substantial performance leap.
- Optical flow estimation and object localization each contribute independently; two-stage combination yields the best results.
- The auxiliary branch (estimating from single frames) is critical for enabling DINOv3 to learn dynamic features.

## Highlights & Insights

- Both pretraining tasks are elegantly designed with clear, well-motivated rationales.
- The inpainting strategy that forces global reasoning is particularly clever.
- The large performance gains demonstrate that dynamic and global features are essential for group activity understanding.

## Limitations & Future Work

- Validation is currently limited to team sports scenarios.
- Group-relevant objects must be predefined (e.g., balls), limiting generalizability.
