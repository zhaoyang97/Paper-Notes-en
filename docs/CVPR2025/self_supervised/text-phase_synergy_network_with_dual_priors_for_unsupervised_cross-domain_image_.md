# Text-Phase Synergy Network with Dual Priors for Unsupervised Cross-Domain Image Retrieval

**Conference**: CVPR2025  
**arXiv**: [2603.12711](https://arxiv.org/abs/2603.12711)  
**Code**: To be confirmed  
**Area**: Self-Supervised  
**Keywords**: Unsupervised Cross-Domain Image Retrieval, CLIP, Text Prior, Phase Prior, Frequency Domain Alignment, Domain Prompt, Pseudo-label Noise

## TL;DR
TPSNet is proposed to address unsupervised cross-domain image retrieval using dual text-phase priors: domain prompts (text prior) provide more precise semantic supervision than pseudo-labels, while phase features (phase prior) achieve semantic-preserving domain-invariant alignment, with both synergistically fused through cross-attention.

## Background & Motivation
- Unsupervised cross-domain image retrieval (UCDIR) aims to retrieve images of the same category across different domains (e.g., real images vs. sketches) without annotations.
- Existing works adopt a two-stage paradigm: clustering to generate pseudo-labels $\rightarrow$ intra-domain contrastive learning + cross-domain feature alignment.
- **Limitations of Prior Work**: 
  - **Pseudo-label issue**: Discrete pseudo-labels generated by K-means clustering are inaccurate and incomplete, leading to false pair constraints and low-quality class prototypes.
  - **Semantic degradation issue**: Cross-domain alignment (adversarial learning, statistical distribution alignment, etc.) neglects the entanglement between domain-specific information and semantic information, resulting in the loss of semantic information during the spatial domain alignment process.
- There is a need for better semantic supervision and domain-invariant alignment strategies.

## Core Problem
In unsupervised cross-domain retrieval: (1) How to provide more accurate semantic supervision than pseudo-labels? (2) How to avoid losing semantic information during cross-domain alignment?

## Method
TPSNet consists of two key components: the Domain Prompt Generation module (DPG) and the Text-Phase Dual Prior network (TPDP).

### 1. Domain Prompt Generation Module (DPG) — Text Prior
- Performs K-means clustering on images from both domains separately, initializing a learnable text prompt for each cluster.
- Prompt template: "An image of a $[X]_1[X]_2...[X]_M$" ($[X]_i$ represents learnable tokens).
- Freezes the CLIP encoder and only optimizes the prompt tokens.
- Uses an improved cross-modal contrastive learning: image-to-text loss $L_{i2t}$ + text-to-image loss $L_{t2i}$.
- **Key Innovation**: Re-pairs image and text embeddings based on cosine similarity in $L_{i2t}$, which can partially correct inaccurate pseudo-labels.
- The optimized domain prompts encode more precise semantic information, serving as the subsequent text prior.

### 2. Text Prior Semantic Feature Extraction (TPFE)
- Passes the learned domain prompts through a shared text encoder to generate text features $T_A'$ and $T_B'$.
- These text features serve as the text prior to guide the semantic learning of visual features.

### 3. Phase Prior Domain-Invariant Feature Extraction (PPFE) — Phase Prior
- **Frequency Domain Decomposition**: Performs FFT on grayscale images to separate amplitude and phase spectra.
- **Phase Image Reconstruction**: Retains the phase spectrum, replaces amplitude with a constant $R$, and performs IFFT to obtain the phase image $X^{phase}$.
- **Phase Feature Encoder**: Lightweight CNN (Conv3×3 + BN + ReLU + AvgPool) $\rightarrow$ Flatten $\rightarrow$ FC to obtain phase feature $I^{phase}$.
- **Feature Fusion**: Concatenates RGB features $I^{rgb}$ and $I^{phase}$, then passes them through Self-Attention + LayerNorm + Average Pooling to obtain the fused feature $I^f$.
- **Principle**: The phase spectrum encodes cross-domain invariant structural and semantic cues, which are more robust than the amplitude spectrum.

### 4. Dual-Prior Synergistic Fusion
- Cross-Attention: Takes text features $T'$ as query, and fused visual features $I^f$ as key/value.
- The output $I'$ contains both the precise semantics of the text prior and the domain invariance of the phase prior.
- Class prototypes are updated via momentum at each epoch.

### 5. Loss & Training
- Prototype cross-entropy loss $L_{pce}$: Pulls features closer to their corresponding class prototypes.
- Image-to-text contrastive loss $L_{i2tce}$: Cooperates with label smoothing $\sigma_j$ to alleviate pseudo-label errors.
- Total loss: $L = \alpha \cdot L_{pce} + \beta \cdot L_{i2tce}$

## Key Experimental Results

### Office-Home (ViT-B backbone, P@1/P@5/P@15)

| Direction | TPSNet P@1 | SA-MoE P@1 | DD P@1 |
|------|-----------|-----------|--------|
| Art$\rightarrow$Real | 89.53 | 71.12 | 60.94 |
| Real$\rightarrow$Art | 91.74 | 73.86 | 61.92 |
| Art$\rightarrow$Product | 81.17 | 64.69 | 58.76 |
| Clipart$\rightarrow$Real | 51.68 (R50) | - | 33.31 |

- Under the ViT-B setting, Art$\rightarrow$Real P@1 reaches 89.53, which is 18.4 percentage points higher than SA-MoE.
- Leads by a large margin across all 12 cross-domain retrieval scenarios.

### ResNet-50 backbone also leads significantly
- Compared with ProtoOT/ShieldIR, the average gain is 15-20 percentage points.

## Highlights & Insights
1. **Text-phase dual-prior design**: The two priors address the core problems of UCDIR from different perspectives (inaccurate semantic supervision + semantic degradation in cross-domain alignment).
2. **Ingenious application of frequency domain phase separation**: The idea of retaining structural semantics and discarding domain style via the phase spectrum is simple yet effective.
3. **Domain prompts correcting pseudo-labels**: Partially corrects clustering errors through a re-pairing mechanism.
4. **Astonishing experimental gains**: Outperforms the second-best method by ~18 percentage points on Office-Home ViT-B.
5. **Clear dual-pathway design**: The text pathway provides semantics, while the image pathway (including phase) provides domain invariance, which are fused via cross-attention.

## Limitations & Future Work
- The number of K-means clusters $C$ needs to be pre-set, which remains the cornerstone of the method—if the initial clustering quality is extremely poor, the optimization of domain prompts might be limited.
- The phase feature encoder is relatively simple (only one layer of Conv+FC), which might lose some structural information.
- The choice of replacing the amplitude with a constant $R$ (how to determine $R$?) is not discussed in detail.
- The text prior relies on the quality of CLIP's semantic space, which may have limited effectiveness on domains not covered by CLIP's pre-training data.
- Only 7 categories ($>200$ samples/domain) are selected from DomainNet, and the performance under large-scale settings remains to be validated.

## Related Work & Insights
- vs. **DD/CoDA**: Directly utilize pseudo-labels, whereas TPSNet significantly improves the quality of semantic supervision through the text prior.
- vs. **ProtoOT/ShieldIR**: Prototype alignment based on optimal transport, but they still align features in the spatial domain, leading to semantic degradation.
- vs. **SA-MoE**: Maintains semantic integrity through semantic attention fusion, but TPSNet introduces the frequency domain phase prior on top of this, achieving larger gains.
- vs. **FDA/FUDA**: Only manipulate high/low-frequency components rather than performing amplitude/phase separation, whereas TPSNet's phase separation strategy retains semantics more directly.

## Inspirations & Connections
- The idea of using the phase spectrum as a domain-invariant feature can be extended to other vision tasks requiring domain adaptation.
- The domain prompt design of the text prior is closely related to prompt learning, and more complex prompt structures can be explored.
- The dual-prior synergistic framework design is generic and can be extended to other multi-modal or multi-domain learning scenarios.
- The potential of frequency domain analysis in cross-domain learning is currently underestimated and deserves further exploration.
