# Accelerating Eigenvalue Dataset Generation via Chebyshev Subspace Filter

**Conference**: ICLR 2026  
**OpenReview**: [https://openreview.net/forum?id=rrbCQT7JKX](https://openreview.net/forum?id=rrbCQT7JKX)  
**Code**: TBD  
**Area**: Scientific Computing / Numerical Linear Algebra / AI for Science  
**Keywords**: Eigenvalue Problem, Chebyshev Filter, Subspace Iteration, Dataset Generation, Operator Similarity

## TL;DR
Addressing the bottleneck where training neural operators requires massive operator-eigenvalue labeled data generated by expensive numerical solvers, this paper proposes SCSF (Sorting Chebyshev Subspace Filter). SCSF first uses truncated FFT to rank operators with similar spectral distributions in adjacent positions and then utilizes Chebyshev filtering subspace iteration to use the eigenpairs of the "previous problem" as a hot-start for the "next problem." This transforms the entire dataset generation from "independent solving" into a "relay solving" process, achieving up to a 3.5× speedup compared to mainstream solvers.

## Background & Motivation
**Background**: Solving eigenvalue problems for operators is a core task in quantum physics, fluid mechanics, and structural mechanics. Traditional numerical solvers (e.g., Krylov-Schur) are accurate but expensive. Recently, neural operators/neural eigenvalue methods have emerged because a single forward inference takes only milliseconds, which is orders of magnitude faster than numerical solvers.

**Limitations of Prior Work**: Neural methods are data-driven and require large-scale labeled data before training—each sample being "an operator + its eigenpairs (eigenvalues/eigenvectors)." These labels must be generated using expensive traditional solvers. Taking QM9 as an example, for $1.34\times10^5$ molecular samples, each requires solving a Hamiltonian eigenvalue problem. Generating the entire dataset often takes dozens of hours or even days. The paper notes that in the six-step data generation pipeline, "solving eigenvalues" (step 4) accounts for approximately 95% of the total overhead.

**Key Challenge**: Existing data generation methods solve each matrix in the dataset **independently**. However, operators within the same dataset often originate from the same parameter distribution and describe related physical phenomena, making them **highly similar** (similar spectral distributions and invariant subspaces). Independent solving wastes this similarity, leading to significant redundant computation. While prior work has shown that "leveraging similarity" can accelerate the generation of linear system datasets, applying similarity to **eigenvalue** datasets has remained an open problem.

**Goal**: To transform "independent solving per problem" into "sequential solving that utilizes previous results to accelerate subsequent ones" without reducing solving accuracy, thereby eliminating redundant calculations in eigenvalue data generation.

**Key Insight**: The authors observe two points: (1) Operators are primarily determined by the **low-frequency components** of the parameter matrix, while high-frequency components are mostly noise; (2) Two matrices with similar spectral distributions also have similar **invariant subspaces**, which can be borrowed from each other. The former makes "finding similarity" cheap, while the latter makes "utilizing similarity" effective.

**Core Idea**: Replace "independent solving" with "sorting + relay"—truncated FFT sorting places similar problems adjacently, and Chebyshev filtering subspace iteration uses the eigenpairs of the previous problem for a hot-start.

## Method

### Overall Architecture
SCSF addresses how to quickly solve a "sequence of eigenvalue problems for an entire dataset." The input is a batch of Hermitian matrices $A^{(1)},\dots,A^{(N)}$ discretized from PDE operators (each needing the $L$ smallest eigenpairs $(\Lambda^{(i)}, V^{(i)})$), and the output is the assembled eigenvalue dataset. The process consists of three stages: first **sorting** the unordered matrix sequence into a sequence where "adjacent problems have similar spectral distributions"; then **relay solving** along this sequence—problem $i$ no longer starts from a random subspace but uses the eigenpairs just solved from problem $i-1$ as a hot-start, using Chebyshev filtering to pull the spectrum into an easily solvable state; finally, assembling all eigenpairs into the dataset.

The sequential eigenvalue problem for each sample is expressed as:

$$A^{(i)}v_j^{(i)} = \lambda_j^{(i)} v_j^{(i)},\quad j=1,\dots,L;\ i=1,\dots,N$$

where $A^{(i)}\in\mathbb{C}^{n\times n}$ is obtained by discretizing the parameter matrix $P^{(i)}$ using the finite difference method (FDM). All acceleration in SCSF is built on the premise that $A^{(i)}$ under the same distribution are highly similar.

### Key Designs

**1. Truncated FFT Sorting: Ranking similar problems adjacently cheaply.**

For relay solving to be effective, adjacent matrices in the sequence must be sufficiently similar. A naive approach (SKR) would involve calculating pairwise Frobenius distances of parameter matrices $P$ for greedy sorting, which requires repeated high-dimensional comparisons with a complexity of $O(N^2p^2)$, where $p$ is the operator resolution. This becomes infeasible for large matrices. The authors observe that the **low-freq components** of $P$ primarily determine the operator. Thus, they perform a truncated FFT on each $P^{(i)}$, keeping only a $p_0\times p_0$ low-frequency block $P_{low}^{(i)}$ ($p_0\ll p$, with $p_0=20$ being sufficient in experiments), and then perform greedy sorting on these small blocks. The total complexity is reduced to $O(N^2p_0^2 + Np^2\log p)$. Remarkably, experiments show this low-cost sorting produces sequences that are **over 98% identical** to those from expensive full greedy sorting.

**2. Invariant Subspace Hot-start: Using previous eigenpairs as a starting line.**

Standard subspace iteration starts each problem from a random initial subspace, discarding previous results. In solving problem $i$, SCSF sets the initial iteration subspace $\tilde V_0 = V^{(i-1)}$ and initial spectrum $\tilde\Lambda_0 = \Lambda^{(i-1)}$. Since sorting ensures that $A^{(i)}$ and $A^{(i-1)}$ have similar spectral distributions and invariant subspaces, this starting point is already very close to the true solution, significantly reducing the number of subsequent iterations. Only the first problem $A^{(1)}$ in the sequence defaults to random initialization. This design is tightly coupled with sorting: the better the sorting, the higher the hot-start quality, and the more iterations are saved.

**3. Chebyshev Spectral Filter Iteration (ChFSI): Amplifying the target spectral region.**

A good starting point is not enough; iteration must converge quickly to the desired $L$ smallest eigenvalues. SCSF uses Chebyshev filtering subspace iteration for spectral transformation. Chebyshev polynomials of the first kind $C_m(t)=\cos(m\cos^{-1}t),\ |t|\le1$, satisfy a three-term recurrence $C_{m+1}(t)=2tC_m(t)-C_{m-1}(t)$. They grow extremely fast outside the interval $[-1, 1]$ and are flattened inside. Applying $C_m(A)$ to the subspace **amplifies** the **target spectral region** (estimated using center $c=\frac{\alpha+\beta}{2}$ and half-width $e=\frac{\beta-\alpha}{2}$ from the previous problem) relative to other spectra. The single-step iteration (Algorithm 3) involves: applying Chebyshev filtering $\tilde V_0 = C_m(\tilde V_0) \rightarrow$ QR orthogonalization on $[\tilde V\,|\,\tilde V_0] \rightarrow$ computing the Rayleigh quotient $G=Q^\top A^{(i)}Q$ to project the problem onto an approximate eigenspace $\rightarrow$ solving this small-scale reduced problem and projecting back $\rightarrow$ locking converged eigenpairs and continuing filtering for unconverged ones until the count $\ge L$. The polynomial degree $m$ (e.g., $m=20$) controls filtering strength. Complexity analysis shows the Chebyshev filtering step $O(mn^2L)$ is the dominant per-step cost.

### A Full Example
Taking the Helmholtz dataset (matrix dimension 6400, solving for 400 smallest eigenvalues, precision 1e-8) as an example: First, perform truncated FFT on all $N$ parameter matrices to get low-frequency blocks and use greedy sorting to form a sequence where adjacent problems are similar. The 1st problem is randomly initialized and solved via ChFSI to get $(\Lambda^{(1)},V^{(1)})$. For the 2nd problem, instead of a random start, it uses $\tilde V_0=V^{(1)},\tilde\Lambda_0=\Lambda^{(1)}$. Because the problems are similar, this start is close to the truth, requiring an average of only 5.5 iterations to converge (vs. 10.4 for random ChFSI). This continues sequentially. In this setup, the average time per problem is 40.52s, compared to 66.66s for the randomly initialized version.

## Key Experimental Results

### Main Results
Four datasets (Generalized Poisson, Second-order Elliptic, Helmholtz, Fourth-order Vibration, dimensions 2500–10000) were compared against five mainstream solvers. Selected average solving times (seconds, lower is better):

| Dataset (Dim/Prec) | L | Eigsh | LOBPCG | KS | JD | ChFSI | SCSF |
|--------|---|-------|--------|-----|-----|-------|------|
| Helmholtz (6400/1e-8) | 200 | 151.7 | 129.9 | 98.34 | 489.6 | 107.1 | **31.31** |
| Helmholtz | 400 | 253.5 | 460.4 | 283.0 | 3829 | 121.5 | **40.52** |
| Helmholtz | 600 | 398.8 | 1031 | 329.6 | – | 146.2 | **51.32** |
| Vibration (10000/1e-8) | 600 | 1037 | 2716 | 857.8 | – | 382.3 | **131.4** |

On Helmholtz, SCSF achieves speedups of 8× / 20× / 6× / 95× / 3.5× relative to Eigsh / LOBPCG / KS / JD / ChFSI, respectively (even 3.5× over the strongest ChFSI). Two patterns emerged: **The more eigenvalues required** (larger L), the more obvious SCSF's advantage becomes (e.g., 5.5× faster than KS at L=400 on Elliptic), as inherited subspaces contain substantial information. **The larger the matrix dimension**, the greater the advantage (comparable to Eigsh at dim <3600, significantly leading at dim >5000), as larger matrices provide more accurate approximations of true eigenvalues with less relative noise.

### Key Findings
- **Chebyshev filtering is the main driver of speedup**: Even when baselines are updated with "previous eigenvector hot-start," they remain far slower than SCSF, suggesting Chebyshev spectral filtering is the optimal vehicle to translate similarity into acceleration.
- **Sorting quality does not require high cost**: Truncated FFT sorting produces 98%+ identical sequences at a fraction of the cost of full greedy sorting, a classic example of "using cheap approximations to replace expensive exactness."
- **Robustness of truncation threshold**: $p_0=20$ (much smaller than $p$) is sufficient; low-frequency components are enough.
- SCSF is a pure numerical algebra acceleration technique; it does not change solving results at the specified precision (≥1e-8), serving as ground truth for downstream training.

## Highlights & Insights
- **Reframing "Dataset Generation" as "Sequential Eigenvalue Problems"**: This is the most critical perspective shift—once it is accepted that operators from the same distribution are similar, independent solving is wasteful, and "sorting + relay" becomes logical. This reframing can be migrated to any "batch solve for same distribution" scientific data generation task.
- **Decoupling "Finding Similarity" and "Using Similarity" via Low-frequency Truncation**: Using cheap low-frequency FFT blocks for sorting while using full matrices for solving balances both needs without the overhead of high-dimensional distance calculations.
- **Insight into the Coupling of Sorting and Hot-start**: The authors quantify that sorting contributes 1.3–2.8× speedup, demonstrating a solid experimental design by isolating and quantifying each component.
- **First work to accelerate eigenvalue dataset generation**: Fills the gap in "similarity acceleration" which existed for linear systems but not for eigenvalue problems.

## Limitations & Future Work
- **Limited to Hermitian / Linear Operators**: The method assumes self-adjoint operators and Hermitian matrices; non-Hermitian or nonlinear operators are not yet covered (primary future work).
- **Fixed Similarity Metric**: Currently uses the Frobenius norm of parameter matrices-a one-size-fits-all metric that may not suit all problems; the plan is to explore problem-specific metrics.
- **Reliance on Continuous Parameter-to-Operator Mapping**: If the mapping is discontinuous, the "adjacent parameters ⇒ adjacent spectra" premise fails; future work aims to measure similarity directly from the operator or matrix representation.
- (Self-addition) Experiments are solely on PDE discretization matrices, lacking end-to-end verification in real large-scale scientific scenarios like electronic structure calculations. Speedup magnitude is highly dependent on operator similarity (e.g., only ~10% faster than Eigsh on Generalized Poisson).

## Related Work & Insights
- **vs ChFSI (Randomly Initialized)**: ChFSI starts each problem randomly; SCSF adds sorting and cross-problem hot-starts to it, gaining another 3.5× speedup on Helmholtz. Both use Chebyshev filtering; the difference is "reusing previous information."
- **vs SKR / Naive Greedy Sorting (Wang et al., 2024)**: SKR uses greedy sorting on full parameter matrices to accelerate linear systems ($O(N^2p^2)$); this paper uses truncated FFT to reduce sorting to $O(N^2p_0^2+Np^2\log p)$ and generalizes the target to eigenvalue problems.
- **vs General Eigenvalue Solvers (Eigsh/LOBPCG/KS/JD)**: These solvers treat each matrix independently; SCSF's gain comes from "stringing independent problems into a sequence," which is why its advantage grows with larger L and dimensions.

## Rating
- Novelty: ⭐⭐⭐⭐ First similarity-based acceleration method for eigenvalue dataset generation; clear "sorting + relay + filtering" combination.
- Experimental Thoroughness: ⭐⭐⭐⭐ Four datasets, five baselines; sorting, filtering, and thresholds were ablated and quantified solidly.
- Writing Quality: ⭐⭐⭐⭐ Motivation and methods are clear, with complete formulas and pseudo-code.
- Value: ⭐⭐⭐⭐ Directly addresses the data generation bottleneck for AI for Science; up to 3.5× acceleration without losing accuracy is highly practical.
