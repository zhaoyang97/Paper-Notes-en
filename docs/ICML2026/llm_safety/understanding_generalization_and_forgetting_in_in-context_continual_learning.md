# Understanding Generalization and Forgetting in In-Context Continual Learning

**Conference**: ICML 2026  
**arXiv**: [2605.28705](https://arxiv.org/abs/2605.28705)  
**Code**: To be confirmed  
**Area**: LLM Inference / Continual Learning / Attention Mechanism  
**Keywords**: In-context learning, continual learning, forgetting, task interference, Transformer theory

## TL;DR
This work establishes the first theoretical framework for In-Context Continual Learning (ICCL), revealing systematic biases and task interference inherently generated by attention mechanisms when processing multi-task sequences, which leads to performance decay and forgetting sensitive to task order.

## Background & Motivation

**Background**: LLMs adapt to new tasks during inference via In-Context Learning (ICL) without parameter updates. However, existing theories primarily focus on single-task ICL, whereas real-world prompts frequently contain sequences of heterogeneous tasks.

**Limitations of Prior Work**: Classical literature on continual learning investigates forgetting caused by parameter updates. In contrast, ICL involves adaptation with frozen parameters based entirely on attention. A theoretical gap exists regarding whether LLMs implicitly perform continual learning when processing long-context multi-task sequences and the conditions under which they forget.

**Key Challenge**: Single-task ICL theory (assuming all examples derive from the same function) cannot capture inter-task dependencies. Classical continual learning theory is based on training-time parameter updates, which is fundamentally different from the pure attention-based adaptation at inference time.

**Goal**: (1) Construct the first theoretical framework for ICCL; (2) Quantify generalization and forgetting in multi-task sequences; (3) Explain experimental phenomena such as task-order sensitivity and performance saturation in long prompts.

**Key Insight**: The mechanism of how attention aggregates historical context is critical. Standard linear attention aggregates context uniformly (causing future information leakage). Masked linear attention aggregates causally (respecting task order but still producing systematic interference).

**Core Idea**: Characterize how task similarity, context length, and task order jointly determine whether historical information leads to positive or negative transfer through explicit **bias-variance-interference decomposition**.

## Method

### Overall Architecture
The paper formalizes ICCL as an analytical regression problem: a prompt sequence is constructed by concatenating examples and queries from $T$ regression tasks and fed into a shared attention layer. For each task $t$, the model infers task parameters $w_t$ from $M$ in-context examples $\{(x_{t,i}, y_{t,i})\}_{i=1}^{M}$ and predicts the query $y_{t,q} = \langle w_t, x_{t,q} \rangle$. Within this setting, the authors derive closed-form expressions for generalization error $G_t$ (current task accuracy) and forgetting error $F_t$ (degradation of previous tasks during subsequent tasks), making the conditions for positive transfer versus forgetting computable.

### Key Designs

**1. Masked Linear Attention Model: Encoding task order with causal masks to prevent future information leakage**

Standard linear attention used in single-task ICL theory aggregates all context uniformly. In multi-task sequences, this allows task $t$ to "peek" at examples from future tasks, violating the causality of continual learning. The authors employ masked linear attention $f_{\text{MSA}}(P;\theta) = P + WP \cdot \mathrm{mask}(P^\top VP)$, where $\mathrm{mask}(A)_{i,j} = \frac{1}{j}A_{i,j}$ (if $i \le j$) and $0$ otherwise. This forces information to flow only from the past to the present, respecting task arrival order while maintaining the analytical benefits of linear attention for error decomposition.

**2. Bias-Variance-Interference Decomposition: Separating prediction error to identify if context helps or hinders**

To determine if increasing context length is beneficial, the authors decompose the prediction error $\mathbb{E}[(\hat{y}_{t,q} - y_{t,q})^2]$ for task $t$ into three components: (i) irreducible error; (ii) finite sample variance, which scales as $O(1/M)$ and decays as context examples increase; and (iii) task mean bias $\|\frac{1}{t}\sum_{s=1}^t w_s - w_t\|_2^2$, representing the deviation of the historical task average from the current $w_t$. The key insight is that while variance can be mitigated by increasing $M$, the bias term depends solely on task similarity and is independent of $M$. Consequently, extra context is beneficial when tasks are aligned and variance dominates, but harmful when tasks are heterogeneous and bias pulls predictions toward an incorrect historical mean.

**3. Task Similarity and Order Dependency Coefficients: Attributing forgetting to the redistribution of attention weights**

In this framework, forgetting is not about parameter overwriting but the redistribution of attention weights across historical positions when processing new tasks. The authors introduce dependency coefficients $\alpha_i(t) = c_t < 0$ (if $i \le t$) and $\alpha_i(t) = d > 0$ (if $i > t$) to characterize this: learned past tasks are assigned negative weights (canceling their contribution, leading to degradation), while future tasks are assigned positive weights (causing interference). The expanded forgetting error comprises within-task variance terms that decay as $O(1/M)$ and cross-task mean interference terms $\mathrm{tr}(\mu_i\mu_j^\top\Gamma^{-2}\Lambda)$. Unlike variance, the **mean interference converges to a non-zero constant even as $M \to \infty$**. This explains why long contexts cannot eliminate forgetting—as long as subsequent tasks are not orthogonal to current task means, residual interference persists, peaking when tasks are highly aligned.

## Key Experimental Results

### Main Results

| Factor | Impact on Generalization | Impact on Forgetting |
|------|-----------|-----------|
| Context Length $M$ | Reduces variance; saturation or degradation occurs after alignment threshold as bias dominates | Variance term decays at $O(1/M)$; mean interference remains constant (forgetting persists even as $M \to \infty$) |
| Task Similarity | Historical information reduces bias when tasks are aligned; bias increases rapidly when tasks are heterogeneous | Interference $\mathrm{tr}(\mu_i\mu_j^\top\Gamma^{-2}\Lambda)$ increases significantly when future tasks are aligned with the current task |
| Task Order | N/A for single tasks; determines historical aggregation in multi-task scenarios | Order-sensitive: the degree of alignment between subsequent and previous tasks determines interference strength |

### Key Findings

| Experiment | Phenomenon | Verification |
|------|------|------|
| Non-monotonicity | For Task 2, increasing $M$ from 3 to 19 caused the error to jump from its minimum to 0.99 | Fully aligns with theoretical predictions |
| Task Clustering Effect | Performance is superior within similar clusters {Task 1, 3, 5}, while strong interference occurs across clusters | Consistent with the theory |
| Real LLMs | Qwen2.5 exhibits catastrophic forgetting (0.934 → 0.472) for Task A at $M=1$ in an SST-2 → AG News sequence | Matches theoretical predictions |

## Highlights & Insights
- **First Theoretical Bridge**: Unifies ICL and continual learning by explaining the mechanism of forgetting under frozen parameters via attention weight redistribution.
- **Analyzable yet Transferable**: Assumptions from the linear regression model remain valid when tested on non-linear two-layer ReLU networks.
- **Practical Implications**: In multi-task prompting, task order should be intentionally designed, or smaller $M$ should be used to mitigate negative transfer.

## Limitations & Future Work
- Linear task distribution assumptions may not capture the full complexity of real-world NLP.
- The analysis is based on masked linear attention; differences in multi-head softmax attention mechanisms are not fully explored.
- The awareness of task boundaries via position embeddings was not considered.
- Future directions: Designing "task-boundary aware" attention mechanisms; studying prompt reordering to mitigate forgetting; extending to non-linear self-attention and multi-head mechanisms.

## Related Work & Insights
- **vs Single-task ICL Theory (Bai et al. 2023, Von Oswald et al. 2023)**: These works assume homogeneous examples; this paper introduces heterogeneity in task sequences.
- **vs Classic Continual Learning (Lin et al. 2023)**: While prior work focuses on forgetting due to parameter updates, this paper proves that attention aggregation with frozen parameters also leads to inevitable forgetting.
- **vs Empirical ICCL Studies (Kang et al. 2025)**: While they demonstrate that ICL can perform continual learning, this paper identifies the fundamental theoretical causes for **when it succeeds and fails**.
