# Precise Event Spotting in Sports Videos: Solving Long-Range Dependency and Class Imbalance

**Conference**: CVPR 2025  
**arXiv**: [2503.00147](https://arxiv.org/abs/2503.00147)  
**Code**: None  
**Area**: LLM Pre-training  
**Keywords**: Precise event spotting, sports videos, class imbalance, temporal dependency, contrastive learning

## TL;DR

An end-to-end trainable precise event spotting framework is proposed, which enhances the spatiotemporal information of features through an Adaptive Spatiotemporal Refinement Module (ASTRM) and introduces a Soft Instance Contrastive (SoftIC) loss to address the class imbalance problem. It surpasses the state-of-the-art with 73.74 mAP under the SoccerNet V2 tight setting.

## Background & Motivation

Precise Event Spotting (PES) requires detecting the exact frame of occurrences in long untrimmed videos, which is particularly crucial in sports videos. It faces two major challenges:

1. **Long-range temporal dependency**: The category of many events can only be determined by observing long-range frames. For instance, "shots on target" and "shots off target" are annotated at the instantaneous moment of the shot, but identifying them requires observing the subsequent trajectory of the ball. Relying solely on neighboring frames is insufficient for accurate prediction.
2. **Class imbalance**: The occurrence frequency of sports events is naturally uneven. In soccer, "ball out of play" events occur far more frequently than "red cards", leading to poor model performance on minority classes.

Limitations of Prior Work:
- Transformer-based methods (such as ASTRA) rely on large pre-trained feature extractors, and the attention weight matrix of self-attention on long videos is too large, making it difficult to learn effectively.
- CNN-based methods like E2E-Spot and T-DEED have limited capability in extracting temporal information.
- Almost no methods specifically address the class imbalance problem, with only ASTRA active in trying a mixup variant.

## Method

### Overall Architecture

An end-to-end trainable network: CNN spatiotemporal feature extractor (RegNetY + ASTRM) $\to$ Bi-GRU long-range temporal module $\to$ linear classifier. The model is trained using the ASAM optimizer, combined with the SoftIC loss to handle the class imbalance issue.

### Key Designs

**Design 1: Adaptive Spatiotemporal Refinement Module (ASTRM)**

- **Function**: Enhances both spatial and temporal information during the feature extraction process.
- **Mechanism**: Three sub-modules are connected in series—(a) Local Spatial: MaxPool + AvgPool along the channel dimension followed by a 7×7 convolution + Sigmoid to generate spatial attention weights; (b) Local Temporal: 3×1×1 3D convolution to capture local temporal dynamics + Sigmoid; (c) Global Temporal: Global Average Pooling + FC layer to generate dynamic convolution kernels, which are convolved with the enhanced features from the first two stages.

$$\Psi(\mathbf{x}) = ((\mathbf{x} \odot (1 + \mathcal{F}_s(\mathbf{x}))) \odot (1 + \mathcal{F}_t(\mathbf{x}))) * \mathcal{G}_t(\mathbf{x})$$

- **Design Motivation**: Spatial information is equally vital for event spotting (e.g., the position of the ball) and temporal information alone is insufficient. Global temporal context is injected through dynamic convolution kernels in a simple and efficient manner.

**Design 2: Soft Instance Contrastive (SoftIC) Loss**

- **Function**: Effectively promotes intra-class compactness and inter-class separation under mixup augmentation, alleviating class imbalance.
- **Mechanism**: Extends the Instance Contrastive Loss to support soft labels (non-one-hot labels generated by mixup). A memory bank stores features and their class weights; during contrastive learning, the class weights $w_j$ are used to scale the feature similarity.
- **Design Motivation**: IC Loss assumes each sample has only a single label, which is incompatible with mixup. SoftIC addresses blended labels through weighting, simultaneously leveraging the regularization capability of mixup and the representation separation capability of contrastive learning.

$$\mathcal{L}_{SIC}(\mathbf{z}_i, \omega) = \frac{1}{\omega|M(\mathbf{c}_i)|} \sum_{(\mathbf{z}_j, w_j) \in M(\mathbf{c}_i)} \log \frac{\exp(\mathbf{z}_i \cdot w_j \mathbf{z}_j / \tau)}{\sum_{(\mathbf{z}_k, w_k) \in A(\mathbf{c}_i)} \exp(\mathbf{z}_i \cdot w_k \mathbf{z}_k / \tau)}$$

**Design 3: ASAM Optimization Strategy**

- **Function**: Improves the generalization capability of the trained model.
- **Mechanism**: Employs Adaptive Sharpness-Aware Minimization instead of standard Adam, considering a scale-adaptive neighborhood of the loss landscape to compute flat minima.
- **Design Motivation**: The fixed neighborhood of SAM is not flexible enough, whereas the adaptive neighborhood of ASAM is more effective for event spotting tasks.

### Loss & Training

$$\mathcal{L}_{final} = \mathcal{L}_{BCE} + \lambda_{SIC} \cdot \mathcal{L}_{SIC}$$

where $\lambda_{SIC} = 0.001$.

## Key Experimental Results

### SoccerNet V2 Test Set

| Method | Params(M) | GFLOPs | Tight mAP | Loose mAP |
|------|-----------|--------|-----------|-----------|
| E2E-Spot (RegNet-Y 200) | 4.46 | 39.61 | 61.19 | 73.25 |
| Spivak | 17.46 | 461.89 | 65.10 | 78.50 |
| ASTRA | 44.33 | 8.83 | 66.63 | 78.14 |
| COMEDIAN (ViSwin-T) | 70.12 | 222.76 | 71.33 | 77.07 |
| **Ours** | **6.46** | **60.25** | **73.74** | **79.11** |

### Performance Comparison on Minority Classes (Tight Setting)

| Class | E2E-Spot | COMEDIAN | Ours |
|------|----------|----------|----------|
| Red card | ~30% | ~55% | **~72%** |
| Yellow→Red | ~20% | ~45% | **~65%** |
| Penalty | ~50% | ~60% | **~75%** |

### Ablation Study

| Component | SoccerNet V2 Tight |
|------|-------------------|
| Baseline (RegNetY + GRU) | 61.19 |
| + ASTRM | 66.82 |
| + SoftIC | 70.41 |
| + ASAM | **73.74** |

### Key Findings

1. Outperforming COMEDIAN (70M parameters) with only 6.46M parameters by achieving a $+2.41$ tight mAP gain, demonstrating that end-to-end training combined with meticulous design is superior to stacking large models.
2. The performance improvement of SoftIC on minority classes is particularly distinctive (more than doubling the AP of the "Red card" class), which effectively alleviates class imbalance.
3. ASTRM contributes $+5.63$ mAP, SoftIC contributes $+3.59$ mAP, and ASAM contributes $+3.33$ mAP—the contributions of all three components are significant.
4. The end-to-end trained CNN+GRU architecture outperforms plans using pre-trained offline features with standard Transformers under the tight setting.

## Highlights & Insights

1. **Efficiency is King**: Beating a 70M parameter model with only 6.46M parameters shows that a carefully designed lightweight network coupled with end-to-end training is superior to stacking large models.
2. **Generalizability of SoftIC Loss**: Porting contrastive learning to support soft labels is valuable for any imbalanced classification task utilizing mixup.
3. **Three-Stage Design of ASTRM**: The cascade refinement of spatial $\to$ local temporal $\to$ global temporal features fully exploits multi-dimensional information.

## Limitations & Future Work

1. A processing window size of 128 frames may not suffice to cover certain events that demand longer temporal contexts.
2. SoftIC requires an extra memory bank for feature storage, increasing memory overhead.
3. The validation is limited to sports videos, without testing on other event detection scenarios such as surveillance videos.
4. Future work could explore incorporating ASTRM into larger backbones to further boost performance.

## Related Work & Insights

- **E2E-Spot**: A pioneer in end-to-end event spotting, which Ours significantly enhances based on its architecture.
- **COMEDIAN**: Achieves high performance through a three-stage training process and a large backbone, but suffers from low efficiency.
- **Instance Contrastive Loss**: SoftIC directly extends IC Loss to adapt to the mixup scenario.
- Insight: The contrastive learning solution (SoftIC) for handling the class imbalance problem can be migrated to other long-tailed distribution tasks.

## Rating

⭐⭐⭐⭐ — Highly efficient end-to-end design that achieves SOTA with very few parameters. The SoftIC loss offers an elegant and practical solution for the class imbalance problem. Although ASTRM is not entirely novel in design, its composition is effective. The substantial gain under the tight setting demonstrates that improvements in minority classes are key.
